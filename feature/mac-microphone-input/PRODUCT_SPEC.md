# Mac 麦克风语音输入

本规范定义 macOS 上显式启停 Mac 麦克风送音的用户行为。此功能不要求连接遥控器、手机或网页。

- 连接页保留现有布局、输出设备和增益。新增物理输入设备选择及“用 Mac 麦克风说话”按钮。悬停提示必须为“仅在不使用遥控器时使用”。
- 输入设备标签、设备名称、收音状态和启停按钮保持同一行，快捷键设置单独放在下一行。空间不足时截断设备名称，并通过悬停显示完整名称；状态和按钮保持完整。错误说明放在输入行下方，不缩小中文字号。
- 开始后显示“Mac 麦克风正在收音”和“停止用 Mac 麦克风说话”。准备与停止阶段必须持续可见。停止完成前不能开启第二次会话。
- 连接页、菜单栏右击菜单和可配置全局快捷键控制同一个会话。快捷键默认不设置。组合键必须包含 Command、Control 或 Option；不支持单独修饰键或 Fn，不区分左右修饰键。按住时只触发一次。注册失败时显示提示。
- 三个入口只控制物理麦克风向虚拟麦克风送音，不启动或结束输入工具的语音识别，不发送 Fn 或其他语音快捷键。开始和停止均不激活其他应用、不恢复输入框焦点、不隐藏 SayAll 窗口。
- 开始前只验证麦克风权限、所选输入设备和虚拟输出。本功能不以辅助功能权限、前台应用或文本框状态作为启动条件。用户自行在输入工具中开始或结束语音识别。
- 默认选择 Mac 内置麦克风。没有内置麦克风时由用户选择物理输入。设备丢失时停止并提示，不静默改用其他设备。排除已识别的虚拟和聚合输入，避免自循环。
- 音频只从所选物理麦克风进入当前 SayAll / MiRemoteV 2ch 或 BlackHole 2ch 虚拟输出。普通扬声器不能作为此功能的输出。本功能不更改系统默认输入/输出，不自动修改第三方工具设置。
- 首次明确启动时才请求麦克风权限；空闲时不采集，不做常驻声音检测，不自动开始。原始音频和文字历史继续遵循用户现有的显式保存设置。
- 本功能不使用遥控器的语音触发模式。Fn 点按、按住及其他触发键设置只控制原有遥控器、手机和网页路径。
- 正常停止必须先停止采集准入，按序提交已接收的 PCM 与重采样尾部，再排空虚拟输出。不用 flush 丢弃正常尾音。
- 已有语音、音频测试或待启动会话占用时拒绝本次启动。本功能准备、收音或停止期间拒绝其他来源的软件语音启动，不混音。提示不代表已屏蔽系统硬件 Fn 映射，必须完成真实遥控器互斥验收。
- 切换前台应用或输入位置时保持送音，直到用户显式停止或发生设备、权限、系统生命周期异常。此功能不替用户选择输入位置。
- 权限拒绝、设备失效、采集或触发失败、准备超时、系统休眠和退出均有可归因的终态。异常被迫中断必须记录 forced，不能报告为正常成功。恢复后不自动重开麦克风。

验证边界见 [测试手册](../../Testing/MacMicrophoneInput.md)。本地构建、模拟音频和截图不能证明真实文字上屏或硬件兼容。
