# 语音触发自定义快捷键

本规范定义“语音键模拟 Fn 点按”模式下，为 Typeless 等点按切换式语音工具发送自定义快捷键的用户行为。它只改变每次语音开始和结束时发送的触发键，不改变收音、音频路由和尾音排空。

## 用户问题与目标

Typeless 的普通听写可以使用 Fn 点按。翻译等模式可能要求 Fn 组合键（例如 Fn + Shift + S），而同一个组合键不会启动或结束默认听写。用户需要在不更换遥控器、不清空现有 Fn 点按行为的前提下，让一次 SayAll 语音会话发送该组合键。

## 可见行为

- 仅当语音键模式为 Fn/地球键且“语音键模拟 Fn 点按”已开启时，按键映射页的语音设置区显示“自定义语音触发”。关闭 Fn 点按或切换语音键模式后，该行隐藏。
- 默认未设置。未设置时继续发送现有 Fn 点按，已有用户行为不变。设置后，每次语音开始发送一次自定义快捷键，结束时再发送一次；同一次会话不混发 Fn。
- 用户可按一次录制快捷键，显示当前组合；可重新录入或清除。录制沿用设置页现有快捷键录入交互和失败提示。
- 组合键至少包含一个修饰键（Control、Option、Shift、Command 或 Fn）；单独普通字符被拒绝并提示，避免向目标 App 输入文字。支持普通键组合（如 Fn + Shift + S），也支持纯修饰键组合（如 Fn + Shift）；纯修饰键组合只发送修饰键按下/释放，不额外发送主键。示例为 Typeless 翻译的 Fn + Shift。
- 语音收音、准备、停止或排空期间禁止修改或清除触发键；按钮禁用，模型层也拒绝写入。结束时提示用户后再修改。
- 自定义触发只在 Fn 点按路径生效。长按式工具、Fn 点按关闭、非 Fn 语音键模式、手机、Apple Watch 和网页版语音入口保持原行为。

## 会话语义

- 开始：遥控器按下后仍先执行现有目标就绪等待和 150 ms 启动延迟；发送自定义快捷键后等待 120 ms 让目标切换就绪，再按序提交 pre-roll。首个有效音频不因自定义快捷键产生额外双击窗口或长按阈值。
- 结束：先收到遥控器松开，保留在途 PCM 并完成输出排空，再发送一次自定义快捷键。不得为更快结束而 flush、清空或截断尾音。
- 失败：开始阶段自定义快捷键提交失败时，本次会话以 `start_tap_failed` 结束，关闭 Fn 点按并回退硬件 Fn 路径；不得在同一会话改为发送 Fn 或继续提交音频。结束阶段失败记为 `stop_tap_failed`，不得把未确认的目标状态报告为成功。
- 同一次会话固定一种触发。开始使用自定义触发后，结束、关闭或退出都只发送同类触发；即使 Fn 点按模式或触发设置在会话中被外部改动，也不得改用 Fn。自定义触发不可用时按失败处理并记录，不混发。
- 禁用 Fn 点按、断连、挂起或退出发生在自定义触发已提交但启动尚未完成时，必须发送一次匹配的关闭快捷键，不能改用 Fn。遥控器仍按住时，完成回调等待松开，和现有 Fn 路径一致。
- 禁用或退出发生在自定义会话已进入收音阶段时，先走现有排空并发送一次匹配的停止快捷键；正在发送停止快捷键时退出，不再补发，避免把目标重新打开。
- 自定义快捷键提交成功只表示按键事件已提交，目标 App 是否接受属于不可观察边界，日志记录 `target_response=unknown`。

## 持久化与兼容

- 触发键保存在本机设置中，随完整配置导出和导入；旧配置缺少该字段时按未设置处理，继续使用 Fn。
- 导入的触发键必须通过同一组合键校验；裸键只丢弃该字段并在导入报告中标记 `voiceTriggerShortcut`，其余配置仍正常导入。
- 语音键模式或 Fn 点按关闭时保留已保存的触发键，便于用户重新开启；实际生效值由模式和开关共同门控。
- 当前 `PortableHostSettings.voice` 不包含该字段。跨 Mac 便携配置在私有包增加字段前不会携带该触发键，导入后回退为未设置；不得在本仓库绕过私有包格式。
- 不新增 `VoiceKeyMode` 取值，不改变现有按键配置、iOS 或网页协议字段。

## 明确不做

- 不实现按 App 或按键方案分别配置触发键；该能力需要独立需求。
- 不改变手机、Apple Watch、网页版的移动语音点按语义。
- 不改变 RC003 约 60 秒录音限制、Lark/飞书 Fn 消费、Mac mini 无内置键盘或系统 Fn 占用行为。
- 不自动启动、读取或修改第三方 App 的内部状态；只通过公开快捷键注入触发。
- 不因自定义快捷键而改成持续录音、自动切换输入源或额外聚焦输入框。

## 实现范围

- `Sources/RemoteMic/RemoteButtons.swift`：触发键合法性校验、纯修饰键组合识别与显示。
- `Sources/RemoteMic/AppSettings.swift`：本机持久化、生效门控、导入导出与旧格式兼容。
- `Sources/RemoteMic/ShortcutCaptureMonitor.swift`：语音触发录入允许纯修饰键组合；其他录入器保持原规则。
- `Sources/RemoteMic/ShortcutEventSequence.swift`、`KeyboardInjector.swift`：纯修饰键组合只发送修饰键边沿，普通组合继续走完整快捷键。
- `Sources/RemoteMic/VoiceFnTapSessionController.swift`：自定义触发、会话内触发类型固定，以及失败、禁用、挂起和退出时的匹配关闭。
- `Sources/RemoteMic/BridgeAppModel.swift`：注入接线、录音中拒绝修改和脱敏日志。
- `Sources/RemoteMic/SettingsView.swift`：按键映射页语音设置区的录入、清除、错误和禁用状态。
- `Resources/*.lproj/Localizable.strings`：中英文文案。
- `Sources/RemoteMic/SettingsScreenshotRenderer.swift`：生产设置页截图 fixture。

## 隐私与日志

- 不记录按键字符、完整组合或目标 App 内容；只记录 `has_function`、`modifier_count`、会话操作 ID 和结果。
- 日志不得把按键事件提交、音频入队或目标切换等待记为最终文字成功。成功、失败、取消、超时、禁用和退出路径都保留可关联终态。

## 验证边界

- 自动化覆盖：组合键校验、本机持久化、旧格式、导出导入、无效导入拒绝、控制器自定义/回退/失败、录音中拒绝修改、禁用与退出时的匹配关闭。
- 真机覆盖：RC003 按住采音与 Typeless 翻译模式的开始、结束、连续会话、快速按放、断连恢复和第一次文字上屏。模拟器、单元测试和构建不能替代真实文字结果。
