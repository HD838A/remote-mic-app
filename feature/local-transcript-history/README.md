# 本地语音转写记录

## 为什么开发

用户完成语音输入后，转写文字通常只存在于目标应用中，无线麦自身无法按时间回看。该功能提供一个默认关闭、完全本地的独立记录入口，方便用户按应用和日期查看自己实际输入过的文字。

## 用户功能

- 在侧边栏“统计”下方打开“回眸”（英文为 “Reflections”），并开启“记录回眸”（英文为 “Save to Reflections”）。
- 新完成的语音输入会按目标 App 和语音结束时的本机日期分组。
- 页面默认按时间倒序显示全部 App 的记录；顶部应用栏固定显示“全部应用”，其余 App 按最近使用排序并支持单行横向浏览或在页面内展开为自适应网格，点击后只查看该 App 的时间线。
- 日期分组默认展开最新一天，用户可以逐日展开或折叠；每条记录始终显示来源 App 的真实图标和名称。
- 页头在标题右侧显示可换行的本地隐私说明，保存开关固定在最右侧；页面底部不重复显示同一说明。
- 支持复制单条记录、删除单条记录、删除当前 App 的全部记录和删除全部记录。
- 可独立开启“暂存原始语音（4小时）”；录音以本机 `.m4a` 保存，可在记录中播放，并在语音结束 4 小时后自动删除。该开关默认关闭。
- 关闭开关只停止保存新记录，不删除已有记录。

## 范围与非目标

本功能只接入 Mac 已有的公共语音开始/结束和解码后 PCM，不修改蓝牙、ATVV、Fn 注入、iOS、Watch 或网页协议。它不提供云同步、全文搜索、智能后处理、跨设备同步或服务端备份。可授权的只读 MCP 由独立功能档案 [`本地 Agent 访问集成`](../sayall-mcp-integration/) 记录，并且只返回非空转写文字，不读取音频。

## 关键设计与开发过程

语音开始时通过 Accessibility 保存安全可编辑目标的最小快照；组合动作刚切换 App、输入焦点尚未稳定时，会在 1.25 秒内短时重试，不阻塞音频。语音结束后最多等待 8 秒，优先读取原选区处的连续新增或替换；第三方输入法短暂重组邻近文字时继续等待最终稳定结果，不再立即丢弃整次会话。若最终仍无法安全读取文字，回眸会保留一条“未能读取转写文字”的会话记录，不会保存输入框全文。密码、Token、搜索框、地址栏和设置类输入区域不会保存文字。

开启音频暂存时，同一会话的 16 kHz 单声道 PCM 会编码为 32 kbps AAC `.m4a`，再与文字记录通过同一个 session ID 关联。音频独立保存在：

`~/Library/Application Support/RemoteMic/TranscriptAudio/v1/<session-id>.m4a`

目录权限为 `0700`、音频文件为 `0600`；文件的过期时间严格按语音结束时间加 4 小时计算。App 启动、进入回眸页和到达过期时刻都会清理，删除记录时关联音频立即删除，而文字记录仍沿用可恢复删除。

数据使用版本化 JSON，路径为：

`~/Library/Application Support/RemoteMic/Transcripts/v1/<app-key>/<YYYY-MM-DD>.json`

目录权限为 `0700`，正文文件权限为 `0600`，原子写入。删除单条记录会先把原日期文件移到 macOS 废纸篓再重写剩余内容；按 App 或全部删除会把对应目录移到废纸篓。

详细研究和实施计划保存在私有产品资料库，不复制到公开源码仓库。

## 涉及文件

- `Sources/RemoteMic/AppSettings.swift`：保存默认关闭的本地记录开关。
- `Sources/RemoteMic/TranscriptCaptureCoordinator.swift`：安全输入框快照、文字稳定等待和本次差异提取。
- `Sources/RemoteMic/TranscriptArchiveStore.swift`：按 App/日期落盘、加载和可恢复删除。
- `Sources/RemoteMic/VoiceAudioArchiveStore.swift`：AAC `.m4a` 写入、播放、权限和 4 小时清理。
- `Sources/RemoteMic/VoiceHistorySessionCoordinator.swift`：把文字、音频和回退状态合并为唯一会话记录。
- `Sources/RemoteMic/BridgeAppModel.swift`：接入公共语音生命周期并向界面发布记录。
- `Sources/RemoteMic/TranscriptHistorySection.swift`：顶部可展开应用栏、可折叠日期时间线、真实 App 图标、复制和删除界面。
- `Sources/RemoteMic/SettingsView.swift`：在唯一侧边栏顺序中把“回眸”固定放在“统计”下方，并提供独立页面；页头依次放置标题、可换行隐私说明和最右侧保存开关。
- `Resources/*/Localizable.strings`：中英文界面文字。
- `Tests/RemoteMicTests/Transcript*Tests.swift`：存储、捕获和 Feature Flag 自动化。

## 隐私与兼容边界

默认只保存本次新增转写文字、开始/结束时间、目标 App 名称、Bundle ID、输入来源和本地日期元数据。只有用户另行开启音频暂存时才保存本次原始语音，且最多保留 4 小时。不会保存输入框全文、前后文、窗口标题、文档名、URL、设备标识或 API Key，也不会上传。功能不依赖私有 AI 组件；未安装私有组件或没有 API Key 时仍可运行。

Accessibility 不提供统一的跨应用“语音结果事件”，因此当前实现只覆盖能够读取文本值和选区的安全标准输入区域。使用自绘编辑器、Web contenteditable、跨进程输入面板，或文字出现前就切换目标时可能放弃保存，避免误记录其他内容。
