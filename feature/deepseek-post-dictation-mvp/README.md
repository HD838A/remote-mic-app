- 状态：等待人工验收
- 平台：macOS
- 功能开关：`AI 整理（实验）`，默认关闭
- 实现提交：`b433eac feat: add DeepSeek post-dictation MVP`
- 对应公开任务：根目录 [`TODO.md`](../../TODO.md) 中“实现无线麦独立语音输入 V1”和“提升专业术语、缩写和字母数字编号的语音识别准确性”

## 为什么开发

现有 Remote Mic 已经可以把 RC003、附近 iPhone 和网页遥控器的声音送入虚拟麦克风，再由豆包输入法实时识别并写入当前输入框。但输入法原始结果仍可能包含口头禅、重复、改口、标点问题，以及分支名、路径、系统名和代码标识符等编程术语错误。

长期方案是由 App 自己管理流式 ASR、稳定片段和完整文本 revision。该方案涉及更多接口和状态机。在长期链路完成前，本功能先验证一个较小的过渡闭环：继续让豆包输入法负责实时上屏，只在语音结束且本次文字稳定后调用一次 DeepSeek，确认目标没有变化后只替换本次语音文字。

这个 MVP 主要验证：

- DeepSeek 对真实口述文字的整理质量、延迟和费用是否可接受；
- 能否可靠识别“本次语音新增或替换的文字范围”；
- 用户切换 App、移动焦点或继续输入时，迟到结果能否安全取消；
- 编程术语及 `/`、`-`、`_`、`.` 等口述符号能否被克制地恢复；
- 失败时能否始终保留豆包原文。

## 功能介绍

完整链路：

```text
RC003 / iPhone / 网页遥控器
        ↓
现有虚拟麦克风
        ↓
豆包输入法实时上屏
        ↓
语音结束后等待本次文字稳定
        ↓
DeepSeek 单次、非流式整理
        ↓
重新校验 App、焦点、全文和本次范围
        ↓
只替换本次语音文字
```

用户可以在设置的独立“AI 整理”页面：

- 开启或关闭实验功能；
- 把 DeepSeek API Key 保存到 macOS Keychain；
- 测试 DeepSeek 连接；
- 手工添加系统名、项目名、分支名、命令、路径和标识符及其口述别名；
- 查看等待、整理、完成、跳过或失败状态；
- 在精确写入失败但已取得整理结果时，主动点击“复制整理结果”。

当真实语音整理进入 DeepSeek 请求阶段时，App 会在当前屏幕 Dock 上方显示一个全局置顶 HUD：

- 只在实际后整理请求期间出现，不为等待文字、稳定检测或“测试连接”显示；
- 使用 App Logo 的暖橙和星光黄作为处理中主题色；
- 不激活 Remote Mic、不接收鼠标事件、不显示音频电平或可点击控件；
- 请求完成、跳过、失败或取消后立即淡出；
- 设置页继续保留最近状态和错误原因，用于配置与排障。

## 本次范围

本版实现：

- 每次语音最多一次 `deepseek-v4-flash` 非流式请求；
- 语音开始时锁定前台 App、焦点文本元素、原始文字和选区；
- 插入点前后各最多 100 个 Swift `Character` 的只读上下文；
- 基于原始光标或选区计算本次连续变化范围；
- 约 900ms 稳定检测和约 8 秒总超时；
- 目标、焦点、完整文字和本次范围的替换前二次校验；
- 编程术语表、口述别名和受保护文本；
- 数字、版本号、否定和受保护术语的本地确定性检查；
- API、解析、焦点、范围或写入失败时保留豆包原文；
- 默认关闭以及中途关闭、新会话取消旧请求。
- DeepSeek 实际整理期间跨 App 显示底部居中全局 HUD。

本版不实现：

- 豆包流式语音 API 或其他 ASR；
- 音频上传给 DeepSeek；
- 流式 LLM、录音中的局部整理或多请求队列；
- 自动扫描 Git、项目目录、终端历史或剪贴板；
- 自动学习用户纠错；
- 自动列表格式。首期 `automaticList` 固定为 `false`；
- 自动切换或启动豆包输入法；
- 对所有富文本、终端和网页编辑器作兼容承诺。

## 数据与隐私边界

发送给 DeepSeek：

- 目标 App 名称和 Bundle ID；
- 语音开始时插入点前后各最多 100 个可见字符；
- 本次豆包新增或替换的文字；
- 用户明确启用的编程术语；
- 固定关闭自动列表的格式策略。

不发送：

- 音频；
- 输入框全文；
- 窗口标题、文档名、网页 URL 或屏幕内容；
- 剪贴板、项目文件、Git 分支、终端历史或语音历史。

API Key 只保存在 macOS Keychain，不进入 `UserDefaults`、术语 JSON、日志、配置导出或源码。运行日志只记录 Prompt 版本、字符数量、耗时、状态码或错误类型，不记录 App 名称、上下文、原文或整理结果。

## 当前验证状态

已经完成：

- 159 项自动化测试通过；
- Release 构建通过；
- App 包结构和本地签名校验通过；
- 使用真实 DeepSeek API 验证 `deepseek-v4-flash` 可直接调用；拼写 `deepseek-v4-fash` 会被服务端拒绝；
- 真实 API 语料验证 `feat 斜杠 voice one 横杠 test` 可恢复为 `feat/voice1-test`；
- `automaticList = false` 时没有自动列表化；
- 普通语义中的“横杠”没有被错误替换为符号；
- 提交前敏感信息扫描未发现 API Key。

仍需人工验收：

- 豆包输入法真实上屏和稳定等待；
- TextEdit、Codex、浏览器、聊天工具等不同 AX 文本控件；
- RC003、附近 iPhone 和网页遥控器完整输入链路；
- 用户快速切换焦点、继续输入、开始新会话和中途关闭功能；
- 设置页面实际窗口尺寸、滚动和全部入口。
- 全局 HUD 在普通桌面、全屏 App、多显示器和不同 Dock 位置下的真实显示边界。
