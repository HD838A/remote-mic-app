# 遥控器鼠标移动产品规范

## 适用范围

本规范约束 macOS 上通过遥控器普通按键移动系统光标的行为。Windows 使用同一语义，由独立实现承载。

验证方法和通过/失败证据由 [`Testing/MousePointerActions.md`](../../Testing/MousePointerActions.md) 定义。本规范只定义产品行为。

## 用户问题与目标

用户希望把遥控器当作简易鼠标：把方向键配置为“↑ 鼠标向上 / ↓ 鼠标向下 / ← 鼠标向左 / → 鼠标向右”，按住时连续移动光标，松手立即停止；移动后用 OK 直接单击目标。目标是不需要触控板也能完成演示、客厅操作和躺姿操作。

产品不引入独立的“鼠标模式”开关。每个按键绑定一个鼠标移动动作，并复用“按住时连续执行”配置；OK 单击遵循同一用户可观察语义。Windows 由独立仓库实现和验收，本 PR 不修改 Windows。

## 动作

新增“鼠标”分类，排在“打开 App”后面，包含四个动作：

| 动作 | raw value | 行为 |
| --- | --- | --- |
| ↑ 鼠标向上 | `mouseMoveUp` | 光标向上移动 |
| ↓ 鼠标向下 | `mouseMoveDown` | 光标向下移动 |
| ← 鼠标向左 | `mouseMoveLeft` | 光标向左移动 |
| → 鼠标向右 | `mouseMoveRight` | 光标向右移动 |

- 动作可以绑定到任意普通按键的单击、双击或长按。
- 方向由动作决定，不由物理按键决定。
- 鼠标移动动作允许按住重复；其他动作能力不变。
- 鼠标移动不使用“按住执行”或“长按后按住”；这两个行为仍只支持键盘方向键。

## 距离

- 每个鼠标移动绑定可配置 `1...100`，默认 `20`。
- 单位是“点（pt）”，与 macOS 光标坐标一致；不要写成“像素”。
- 距离只影响当前绑定，不改变其他按键。
- 旧配置缺少距离时按 `20` 处理，不迁移、不报错。
- 非法距离不得写入；导入时非法值必须拒绝并保留原配置。
- 选择鼠标动作后，如果当前按键的按住行为还不是对应的“重复执行”模式，动作编辑区显示页内提示：鼠标默认只移动一次，可设置按住时连续移动。
- 提示提供“设置按住”和“保持单次”两个明确选择；前者切到按住设置并选中对应重复模式，后者只关闭提示，不修改配置。
- 不自动把用户配置改成按住重复；提示不得使用弹窗或短暂 Toast，用户处理或选择保持单次后不再反复出现。

## 单次触发与按住

| 按住行为 | 行为 |
| --- | --- |
| 未设置 / `once` | 按下执行一次固定距离移动 |
| `repeatSingle` | 按下即进入连续移动；配置双击时等双击窗口结束后开始 |
| `repeatLong` | 达到长按阈值后进入连续移动；阈值前不移动 |
| `singleHold` / `longHold` | 不可用于鼠标移动 |

- 连续移动在按下时立即开始，不等待 `350 ms` 重复启动时间。这个绕过只对鼠标移动动作生效。
- 松手立即停止，并补上最后一个节拍到松手之间的位移。
- 同时按住两个方向时，两个动作各自移动，得到两轴合成；不做归一化。
- 光标到达屏幕边界后钳制，不继续累积屏幕外位移。
- 单次按住最长 15 秒；释放后可以重新开始。
- 事件创建失败立即结束本次移动，释放前不再自动重试。
- 连续移动时每次按下/释放必须成对；任何路径不得让光标在松手后继续移动。

## 速度曲线

- 初速 = 距离 × 10 点/秒。
- 最大速度 = min(初速 × 5, 2000 点/秒)。
- `0...500 ms`：保持初速。
- `500...1200 ms`：二次缓入到最大速度。
- `>1200 ms`：保持最大速度。
- 单帧最多积分 `32 ms`，卡顿后不能一次跳很远。
- 亚像素余量保留到下一帧。

## 生命周期

以下路径必须停止所有鼠标移动并写结束日志：

- 按键释放；
- 断连、监听停止、设备移除；
- 睡眠、会话切换、App 退出；
- 辅助功能权限撤销；
- 绑定、档案、来源或前台上下文变化；
- 语音键按下；
- App 切换器开始；
- 常用语面板开始；
- 滚动或翻页动作开始；
- 显示器配置变化；
- 锁屏等一次性系统动作。

## 移动后按 OK 单击

「鼠标」分类提供一个全局开关「移动后按 OK 单击」，默认关闭。

- 最近一次遥控器鼠标移动成功后的 5 秒内，按下 OK 发送一次左键按下/抬起，光标位置不因点击改变。
- 这次 OK 在按下边沿立即消费，不等待双击或长按窗口；释放时不再发送第二次点击，也不执行 OK 的原绑定。
- 超过 5 秒、没有成功移动、开关关闭、应用切换器/常用语/快捷键编辑/权限不可用时，不转为单击，OK 继续执行原绑定。
- 点击注入失败时不得吞掉 OK；调用方继续执行原绑定，并记录失败日志。
- 只有成功移动才刷新窗口；到达屏幕边界没有实际位移时不刷新。
- Apple Remote 触摸点击和 Windows 独立实现按各自入口映射同一语义；Windows 的 OK 键开关默认关闭并使用 5 秒窗口，不由本文件推导其实现已完成。

## 同步与保留

- 鼠标移动距离保存在基础绑定、设备档案和完整配置备份中。
- 修改快捷键、目标 App 或其他动作参数不得丢失已有距离。
- 私有 Portable Transfer 已承载鼠标动作和距离；新宿主导出时写入距离，旧宿主遇到未知字段按仓库既有前向不兼容行为处理。
- 键位方案的鼠标动作和距离只在按键映射页编辑，键位方案页只保留概览并跳转到按键页；私有按键方案组件只负责保存和传输数据，不显示距离编辑控件。旧宿主缺少对应接口时隐藏鼠标分类，不得静默替换成其他动作。
- 含鼠标动作的配置被旧版 App 读取时，按仓库既有前向不兼容行为处理；不得声称可无损降级。

## 日志

只写会话级日志，不逐帧写：

- `MOUSE MOTION phase=config`
- `phase=start`
- `phase=progress`，每秒最多一行
- `phase=completed`，包含原因、时长、tick 数、请求位移、观察位移、峰值速度、丢弃时间和错误数

单次固定移动写 `MOUSE MOVE phase=completed`。日志不得写绝对光标坐标、用户内容或第三方 App 私有状态。

## 不在本期范围

- 鼠标左键、右键、中键和左键双击动作；
- 独立鼠标模式开关、OK 三手势、方向键双击分上下文；
- 拖拽；
- 滚轮和翻页动作的语义变化。
