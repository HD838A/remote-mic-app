# 按键映射与快捷键显示产品规范

## 适用范围

本规范约束 macOS 与 Windows 的按键映射页面、快捷键录入、快捷键预设和组合动作显示。平台可以使用不同的系统 API，但用户看到的快捷键语义和显示层级必须一致。

## 快捷键的三种文字形式

每个修饰键或特殊键必须维护完整名称、简写和图标三种形式。主键字母和数字保持原字符；方向键、功能键和特殊键也必须有稳定的完整名称。

| 完整名称 | 简写 | 图标 |
| --- | --- | --- |
| Command | Cmd | ⌘ |
| Shift | Shift | ⇧ |
| Option | Opt | ⌥ |
| Control | Ctrl | ⌃ |
| Return | Return | ⏎ |
| Delete | Del | ⌫ |
| Tab | Tab | ⇥ |
| Left | Left | ← |
| Right | Right | → |
| Up | Up | ↑ |
| Down | Down | ↓ |
| Escape | Esc | ⎋ |
| Space | Space | ␠ |

后续增加的键必须同时补齐三种形式，不得只新增一个面向用户的字符串。

## 页面显示规则

1. 快捷键按钮、已保存值、组合动作预览默认只显示图标形式，例如 `⇧⌘Z`、`⌥⌘←`。
2. 鼠标悬停在快捷键表示上时，使用 tooltip 显示完整形式，例如“Shift + Command + Z”；悬停前不得把完整名称和图标重复拼接。
3. 无障碍标签使用完整名称，顺序与图标顺序一致；无障碍朗读不受视觉缩写影响。
4. 用户主动录入快捷键时，编辑状态可以显示完整名称帮助理解；保存后恢复图标显示。
5. 修饰键的显示顺序固定为 `Control → Option → Shift → Command → 主键`。该顺序只约束视觉和朗读，不改变实际按键事件顺序。

## 动作编辑器交互

- 动作编辑器打开后必须自动滚动到当前按键的设置面板；单击、双击和长按三种入口行为一致。
- 动作分类不提供“全部”可见 tab。首次打开时展示全部动作分组；用户可使用“基础按键”“系统与媒体”“自定义动作”筛选，筛选按钮必须保持足够点击面积并在窄窗口不裁切。
- 分类筛选只改变候选列表，不执行或改写当前动作。
- 组合动作属于“自定义动作”能力；只有显式注入私有 Macro Package 的构建才显示组合动作，公开构建必须隐藏而不是显示空壳入口。
- 组合动作选择项优先使用横向排列；选项较多时使用无障碍可操作的横向滚动容器，不把长名称堆成超长纵向列表。每个选项显示名称、步骤数和选中状态，名称最多显示两行。

## 遥控器图区与设备卡片

- 卡片形式或有边框的按钮必须在整个卡片或边框范围响应点击。
- 文字、图标、内部空白和边框内侧必须执行同一按钮动作。
- 遥控器设备卡的上述区域都用于选择该设备。
- 卡片内的启用、停用和重试按钮只执行自身动作；禁用时不得执行。
- 遥控器图上方不得添加任何元素。
- 启用、停用和授权重试入口必须放在页头既有遥控器卡片内。
- 遥控器卡片最多三行：型号、系统名称、连接状态与电量。
- 遥控器卡片右侧不显示对勾；选中状态使用卡片底色和边框。
- 启用、停用、重试与苹果遥控器的语音会员入口都排在第三行内（连接状态与电量的同一行），不单独占用卡片右侧一列，也不得新增第四行。
- 未启用的遥控器卡片在第三行显示“启用”，不增加说明文字。
- 已启用且授权失败或取消时，卡片第三行显示“重试”按钮。
- 苹果遥控器只有语音是会员功能：无权益时第三行同时显示“点击开通会员功能”，但启用、停用照常可用；连接、普通按键与触摸不读会员状态。
- 需要主动启用的已登记遥控器必须保留卡片，不能因服务未启动而隐藏入口。
- 准备过程不得再次触发授权；录音及尾音处理期间禁用操作按钮。
- UI 改动必须先展示界面方案，经用户确认后实现。

## 多硬件共享边界

1. 按键设置页的页头、自定义映射开关、设备选择器、滚动容器、动作编辑器、动作分类、快捷键选择器、通用提示和恢复默认必须由宿主实现一份共享组件。
2. 单款硬件适配器只提供设备能力、可配置 control ID、control ID 到通用按键的映射，以及遥控器图片、热点、连线和固定按键等硬件画布；不得复制或重新实现动作编辑区。
3. 新硬件接入必须复用同一共享设置骨架。启用和授权重试入口放在遥控器卡片内；其他硬件专属开关只能作为声明过的可选页脚内容注入，不能建立另一套页面生命周期、筛选状态或快捷键编辑器。
4. 共享骨架必须统一处理单击、双击和长按进入编辑器后的自动滚动、关闭和设备切换复位；硬件画布只发送“编辑哪个通用按键及触发方式”。

## 触摸说明

Siri Remote 按键映射页只展示可配置按键和语音键，不在页面底部重复解释触摸面手势。触摸能力通过测试手册和帮助文档说明，不占用映射页的布局空间。

## macOS 统一绑定（源码候选）

本节仅定义 macOS 统一设置；Windows 继续使用已有平台映射。生产发布前须完成
[统一按键验证](../../Testing/UnifiedButtonConfiguration.md)。

- 按键页保留实物遥控器、两侧按键卡片、连接曲线与三手势格子；在现有自定义动作区增加组合动作
  搜索列表，使用横向选项显示名称、步骤数和选中态，按稳定 ID 明确绑定。快捷键、打开 App 和聚焦继续就地设置。
- 组合动作页只负责创建、命名、编排、学习输入框、测试、保存和本机导入导出；
  显示绑定和嵌套引用，绑定引用跳转按键页。创建后返回原按键，由用户明确选择，不自动绑定。
- 组合动作的新建、复制和编辑使用页面内“基本设置 → 编排步骤 → 测试与保存”，编辑时隐藏库列表。
  步骤顺序位于左侧，右侧只编辑选中步骤；取消不覆盖已有动作，最后保存有效草稿，不以测试为保存门槛。
- 键位方案页保留摘要及“切换设置 → 设置按键 → 确认保存”流程，继续管理手动/自动模式、默认方案、
  前台 App 规则与导入导出/恢复。摘要只读，“编辑键位”进入本页的设置按键步骤。
- Siri Remote 两个型号和 Chromecast 使用各自真实图片、热点与物理键集合；Chromecast 的系统占用键
  读取按键页同一策略，默认锁定左、右、确定，逐键放开后才能选择。切换设备不删除原设备方案内容。
- 正在编辑与当前生效的方案分别显示。前台 App 切换只改变生效方案，不改变编辑对象。
- 通用 10 键专用方案可以分别配置和执行单击、双击和长按。每一种触发方式都独立解析：缺少该条目时继承基础按键的同一触发方式；明确动作和“不执行”都是覆盖。
  专用方案生效时不再整体停用双击和长按，保留旧数据并按当前触发方式解析。
  每次完整点击即时执行，快速两次执行两次；按住连发仍按最终动作能力判断。
  展示、手势判定和执行使用同一解析结果。失效宏、缺失快捷键、权限拒绝、超时、执行失败均停止，
  不执行基础层替代动作。
- 场景只按前台 App 的 Bundle ID 精确匹配。同设备同 App 只有一条有效规则；未配置 App 使用默认方案；
  暂时未知的前台 App 沿用当前方案，避免抖动。方案仅覆盖普通可配置按键。
- 生效方案改变时取消未完成的普通手势、按住和连发；已经开始的组合动作使用启动时的定义，
  后续触发读取最新定义。语音键按下/释放、首字和尾音生命周期不经过宏或手势窗口。
- 编辑动作会影响全部引用；删除前在页面内显示引用范围，删除后引用保留并显示不可用。
- 宿主管理基础绑定，免费 Package 管理动作库和执行，付费 Package 管理方案覆盖。
  新源码接口停止保存免费模块的物理绑定；旧 Package 保持原兼容接口。
- 首次迁移先保存原宿主配置与设备映射，再将旧免费宏绑定写入基础层，保留原快捷键/App 参数、
  原免费绑定文件和方案覆盖。迁移幂等；恢复某台设备默认不影响其他设备。
- 宿主配置统一导出格式为 2，继续读取格式 1；旧版明确拒绝格式 2。
  无效的明确绑定导入为“不执行”并报告拒绝项，不能暴露下层旧动作。

## macOS 本机脚本步骤

- 免费组合动作提供“运行 Shell 脚本”和“运行 AppleScript”；可以内联编辑、授权、单步测试、保存，
  或由用户明确选择 UTF-8 文本脚本导入初始内容。保存后不跟随外部文件变化。
- 高级脚本默认关闭。开启后逐脚本授权；授权绑定步骤、语言、解释器和源码，修改后须重新授权。
  导入本机动作撤销本机授权；授权本身不导出。社区/官方预设不接受脚本。
- Shell 仅允许 `/bin/sh`、`/bin/zsh`，不加载登录配置，工作目录为用户主目录；
  AppleScript 使用系统 `/usr/bin/osascript`。脚本按当前用户的权限执行，并继续遵守第三方 App 私有数据访问禁令。
- 源码最多 64 KiB；默认单步超时 60 秒，并受整组超时约束。异步执行，不阻塞按键或音频线程；
  非零退出、未授权、超时和取消停止后续步骤；运行中拒绝重复启动。
- 取消/超时终止所属进程组；关闭高级脚本取消当前运行。单步测试显示退出状态和最多 64 KiB 输出，
  输出只存在页面内存；日志只记录操作号、阶段、终态和耗时，不记录源码、参数正文或原始输出。
- 脚本使用 `0.4-draft` 动作 Schema；继续读取 0.1/0.2/0.3，旧版不能将脚本作为其他动作执行。
  本期不增加语音脚本钩子、Webhook、社区执行代码或条件循环。

## macOS 完整 App 配置备份

- 设置页“导出配置”只打开系统保存窗口，不要求用户选择内容类别。
- 完整备份包含全部遥控器配置与基础绑定、全部键位方案及其选择和 App 规则、全部组合动作版本、App 配置、快捷键库、常用语和用户偏好。未引用的配置也必须保留。
- 完整备份使用 `sayall-macos-configuration` 格式和 `.sayall` 扩展名。产品为 `SayAll`，平台为 `macOS`；记录来源版本、Build 和所需读取器。此格式与社区分享文件分开，旧读取器必须拒绝。
- 根据文件内容选择导入入口：完整备份和旧 `personalBackup` 进入设置页；单个键位方案进入键位方案页。不得仅凭 `.sayall` 扩展名分类。
- 完整备份恢复前校验全部内容，并明确提示将替换当前用户配置。取消不写入。私有存储与宿主配置沿用事务恢复；无对应组件时拒绝，不能静默丢弃。
- 账号、凭据、会员权益、系统权限、系统登录项注册、向导进度和验证证据、配对身份、统计、回眸记录和原始录音不属于配置迁移。脚本授权不导出，恢复时撤销旧授权。输入框指纹不迁移，保留配置引用并要求重新确认。
- 公开构建只恢复其具有的配置能力；不得复制私有实现。备份不授予会员权益。

## 普通按键的手势时间与按住行为

- 每种遥控器型号独立保存双击等待时间和长按判定时间。同型号遥控器的全部普通按键共用一份时间。
  默认分别为 `300 ms` 和 `550 ms`。
  双击范围为 `150–500 ms`；长按范围为 `300–1000 ms`；步长均为 `50 ms`。
- 按键页底部只显示一个“按键手势”模块。模块顶部提供“学习你的单击、双击和长按”。
  用户使用同一个普通按键依次完成单击、双击和长按。学习期间不执行该遥控器的普通按键动作。
  学习结果填入双击和长按滑块，但不自动生效。用户可以继续调整；点击“保存”后，新时间从下一次普通按键按下生效。
  学习只接受当前实体遥控器的按下和松开边沿。语音键、手机、手表和网页入口不进入学习。
  无可靠按下和松开边沿时显示不可学习，仍允许手动调整有效范围内的滑块。
- 双击窗口从第一次松键起算；长按阈值从按下起算。首次按下固定动作、模式和时间。
  时间修改从下一次按下生效。映射或模式修改取消当前交互。
- 每个普通按键显示四个配置入口：单击、双击、长按和按住。
  单击、双击和长按分别配置一次性动作。“按住”位于按键名称右侧，单独配置持续行为。
  按键卡片保持原宽度和原高度。底部仍只有单击、双击和长按三列。
- 旧配置缺少按住字段时保持未设置，不改变现有行为。新建或首次修改按键动作时，只有单击动作支持重复且没有长按动作，才默认选择“重复单击”。
  用户只能选择“重复单击”或“重复长按”之一，也可以清除按住配置；清除后不得再次自动恢复默认值。
  默认值只会从“未设置”升级一次。已经保存的选择或从基础按键继承的选择不得被改写：
  新增长按动作等冲突只在运行期降级为不执行重复，移除冲突后按原选择自动恢复。
  卡片使用“按住：重复单击”或“按住：重复长按”显示当前选择。
  独立编辑区使用紧凑的两列单选卡片。动作摘要显示在对应卡片内，不另占一行。
  “重复长按”在长按阈值处首次执行长按动作，之后重复长按动作。
  “重复单击”无双击时按下先执行一次，`350 ms` 后重复；有双击时持续按住双击窗口后首次执行，随后重复。
  第一次短按松键仍等待双击窗口；第二击持续按住不启动重复，松键执行双击。
- 重复间隔首版不开放调整：返回键为 `50 ms`，其他普通键为 `100 ms`。
  可重复动作沿用动作能力白名单。重复单击与长按动作互斥。不透明私有绑定不开放重复。
  不可用模式保留选择、显示原因并停用该键，不自动执行其他模式。
- 旧软件连发迁移为明确的重复单击，并保留原物理键范围和启动时间。
  原生左右键透传、自身 App 防护和旧私有接管保留原语义。
  迁移标记仅保留旧路径范围；用户明确选择模式后使用新模式。
  旧手机来源没有隐式连发。新建空白方案继承基础按键行为；旧方案继续继承旧行为。
- 完整备份包含按型号保存的时序和每台设备的按住行为。键位方案包含按住目标，导入不修改本机时序。
  新备份和本机方案写格式 2、读格式 1/2；旧版本必须拒绝格式 2。
  用户选择保存 `repeatSingle` 或 `repeatLong`；内部 `once` 只标记用户已清除按住配置，不作为第三个可选模式。
  旧候选值 `holdSingle` 读取后迁移为未设置。缺失字段保持旧行为。
  共享方案必须声明按住行为能力；旧组件不支持时显示不可用。
- 松键、断连、休眠、退出、权限撤销、来源、方案或前台目标切换时停止重复。
- 语音键不进入此状态机。语音按下、释放保持即时。播放器快进效果必须另做真实 App 验收。
