# 按键映射与快捷键显示产品规范

## 适用范围

本规范约束 macOS 与 Windows 的按键映射页面、快捷键录入、快捷键预设和组合动作显示。平台可以使用不同的系统 API，但用户看到的快捷键语义和显示层级必须一致。

## 快捷键的三种文字形式

每个修饰键或特殊键必须维护完整名称、简写和图标三种形式。主键字母和数字保持原字符；方向键、功能键和特殊键也必须有稳定的完整名称。

| 完整名称 | 简写 | 图标 |
| --- | --- | --- |
| Command | Cmd | ⌘ |
| Shift | Shift | ⇧ |
| Option | Opt | ⌥ |
| Control | Ctrl | ⌃ |
| Return | Return | ⏎ |
| Delete | Del | ⌫ |
| Tab | Tab | ⇥ |
| Left | Left | ← |
| Right | Right | → |
| Up | Up | ↑ |
| Down | Down | ↓ |
| Escape | Esc | ⎋ |
| Space | Space | ␠ |

后续增加的键必须同时补齐三种形式，不得只新增一个面向用户的字符串。

## 页面显示规则

1. 快捷键按钮、已保存值、组合动作预览默认只显示图标形式，例如 `⇧⌘Z`、`⌥⌘←`。
2. 鼠标悬停在快捷键表示上时，使用 tooltip 显示完整形式，例如“Shift + Command + Z”；悬停前不得把完整名称和图标重复拼接。
3. 无障碍标签使用完整名称，顺序与图标顺序一致；无障碍朗读不受视觉缩写影响。
4. 用户主动录入快捷键时，编辑状态可以显示完整名称帮助理解；保存后恢复图标显示。
5. 修饰键的显示顺序固定为 `Control → Option → Shift → Command → 主键`。该顺序只约束视觉和朗读，不改变实际按键事件顺序。

## 动作编辑器交互

- 动作编辑器打开后必须自动滚动到当前按键的设置面板；单击、双击和长按三种入口行为一致。
- 动作分类不提供“全部”可见 tab。首次打开时展示全部动作分组；用户可使用“基础按键”“系统与媒体”“自定义动作”筛选，筛选按钮必须保持足够点击面积并在窄窗口不裁切。
- 分类筛选只改变候选列表，不执行或改写当前动作。
- 组合动作属于“自定义动作”能力；只有显式注入私有 Macro Package 的构建才显示组合动作，公开构建必须隐藏而不是显示空壳入口。

## 触摸说明

Siri Remote 按键映射页只展示可配置按键和语音键，不在页面底部重复解释触摸面手势。触摸能力通过测试手册和帮助文档说明，不占用映射页的布局空间。
