# 电脑麦克风直通产品规范

## 用户目标

让只支持选择一个麦克风的语音工具始终监听虚拟麦克风，同时允许用户在键盘触发时使用 USB 或 Mac 物理麦克风，并继续使用遥控器麦克风。

## 产品行为

- 功能默认关闭，由用户在“连接与语音”页面明确开启并选择一个物理输入设备。
- 开启后保持等待，不读取物理麦克风。第一次按右 Command 启动键盘语音输入时才把物理麦克风送入当前语音输出设备；再次按右 Command 结束输入时立即停止并释放物理麦克风。
- 遥控器原有音频路径保持不变；按住遥控器语音键时不启动物理麦克风。
- 物理输入和语音输出不得是同一设备，`MiRemoteV 2ch` 与 `BlackHole 2ch` 不作为物理麦克风候选。
- 结束键盘语音、关闭、退出、设备不可用或权限被拒绝时立即停止物理麦克风采集，并显示可操作状态。
- 不上传、不保存、不转写物理麦克风音频；日志不得记录音频内容或设备 UID。
- 物理麦克风直通不得改变遥控器语音键的按下/释放生命周期，不得延迟或截断遥控器音频。

## 权限与恢复

- 首次开启时使用 macOS 标准麦克风权限。
- 设备插拔后刷新设备列表；已选设备重新出现时可以恢复直通。
- 配置导出包含开关与设备 UID；旧配置缺少这些字段时保持关闭。

## 不做事项

- 不自动切换第三方语音工具的内部麦克风设置。
- 不提供回声消除、降噪、自动增益或多路独立音量控制。
- 不把松键后已经停止采音的小米遥控器变成持续录音设备。
