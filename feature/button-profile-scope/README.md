# 按键页的方案作用域编辑

## 状态

设计已评审（2026-10-31），待开发。

## 用户问题

键位方案现在只能在「键位方案」页面里编辑。那套编辑器比按键页弱：没有组合动作搜索、没有快捷键录制、没有打开 App 的那套动作面板。同一个按键在两个页面能做的事不一样，用户要先记住“改单个键去哪、改方案去哪”。

按键页本身已经具备按方案读写的能力，缺的是把它显性化：用户不知道自己在改哪一层，也没有入口从方案页跳过来。

## 用户能看到什么

- 按键页标题下多一条**作用域条**：`正在编辑 [基础映射] [方案 A] [方案 B]`，右端显示 `当前生效：…`。
- 进入方案作用域后：
  - 10 个普通按键之外的控制项（语音键、播放暂停等）整卡置灰、不可点，悬停说明「键位方案只支持 10 个普通按键」。
  - 未覆盖的按键显示基础映射里的动作，用灰色标注「继承」；改过之后卡片出现「按住 · 重复 →」这类摘要。
  - 「按键手势」整块置灰，说明「本型号设置，方案不覆盖」。
- 基础映射作用域下，作用域条右端出现「保存为键位方案」。
- 键位方案页的按键区改成只读摘要，每行一个「去编辑」，底部主按钮「在按键页编辑」。

## 本次做什么

1. **挂载作用域条**。`SettingsView.swift:1983` 已有 `mappingProfileSelector`（基础映射 + 各方案 + 当前生效），目前只定义未挂载。挂到按键页标题与遥控器图区之间。
2. **确认读写分流生效**。`mappingConfiguration(for:trigger:)`、`saveMappingBinding`、`mappingHoldMode`、`setMappingHoldMode` 已经按 `editingMappingProfileID` 分流，本次只补 UI 命中，不重写数据层。
3. **10 键置灰**。用私有包新增的 `supportsProfileButton(_:)` 判定；非 10 键整卡 `opacity 0.4`、禁用点击、移出 Tab 顺序，悬停与无障碍标签统一说明原因。
4. **继承态展示**。方案作用域下，未覆盖的按键显示基础动作并标注「继承」；写入后显示为已覆盖，并提供「恢复继承」。
5. **保存为键位方案**。入口放在作用域条右端（不占标题行、不占右上角遥控器卡片位置）。弹窗包含名称、`保存后立即切换`、可选自动应用；写入 10 键当前动作与按住，任一步失败整笔回滚。
6. **默认方案只读**。用私有包的 `isButtonProfileEditable(profile:)` 判定，默认方案作用域下隐藏或禁用编辑。
7. **会员门禁**。`mappingProfiles(device:)` 在无权限时已返回空数组，作用域条只显示基础映射；「保存为键位方案」置灰并弹会员引导。
8. **适配层透传**。`MacroFeatureIntegration` 增加 `supportsProfileButton` 与 `isProfileEditable(profile:)` 两个转发，供 `SettingsView` 使用；两者都要求私有组件达到对应版本，缺失时按“不支持”降级。

## 本次不做什么

- 不做「另存为」。复制方案只在键位方案页的「复制」按钮做。
- 不改识别时间的归属：双击等待与长按判定仍按遥控器型号保存，不写入方案。
- 不改方案页的导入导出、快照与市场流程。
- 不改方案内容的文件格式。

## 数据与边界

| 现象 | 来源 |
| --- | --- |
| 当前编辑哪一层 | `editingMappingProfileID`（nil = 基础映射） |
| 方案是否可写 | 私有包 `isButtonProfileEditable(profile:)` |
| 10 键白名单 | 私有包 `supportsProfileButton(_:)` |
| 是否继承 | 该 `(button, trigger)` 在方案里没有绑定 |
| 按住的显式/继承 | 私有包 `holdMode(profile:button:)` 返回 nil 为继承 |
| 会员 | `buttonProfilesAccessDecision`，无权限时方案列表为空 |

## 验收

- 自动化：作用域切换后绑定与按住只落在对应层；10 键之外写入被拒绝；默认方案不可写；基础作用域不受影响。
- 人工：Siri Remote 与 Chromecast 两种画布都要验证置灰与继承显示；会员未开通、到期、续费三态；从方案页跳转后返回原页面。

## 风险

- **置灰不等于运行期禁用**。非 10 键在方案作用域下只是不可编辑，运行期仍然执行基础映射；不能顺手把按键停掉。
- **写入被静默丢弃**。私有包对非 10 键和默认方案的写入是 guard 直接返回的，所以 UI 必须先置灰或禁用，否则用户点了没反应。
- **旧组件降级**。没有对应私有组件版本的构建必须仍然可用：作用域条只显示基础映射，不出现方案编辑入口。
