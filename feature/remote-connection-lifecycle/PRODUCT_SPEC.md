# 遥控器连接生命周期与手动恢复

## 产品行为

- 连接页显示“设备”卡片，卡片上方始终提供“连接新的设备”；该入口重新运行设置向导，不依赖当前是否已有设备卡片或历史档案。下方“连接过的设备”保留已登记且当前未连接的设备及独立“连接”入口，小米有限恢复期间可“取消”。苹果未安装组件时连接入口先引导启用；已启用苹果及 Chromecast 的离线连接入口打开系统蓝牙设置，不启动永久自动重连。全部断开时默认展开列表，不设置指向同一列表的重复查看按钮；已有档案、型号、身份和映射保持不变。
- 除设备卡片内的型号或必要名称外，连接页新增区域和直接相邻文案使用“设备”，不使用“遥控器”作为泛称。点击“连接新的设备”只重新运行设置向导，不清除已有连接、按键映射、语音输出设置或其他本地配置。“连接新的设备”使用无边框平面入口行，悬停时显示浅色反馈；不使用虚线框或卡中卡。
- 历史离线档案不在启动后逐台缓存盲连。启动、前台请求、系统真实恢复与用户查找可开启有界共享发现；没有新设备事件时窗口结束，不永久扫描、轮询或定时盲连。
- 每只刚就绪后断开的设备均立即进入有限恢复，不受页面选中项影响；同一设备最多三次连接且总计不超过 60 秒，退避、扫描与握手均计入总时限。
- 自动恢复预算耗尽后暂停。重复广播、前台、睡眠恢复、蓝牙切换和发现桥重建不能重置耗尽状态。短暂 Ready 不视为故障结束；连续可用 30 秒后可开始下一恢复轮次，但十分钟内自动连接最多六次，超限仍须手动恢复。
- 用户针对离线设备点击“连接”时只启动一轮，最长 30 秒且最多一次连接握手；重复点击合并，不并行连接；操作终止后至少五秒才接受同一设备的再次手动请求。取消、失败、超时分别显示明确结果。
- 发现以已登记身份优先识别改名设备，同时保持硬件家族准入边界；每台设备只有一个连接归属，失败候选不能阻塞其他设备的发现与连接。
- 共享发现窗口为 20 秒，开始和结束查询系统已连接候选；仅缓存中存在对象不代表设备在附近。无法观察到广播或系统设备事件时不保证自动恢复，必须保留手动入口。
- 蓝牙关闭、权限不足与系统挂起时停止无效尝试并显示原因。恢复条件不能复活已耗尽预算。手动连接只作用于目标设备，不重建其他健康链路，也不改变页面设备选择。
- 不改变语音按下/释放、ATVV 音频、普通按键映射、Apple 或 Chromecast 适配器行为；正常语音排空不得被查找或取消其他设备打断。
- 苹果遥控器的“启用”和不可用后的“重试”不要求会员，连接、普通按键与触摸继续对非会员开放；会员提示不能替代或禁用这些入口。语音仍沿用既有权益与系统组件要求。
- 连接页左侧新增 Siri Remote 组件安装模块：仅在系统 helper 或 LaunchDaemon 缺失时显示，安装请求一次管理员授权；安装成功后整个模块隐藏。模块不修改遥控器卡片、按键映射、语音设置或其他页面；组件级卸载不在本次范围，记录在 `TODO.md`。
- 等待与暂停阶段没有周期连接日志；发现只记录窗口起止、有限候选汇总和操作终态，不逐广播输出；诊断不包含设备标识、设备名或用户内容。

## 页面与交付边界

- 已确认 HTML 设计见 [连接新的设备入口](design/connect-new-device.html) 与 [统一遥控器卡片](design/cards.html)；中英文、浅深色和最小生产窗口 1067 × 760 都须检查。
- 本轮不增加忘记设备、导出映射或自动连接开关。
- 自动化、生产 UI 截图和真实 RC001/RC003 首次语音、断连、睡眠、多设备矩阵分别记录；真实设备结果仍标记为候选；用户于 2026-11-16 授权自动化通过后合入，并由用户随后完成真机测试。

## 统一遥控器卡片

- 按键页顶部、连接页当前设备及“连接过的设备”使用同一生产卡片组件，固定 `232 × 72pt`、三行：型号通用名、蓝牙名称、整体状态及有效电池/充电数据。型号不使用 RC003/A2540 等内部代号，未知型号明确显示未识别。
- 历史设备保留上次有效蓝牙名称，名称缓存与身份、按键映射分离；未读到名称或设备离线不能清空缓存。序列号不加入新显示缓存；旧档案没有名称时明确显示系统名称未知。
- 苹果未安装独立 PKG 组件、未启用或需用户操作时，右上显示“启用”。安装完成且启用后隐藏该入口，不显示“已启用”。启用不要求会员；缺组件时提供官方安装包入口，安装由用户完成。
- 只有非会员苹果卡片右下显示“开通会员”。历史设备的“连接”位于最右下，会员按钮排在它左侧。其他遥控器不显示启用/会员按钮，不新增开关。
- 第三行的“已连接”是本地整体可用状态：只有当前应当可用的按键及已授权语音链路确认可用才显示绿色“已连接”。蓝牙 Ready 本身不能覆盖 HID 权限、设备打开/读取或语音故障。
- 确认过程中显示“检查中”或“状态确认中”；已确认故障显示“按键异常”“语音异常”或两项均失败的“设备异常”。没有可观察信号时显示“状态确认中”，不伪报成功；状态展示不新增硬件轮询、自动安装或重试循环。既有连接预算保持不变。
- 卡片详情文案以已确认的 [设计稿](design/cards.html) 为准；不得增加设计稿之外的诊断限定语。第三方结果边界保留在产品规范、日志和帮助中，不写入状态详情。该详情用于卡片的辅助功能标签，不作为连接页的独立说明行。
- 连接页当前设备下方恢复三行本地状态：设备连接状态、语音链路状态、语音键映射状态。卡片本身继续显示整体可用状态；两者不互相替代。
- 同一台小米遥控器若因 HID 与蓝牙分别登记而留下互补档案，且该型号只有这一对、两侧都在线，应合并为一条。保留 HID 档案的按键监视器、选中状态和实际执行映射，补入蓝牙标识、连接状态和名称。不同型号或存在多组同型号候选时不得合并。
- 新遥控器只在型号已识别且与当前选中档案同型号时继承完整映射；不同型号使用默认映射。创建时型号未知的小米档案先使用默认映射，识别后再按此规则决定是否继承。
- 非会员苹果语音未开通属于权益限制，不计为故障；普通按键仍须正常。状态仅覆盖本地可观察的链路和权限，不声称第三方语音工具已收音或文字已上屏。
- 电池只显示当前连接且有效的读数或明确充电/外接供电信号；离线不显示旧百分比。当前 Chromecast 适配不提供电量，隐藏该项。充电/供电用闪电叠加电池图标；不增加“语音就绪”文字。
- 用户确认的自包含 HTML 原型见 [设计稿](design/cards.html)。按用户 2026-11-16 在本会话的明确要求，将 HTML 源文件纳入仓库；图片与视频继续只保留外部证据索引。
