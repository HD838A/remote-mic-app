# 键位方案验证摘要

- 自动化：私有 Swift Package 完整 `swift test`、`swift build`；公开宿主注入私有模块后的完整测试和构建。
- UI：组合动作与键位方案独立侧边栏入口；方案整行可点击，状态文字单行显示且窄空间降级为带辅助说明的图标，不使用无说明的 Radio 或星标；名称与输入框同排并移除“格式”装饰；摘要和最终确认页完整预览全部按键与快捷键；新建/编辑使用三步页面内向导；每步 Return 主操作、快捷键局部取消；本地化、中文最小 12pt、分类动作网格、无长下拉/Sheet/Popover；系统 App 选择器除外。
- 语言与空状态：App 卡片只显示图标和名称，页面不显示内部 App 标识或自动切换实现术语；方案为空时，内容区中央有大号主创建按钮。
- 草稿：步骤切换保持未保存内容，取消不改变已保存方案，最后保存一次性提交名称、使用方式、App 规则和全部绑定。
- 格式：`button-profiles.json` 公开 v1 round-trip、未发布旧文件隔离和未知未来格式安全拒绝。
- 路由：实体按键通知键位方案图片；仅第二步只选键不执行，摘要页、其他步骤和离开页面恢复普通执行；Left/Right 有方案单击绑定时先执行方案，无绑定时保留原生方向键连发。
- 动作：禁用、沿用普通映射、基础按键、系统与媒体、已保存/现场录入快捷键、预置/自定义 App 和组合动作的持久化与执行。
- 表单与模式：名称 Return 前进；自动规则暂停提示、恢复入口、目标 App 命中、未配置 App 和无线麦前台默认回退；锁屏/未知前台保持当前；自动状态下当前方案不能误触发手动覆盖。
- 快捷键执行：新录入和旧数据中的方向键忽略展示层伪 Fn，非方向功能键继续保留 Fn；单快捷键同步调用宿主注入器，方向键带扩展键标志，失败不会只记录路由成功。
- 用户验收：2026-08-18 真实 Chrome 与实体遥控器已确认 `Command + Option + 左/右箭头` 可以切换标签页；修改注入链路后必须重新验收。
- 人工：真实遥控器、双设备、Codex/Claude/cmux/网易云前后台、锁屏、权限撤销、稳定语音和最小窗口。
- 失败日志必须区分前台 App 事件、方案解析、绑定解析、动作开始和用户可见结果，不能把监听到事件等同于功能成功。

完整步骤见 [Testing/ButtonProfiles.md](../../Testing/ButtonProfiles.md)。
