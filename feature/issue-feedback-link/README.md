# 问题反馈入口

## 为什么开发

用户需要从 Mac App 直接进入统一的问题反馈页面，避免复制链接、获取动态口令或进行额外登录。

## 用户功能

“关于”页面提供“问题反馈”。点击后由默认浏览器打开 SayAll 工作台，并自动获得最低权限访问，只显示公开排行榜及允许的投票、反馈能力。旧状态栏入口已移除，避免重复入口挤占菜单。

## 范围与非目标

- 本功能只负责打开浏览器，不在 Mac App 内嵌网页。
- 不接入 App Attest、Mac 账号体系或设备注册。
- 不传递用户账号、设备 ID、Token、动态口令或 App 内数据。
- 不提供管理看板、内部规划或数据源修改权限。

## 隐私与兼容边界

入口地址是公开固定地址，知道地址的人也能获得相同的最低权限。权限隔离由 SayAll 工作台服务端执行；Mac App 不能提升访问身份。

浏览器打开入口后，服务端会建立有效期 7 天的匿名 guest Cookie。此后由浏览器按 Web 常规机制发送 Cookie；服务端和其网络基础设施仍可能处理常规 IP 地址、User-Agent 以及该域名下已有的 Cookie。Mac App 自身只请求系统打开固定 URL，不向该 URL 添加设备 ID、日志、账号、Token 或 App 内数据。
