# 常用 macOS 快捷键人工测试手册

## 适用版本与准备

- 适用分支：包含 `Command-Delete` 基础动作的开发分支，以及后续纳入该提交的预览候选。
- 准备一只已连接且普通按键可用的真实遥控器，开启“启用自定义按键”，并授予输入监控和辅助功能权限。
- 准备 TextEdit：输入至少两行文字，并让插入点位于第二行行首；另准备一个可关闭但不影响测试数据的普通 App 窗口。

## 无线麦窗口

1. 打开无线麦设置窗口。
2. 按 `Command-W`，确认窗口关闭、菜单栏进程仍在运行。
3. 重新打开设置窗口，按 `Command-Q`，确认无线麦进程退出。

## 遥控器固定快捷键

1. 开启“启用自定义按键”。
2. 将一个普通按键映射为“基础按键”中的 `Command-Delete`；预期动作直接显示在基础按键分组，无需录入自定义快捷键。
3. 回到 TextEdit，确保插入点位于第二行行首，单击遥控器按键；预期第二行与上一行合并，行为与实体键盘 `Command-Delete` 一致。
4. 撤销后将插入点放到一行中间，再次单击；预期删除从插入点到当前行行首的内容。
5. 长按已映射按键；预期一次物理按下只执行一次，不连续删除多行。
6. 将同一按键分别映射为其他固定快捷键，在 TextEdit 验证剪切、全选、撤销、重做、查找和保存。
7. 在任意有窗口的 App 中验证 `Command-W` 关闭当前窗口。

## 失败判定

- `Command-Delete` 不在“基础按键”分组、名称与当前语言不一致，或保存后变成其他动作。
- 触发后只执行普通 Delete、删除方向错误、没有携带 Command 修饰键，或长按造成多次连续删除。
- 切换动作后已有映射无法保存，或既有固定快捷键行为发生变化。

## 稳定功能回归

- `Delete（退格）` 仍允许按住重复，且不受新增组合动作影响。
- `Command-Return`、`Shift-Return`、`Command-C`、`Command-V`、`Command-Q`、`Command-W`、`Command-X`、`Command-A`、`Command-Z`、`Command-Shift-Z`、`Command-F` 和 `Command-S` 仍只执行一次。
- 中英文切换后，基础按键分组和 `Command-Delete` 名称均完整显示，页面在最小 `1020 × 772` 窗口可访问且不改变窗口几何。

## 日志收集

若真实遥控器触发失败，在菜单“文件 → 打开日志所在文件夹”中收集对应时间段日志，并记录遥控器型号、映射按键、目标 App、插入点位置以及单击或长按方式；日志不应包含测试正文内容。

## 自动化边界

单元测试只验证动作分类、禁止重复、键码 `51` 和 Command 修饰键；代理未操作真实遥控器，也未验证 TextEdit 或第三方 App 对合成事件的实际响应。上述真实环境步骤必须由人工完成，才能视为用户流程验收通过。
