# 功能测试说明

本功能的完整人工测试步骤统一维护在 [`Testing/FirstRunOnboarding.md`](../../Testing/FirstRunOnboarding.md)。

`v1.8.8 (100)` 公开 Pre-release 已通过原流程验证；`v1.8.10 (102)` 候选新增旧安装迁移并通过流程自动化、完整 Swift 测试、项目自检和 Release App 构建。最终签名、公证、公开资产和真实升级结果在候选发布后记录。

交付前至少确认：

- 首次启动无法进入主面板，也没有跳过或稍后继续入口；
- 从 Onboarding 加入前的已安装版本升级后直接进入主面板并保留原设置；全新安装、中途续接和主动重新运行仍显示向导；
- 退出并重启恢复到保存页；
- 每项实时条件缺失时“继续”不可用；
- RC003 真实语音必须同时出现会话开始、PCM 样本、松开停止和文字上屏；
- 三个不同普通按键被真实检测后才能完成；
- 已安装用户通过 Sparkle 升级后首次启动，即使 HID 按键先到而 BLE 状态仍在查找，也能在不重启 App 的情况下只恢复一次连接；
- 完成后进入现有设置页，“关于”页能够重新运行向导，并且兼容麦克风、按键映射、Dock、启动和更新设置不被清除；
- `1020 × 772` 下中英文没有裁切，中文文字不小于 12pt。

单元测试和构建不能替代系统权限、蓝牙、真实音频设备、Sparkle 升级首次启动、豆包、Typeless 及其他第三方工具验收。

## 验证分层

1. 流程层：状态机、持久化、门禁、重新运行和旧设置保留。
2. 页面层：生产视图浅色/深色各 8 张截图、`1020 × 772`、中英文、字号、裁切和视觉一致性。
3. 产物层：Release 构建、签名、公证、安装包、锁屏启动、资产摘要和 Sparkle 更新发现。
4. 现场层：真实权限历史、RC003、MiRemoteV 2ch、第三方语音工具、前后台与断连恢复。

只有现场层可以证明用户机器上的完整链路可用；前面三层用于尽早发现确定性回归。
