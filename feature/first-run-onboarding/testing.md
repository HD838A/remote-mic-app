# 功能测试说明

本功能的完整人工测试步骤统一维护在 [`Testing/FirstRunOnboarding.md`](../../Testing/FirstRunOnboarding.md)。

交付前至少确认：

- 首次启动无法进入主面板，也没有跳过或稍后继续入口；
- 退出并重启恢复到保存页；
- 每项实时条件缺失时“继续”不可用；
- RC003 真实语音必须同时出现会话开始、PCM 样本、松开停止和文字上屏；
- 三个不同普通按键被真实检测后才能完成；
- 已安装用户通过 Sparkle 升级后首次启动，即使 HID 按键先到而 BLE 状态仍在查找，也能在不重启 App 的情况下只恢复一次连接；
- 完成后进入现有设置页，“关于”页能够重新运行向导，并且兼容麦克风、按键映射、Dock、启动和更新设置不被清除；
- `1020 × 772` 下中英文没有裁切，中文文字不小于 12pt。

单元测试和构建不能替代系统权限、蓝牙、真实音频设备、Sparkle 升级首次启动、豆包、Typeless 及其他第三方工具验收。
