# 首次使用设置向导

## 状态

`v1.8.8 (100)` 已作为公开 Pre-release 发布，等待真实环境人工验收。

自动化与构建已覆盖流程状态、持久化和门禁逻辑；签名、公证、最终 ZIP 锁屏启动、公开资产逐字节校验和从 `1.8.7 (68)` 发现候选更新均已通过。真实 RC003、系统权限、MiRemoteV 2ch、豆包、Typeless 和其他第三方语音工具仍需按测试手册完成真机验收。

## 为什么开发

用户首次安装后需要自行理解蓝牙、输入监控、辅助功能、遥控器连接、兼容麦克风和第三方语音工具，任一环节失败时很难判断原因。设置向导把这些条件组织成一条现场验证的任务流，只有真实状态满足后才能继续。

## 用户功能

- 首次启动自动显示 Typeless 式双栏向导，顶部只显示“准备 › 设置 › 试一下”。
- 依次完成语音工具选择、三项系统权限、遥控器连接与实体按键、MiRemoteV 2ch、真实语音文字测试和三个普通按键体验。
- 不提供跳过或稍后继续；关闭 App 后保存当前页，下次启动恢复。
- 完成前不能进入主面板；进入需要硬件的设置阶段后才启动蓝牙和音频运行时。
- “关于”页可重新运行设置向导，并明确说明该操作只重新检查环境，不会清除现有连接、按键映射或其他设置。

## 范围与非目标

本功能复用现有权限、蓝牙、HID、音频设备和语音输出状态，不修改协议、PCM 格式、设备配对方式或按键默认含义。首版不包含 iPhone、网页遥控器或高级映射编辑，它们继续保留在主面板。

## 隐私与兼容边界

- 新增的样本计数只记录当前语音会话收到多少 PCM 样本，不保存样本内容。
- 向导输入框中的测试文字只存在于当前视图状态，不写入设置或业务日志。
- 流程版本和当前位置保存在本机 `UserDefaults`。
- 隐藏截图入口使用随机独立 `UserDefaults` suite，不读取或修改用户正式向导进度。
- 支持 macOS 14 及以上；中文最终显示字号不低于 12pt。
