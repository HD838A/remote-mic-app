# 常用语功能规范与实施规划

## 定位与适用范围

- 常用语是无线麦SayAll.app 的免费基础能力，必须随公开构建交付，不依赖任何私有 Swift Package，也不因缺少可选组件而消失。
- 首发平台为 macOS。本文描述跨平台共同语义；Windows 实现时由同目录的 `platform-windows.md` 只映射平台差异，不得降低本文门禁。
- 本文是常用语产品行为的唯一权威入口。实现、构建接线、本地化文案、测试手册和截图清单都必须与本文一致。

## 为什么开发

- 遥控器适合“按一下就完成一次输入”，但不适合打字。
- 用户与 AI 对话时高频出现的其实是少量固定意图：确认、继续、澄清、授权执行、质疑、要备选、请求判断、总结收敛。
- 这些意图每次都要开口说一遍或用键盘敲，成本高且打断节奏。
- 常用语把高频意图变成“按一个键就上屏”：不用说话、不用键盘、不离开当前 App。

## 用户目标

1. 打开常用语面板后，一次按键插入一条常用语。
2. 常用语可自行新增、编辑、删除和调整顺序。
3. 文本只保存在本机，不联网、不上传。
4. 打开面板不打断用户当前正在使用的 App。

## 数据与来源

### 内置常用语源

- `Resources/CommonPhrases/built-in.md` 是内置常用语的**唯一人工编辑源**。
- 该文件只作为构建输入，**不直接进 App Bundle**。
- 构建期由脚本读取表格数据行生成 App 实际读取的 JSON 资源；App 运行时不解析该 Markdown 的散文段落。
- 不得在 Swift 代码里另存一份硬编码列表，也不得在生成失败时静默回退到旧数据或代码内置列表。
- 表格必须五列全部非空，`#` 从 1 开始连续且唯一；**缺列、单元格为空或编号不连续时构建失败**。
- 表格以外的段落只供人工阅读，不进入生成结果。
- 修改该文件后重新打包，内置常用语必须随之变化。

### 默认五键

- 默认映射到面板五个按键的，是常用语表中**编号 1 至 5 的五行**。
- `built-in.md` 必须**显式标注**这五行的键位，不得由实现代码读取列表顺序自行推断。
- 标注方式：在常用语表增加一列（或在表格下方增加专门一节）声明键位，取值为 `OK` / `左` / `上` / `右` / `下`，其余行留空。
- 脚本必须校验：被标注的行**必须恰好是编号 1 至 5**、`#` 有效、五个键位各出现一次且不多于一次。任一不满足时**构建失败**。
- 增删或调整表格行时必须同步维护该标注；表格前五行变化时标注必须随之变化。

### 用户常用语

- 用户可新增、编辑、删除和调整顺序；用户内容与内置内容分开保存。
- 用户修改内置条目属于用户自己的副本，**不得回写** `built-in.md`（该文件只由人工编辑）。
- 文本只保存在本机；不联网、不上传、不做云备份。
- 日志与诊断输出**不得记录常用语正文**。

## 交互行为

### 打开方式

- 提供一个可绑定的“打开常用语”动作。它出现在按键映射页的动作列表，并作为宿主动作提供给键位方案。
- 用户可以把它绑定到任一可配置按键的单击、双击或长按，复用既有按键绑定链路，不新增一套并行配置。
- 未绑定任何按键时，常用语不影响任何按键行为。
- **实体遥控器、手机遥控与网页版遥控都应支持**：只要某个按键（任一来源）配置了触发“打开常用语”，该来源就必须能打开面板并插入，不得只支持实体遥控器。能力缺失的来源必须明确显示不支持或未知，不得静默替换成含义不同的动作。

### 面板形态

- 面板布局与遥控器实体一致：**方向键围成一圈，OK 键居中**。五个位置的相对位置必须与 RC001/RC003 及 Siri Remote 的方向/OK 排布一致，用户按下的物理位置和面板上显示的位置必须一一对应。
- 每个位置显示对应常用语的**短显示**（`built-in.md` 的“中文短显示”/“Short Display”列），不是完整句。
- 面板是**短时窗口**，不是常驻开关：它只存在于一次调用期间，不提供长期开启的“常用语模式”开关，也不改写任何持久化按键状态。
- 面板打开后保持可见，用户可连续插入多条；**返回键关闭面板**。App 进入后台、遥控器断开或连接丢失时也关闭面板。

### 按键语义

- 面板打开期间，遥控器按键按下列语义映射：

| 按键 | 行为 | 默认对应条目 |
| --- | --- | --- |
| OK | 插入第 1 条 | 编号 1 |
| 左 | 插入第 2 条 | 编号 2 |
| 上 | 插入第 3 条 | 编号 3 |
| 右 | 插入第 4 条 | 编号 4 |
| 下 | 插入第 5 条 | 编号 5 |
| 返回 | 关闭面板，**不透传**给前台 App | — |

- 面板打开期间，这六个键**不区分单击、双击与长按**：按下即响应，不等待手势判定。
- 面板关闭后，这六个键必须**立即恢复**用户原有映射，不留任何残留优先级。

### 响应时延约束（实现必读）

面板打开期间的响应必须绕过现有手势识别，否则首击会被吞。

- 现有分发在按下时会先看该键是否配置了双击或长按：只要该键识别双击或长按为真，就**不立即执行单击动作**，而是交给 `RemoteButtonGestureRecognizer` 判定后再回补。`BridgeAppModel.handleMobileButtonEvent`（约 4463 行）与 Apple Remote 路径（约 2896 行）都是这个结构。
- 后果：若用户在“左”键上配了双击，面板打开后按一下“左”会被推迟到手势判定结束才插入，用户感知为“按了没反应”或“反应很慢”。
- 因此：**面板打开期间对这六个键的认领必须发生在手势识别之前**。把“面板是否打开”的判定放在这些处理函数的最前面，命中即直接执行并结束，不得进入 recognizer，不得引入双击等待窗口或长按阈值。
- 这与仓库既有的“不得因手势识别延迟、吞掉或重排事件”是同一条边界。

### 插入语义

- 在当前光标位置插入，**不替换**已有内容，**不自动回车**，不提交、不发送。
- 插入目标为只读输入框、只读页面、密码或 Token 等安全输入框，或没有任何可输入位置时：**明确提示当前输入框不可用**，不得静默丢弃，也不得把文本插到别的位置。
- 插入需要辅助功能权限；未授权时给出明确失败反馈。

### 文本插入方式与剪贴板

- **首选路径：写入系统剪贴板 + 合成 `Cmd+V`。**
- 依据：`KeyboardInjector` 目前只提供按键级别注入（`postKey(code: CGKeyCode, flags:)`，全部为 `CGKeyCode`），仓库**没有** unicode 文本直插（`CGEventKeyboardSetUnicodeString`）也没有 AX 属性写入（`kAXSelectedTextAttribute`）能力。要把中文句子放进任意前台 App 的光标处，`Cmd+V` 是覆盖真实目标（豆包、微信、浏览器、Electron 应用）最可靠、且唯一沿用现有注入模型的路径。
- 因此本功能**会触碰用户剪贴板**，必须遵守下列约束：
  1. 写入前先快照原剪贴板内容。
  2. 只在插入这一瞬间写入，不做长期占用。
  3. 插入完成后，若期间**用户没有自行复制新内容**，必须恢复原剪贴板内容。
  4. 若期间用户自行复制了新内容，**不得回滚**，以免吞掉用户刚复制的内容。
  5. 常用语正文**不得**进入运行日志、诊断输出或分享内容。
- 备选增强（本期不做，记录取舍）：unicode 直插与 AX 属性写入不触碰剪贴板，但在部分 Electron/WebView 自定义编辑器上覆盖不足，不作为主路径。若将来补充，必须以“首选失败后才降级”的方式接入，且不得改变上列五条约束。

### 按键认领的实现约束

- 面板打开期间对 OK/左/上/右/下/返回 的认领必须基于**运行时状态**，**不得写成长久生效的持久绑定**。
- 依据：宿主按键分发顺序中，私有绑定对每个 `(profileID, button, trigger)` 有一票优先权，命中后不再执行用户配置的普通动作（`BridgeAppModel.performAppleRemoteConfiguredAction`，约 3155 行；手机遥控与网页版走同一顺序，约 4573 行）。若用持久绑定实现，用户的方向键与 OK 会被**永久顶掉**。
- 宿主侧的认领判定在每次按下时重新求值且不被界面读取，因此按模式状态动态认领是安全的实现路径。
- 手机遥控与网页版使用同一 `RemoteButton` 类型与同样的手势识别结构，因此运行时认领必须在这两条路径上也生效，不能只覆盖实体遥控器。注意移动路径使用的是 `settings.selectedRemoteProfileID`，认领判定不能依赖设备来源。

## 与其他能力的边界

- 语音键的按下/释放会话生命周期、首字延迟和尾字完整性不受影响；常用语不得占用语音键，也不得在语音会话期间改变其行为。
- 不修改用户已有的按键配置、键位方案和持久化数据；进入与退出面板都**不得写入按键配置**。
- 恢复默认按键映射不得清除用户常用语；清除常用语也不得改动按键映射。
- 不读取、不解析、不依赖任何第三方 App 的私有文件、数据库、协议或未公开格式；插入只作用于当前前台 App 的公开输入界面。
- 不开放市场、社区上传、任意脚本或任意命令执行。

## 明确不做

- **本轮不做插件化封装。** 插件注册、启用状态、生命周期和统一按键动作入口属于尚未建立的抽象。常用语先按宿主公开实现落地，只在动作目录中预留稳定动作 ID，便于将来平移而不返工。
- **不放进任何私有 Swift Package。** 公开构建必须包含常用语。
- 不做语音朗读、不做自动发送、不做跨设备同步、不做云备份。
- 不做常用语内容的自动生成或 AI 改写。
- 不提供常驻的“常用语模式”开关，面板不长期接管按键。
- 不因本功能改动语音、蓝牙、音频、HID 或虚拟声卡的稳定主路径。

## 产品决定

以下问题已经决定，实现与验收都必须以此为准：

1. 默认五键取常用语表编号 **1 至 5**，并在 `built-in.md` 中显式标注。
2. 面板是**短时窗口**，不是常驻开关；返回键关闭，App 转入后台或遥控器断开时关闭。
3. 目标为只读输入框、选区或密码/Token 等安全输入框时，**明确提示不可用**，不静默丢弃也不降级到别处插入。
4. 面板打开期间**不区分单击、双击与长按**，按下即响应。
5. **手机遥控与网页版遥控同样支持**：任一来源的按键只要配置了触发常用语，就必须能打开面板并插入。
6. 文本插入采用**剪贴板 + `Cmd+V`**，必须原位快照与恢复，详见「文本插入方式与剪贴板」。
7. 面板形态与遥控器一致：**方向键一圈、OK 键居中**，显示短显示文案。

## 验证门禁

- **数据管线**：四类非法输入各一个失败用例；五个键位与标注的对应关系；常用语正文不出现在日志与诊断输出。
- **剪贴板**：插入后原剪贴板内容恢复；期间用户新复制内容时**不**回滚；插入失败也要恢复。
- **时延**：为某个方向键配置双击或长按后，面板内按下该键仍即时插入，不等待手势判定。
- **构建**：无私有包路径与含私有包路径均可构建；公开构建必须包含常用语。
- **自动化**：关闭面板后原映射逐键一致；未绑定按键时按键行为与改动前完全一致。
- **截图**：面板与设置页在生产 UI 的真实运行截图，覆盖中文浅色与中文深色。
- **真机**：真实遥控器逐键插入、连续多次发送、无可用输入框、只读与密码输入框、前台 App 切换、面板开关后原映射完整恢复；实体遥控器、手机遥控、网页版三条来源各验一遍；微信、豆包等真实第三方输入框的文字上屏。
- **边界声明**：以上任一项未完成时只能标记为候选，不得表述为已验收；单元测试、构建与截图都不能替代真机与第三方输入框验收。
