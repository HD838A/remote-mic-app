## 行为

设置页仅保留一组导出、导入按钮。
导出直接打开系统保存窗口，不显示内容选择、备份类型或预览。
自动导出全部可迁移对象和通用、音频、语音、按键设置。
导入同时接受 .sayall 和旧个人配置 JSON。
组合动作及键位方案页仍保留各自的专用入口。

## 准备

使用隔离配置与合成数据。
保存当前配置的摘要，记录宿主和组件提交。
准备组合动作、App 配置和当前遥控器的键位方案。
让方案引用实际快捷键或组合动作。
备份只收集所选对象的依赖快捷键。

## 核心流程

| 操作 | 预期结果 |
|---|---|
| 打开设置页 | 只有一组“导出配置…”和“导入配置…” |
| 点击导出配置 | 直接显示系统保存窗口，无内容选项 |
| 选择位置并保存 | .sayall 含全部可迁移对象及完整依赖 |
| 检查备份范围 | 通用、音频、语音及当前遥控器映射均存在 |
| 重新导入 | 先显示选择与预览，不立即写入 |
| 取消 | 配置摘要保持不变 |
| 确认保存 | 恢复所选配置，方案须手动启用 |
| 导入旧 JSON | 原有配置读取路径仍可用 |
| 缺少私有模块 | 基础 JSON 导入、导出仍可用 |

输入框定位指纹不导出。
账号、凭据、配对身份和使用历史不备份。
键位方案与普通映射按当前遥控器范围备份。
导入收费方案时，保存仍检查会员状态。

## 边界与失败

| 场景 | 处理方式 |
|---|---|
| 对象缺依赖或含不支持的本机脚本 | 沿用格式校验，报错且不写入不完整备份 |
| 生成备份时配置被修改 | 拒绝混合快照，保护现有配置 |
| 保存位置不可写 | 显示失败状态，记录失败阶段 |
| 取消文件面板 | 不写入配置 |
| 导入后依赖待配置 | 提示在对应编辑器中学习或测试 |
| 保存前会员失效 | 阻止收费方案保存 |
