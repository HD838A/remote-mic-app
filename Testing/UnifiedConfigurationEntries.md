## 行为

设置页仅保留一组导出、导入按钮。
导出默认进入现有个人备份流程。
导入同时接受 .sayall 和旧个人配置 JSON。
组合动作及键位方案页仍保留各自的专用入口。

## 准备

使用隔离配置与合成数据。
保存当前配置的摘要，记录宿主和组件提交。
准备组合动作、App 配置和当前遥控器的键位方案。
让方案引用实际快捷键或组合动作。
备份只收集所选对象的依赖快捷键。

## 核心流程

| 操作 | 预期结果 |
|---|---|
| 打开设置页 | 只有一组“导出配置…”和“导入配置…” |
| 点击导出配置 | 显示个人备份及默认选择 |
| 查看备份范围 | 显示当前遥控器型号 |
| 预览并保存 | .sayall 含所选对象及完整依赖 |
| 重新导入 | 先显示选择与预览，不立即写入 |
| 取消 | 配置摘要保持不变 |
| 确认保存 | 恢复所选配置，方案须手动启用 |
| 导入旧 JSON | 原有配置读取路径仍可用 |
| 缺少私有模块 | 基础 JSON 导入、导出仍可用 |

输入框定位信息默认不选。
账号、凭据、配对身份和使用历史不备份。
键位方案与普通映射按当前遥控器范围备份。
导入收费方案时，保存仍检查会员状态。

## 边界与失败

| 场景 | 处理方式 |
|---|---|
| 未选对象缺依赖 | 不阻止所选有效对象 |
| 所选对象缺依赖 | 拒绝导出，并显示原因 |
| 个人备份包含本机脚本 | 沿用现有拒绝规则；可以取消选择 |
| 保存前配置被修改 | 拒绝旧预览，保护新配置 |
| 取消文件面板 | 不写入配置 |
| 导入后依赖待配置 | 提示在对应编辑器中学习或测试 |
| 保存前会员失效 | 阻止收费方案保存 |

## 实际页面检查

使用生产 SettingsView 与隔离配置。
窗口尺寸为 1020 × 772 pt。
保存文件面板接受 .sayall。
重新打开该文件后，显示内容选择与导入确认。
没有 Plus 时，收费方案保存按钮禁用。
取消导入后，隔离存储没有新增文件。

首次检查发现导入确认区高度被压缩。
嵌入滚动页面时，GeometryReader 缺少有效高度。
导入区域增加 520 pt 最小高度。
最终 App 用同一文件复验，导入确认区正常显示。
只选择个人设置时，可以确认保存。
