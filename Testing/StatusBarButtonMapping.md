# 状态栏快捷映射测试手册

## 适用范围

- 分支：`codex/status-bar-button-mapping`
- 功能：仅状态栏运行、状态栏快捷映射、已连接遥控器切换、完整映射页面跳转
- 不改变蓝牙语音协议、按键报告解析和音频输出格式。

## 测试前准备

1. 使用完成首次设置的无线麦SayAll.app。
2. 在系统设置中授予蓝牙、输入监控和辅助功能权限。
3. 准备至少一只已配对的实体遥控器；多遥控器用例需要两只。
4. 在“关于”页面关闭“在 Dock 中显示应用图标”和“启动时自动打开主面板”，然后退出并重新启动 App。
5. 测试前记录每个遥控器“确定 / OK”键的原始单击、双击和长按动作。

## 用例一：仅状态栏启动

1. 启动 App。
2. 确认没有自动显示主窗口，Dock 中没有 App 图标，菜单栏保留无线麦图标。
3. 左键点击菜单栏图标。

预期结果：左键直接展开状态菜单；菜单顶部连接、音频和按键状态可见，并包含“按键快捷映射”。

失败判定：出现主窗口、状态栏图标缺失、左键没有打开菜单，或进程启动后立即退出。

## 用例二：启停按键映射

1. 展开“按键快捷映射”。
2. 关闭“启用自定义按键功能”，按遥控器方向键，确认由 macOS 原生处理。
3. 再次开启该选项。

预期结果：菜单勾选状态立即变化；重新开启后按键状态恢复连接。若权限缺失，应打开权限页面而不是静默失败。

失败判定：勾选状态与实际处理不一致、重复启动 App 才生效，或权限缺失时没有可操作提示。

## 用例三：即时切换单击动作

1. 在“确定 / OK”子菜单选择“Escape”。
2. 不退出菜单栏进程，立即在一个可观察按键输入的 App 中按一次实体 OK 键。
3. 再把 OK 单击动作改为“Return”，立即重试。
4. 退出并重新启动无线麦，再次按 OK。

预期结果：第一次产生 Escape，第二次产生 Return；两次修改都无需重启，重新启动后保持最后选择的 Return。双击和长按原配置不被清除。

失败判定：动作延迟到重启后才生效、执行了旧动作、产生两次输入，或覆盖双击/长按配置。

## 用例四：自定义动作保留

1. 从“编辑完整映射…”进入映射页面，为 OK 单击录入一个自定义快捷键。
2. 回到状态栏，把 OK 临时切换为“Return”。
3. 再次展开 OK 子菜单，切回已经录入的“自定义快捷键”。
4. 按实体 OK 键。

预期结果：未配置的自定义动作不会出现在快捷菜单中；已经配置的自定义快捷键可以反复切走、切回，原录入内容不丢失。

失败判定：菜单提供无法执行的空自定义动作，或切回后需要重新录入快捷键。

## 用例五：两只遥控器

1. 同时连接两只遥控器。
2. 在“当前遥控器”中选择第一只，把 OK 改为 Escape。
3. 选择第二只，把 OK 改为 Return。
4. 分别按两只遥控器的 OK 键。

预期结果：当前遥控器有且只有一个勾选项；两只遥控器分别执行自己的映射，不互相覆盖。

失败判定：菜单显示历史断开设备、选中状态错误，或两只遥控器共享了错误配置。

## 用例六：完整编辑器与稳定功能回归

1. 点击“编辑完整映射…”，确认窗口直接显示按键映射页面。
2. 保持设置窗口打开，再从状态栏打开完整编辑器，确认仍切换到映射页面。
3. 验证语音键按住说话、断开重连、系统睡眠唤醒和退出 App。
4. 分别使用简体中文和英文检查菜单标题、动作分组与按键摘要。

预期结果：页面跳转正确；语音和连接基线无变化；菜单两种语言完整显示，没有内部协议术语。

失败判定：打开的是其他设置页、语音不可用、重连失败、睡眠唤醒后映射失效或菜单出现未本地化 key。

## 日志收集

1. 从状态菜单选择“显示日志”。
2. 记录失败发生时间、遥控器、按键、期望动作和实际动作。
3. 快捷切换成功时日志应包含 `STATUS MENU MAPPING`；按键执行仍应包含既有 `HID BUTTON` 记录。

## 验证边界

- 自动化覆盖：仅状态栏点击策略、动作分组、自定义动作可用性、菜单选中状态、单击映射持久化。
- 代理可验证：Swift 构建、完整单元测试、本地化键一致性和静态菜单结构。
- 用户或真实环境必须验证：实体遥控器输入、双遥控器隔离、系统权限弹窗、后台常驻、睡眠唤醒、第三方 App 实际快捷键和语音输入。
