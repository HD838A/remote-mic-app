# 连接页遥控器状态文案

## 适用范围与准备

- 适用于 `codex/connection-status-remote-model-20261111` 及包含该修复的后续版本。
- 苹果与 Chromecast 用例要求安装包包含相应适配器。
- 准备已保存的小米 2、2 Pro、苹果第 6／7 代或 Chromecast 遥控器档案。
- 通过设置切换中文、英文及浅色、深色外观。

## 操作与预期

1. 打开“连接与语音”，选中尚未连接的遥控器。
2. 检查设备卡片与下方查找文案。
3. 在不同型号之间切换，再切换语言。
4. 连接另一只遥控器，保留当前苹果或 Chromecast 的断开状态。
5. 重新连接选中的遥控器，检查状态转换。

| 场景 | 预期 |
| --- | --- |
| 已知型号正在查找 | 中文显示“正在查找”加卡片型号名 |
| 英文正在查找 | 显示“Looking for”加卡片型号名 |
| 切换设备或语言 | 文案同步更新 |
| 历史未知型号 | 显示通用遥控器查找文案 |
| 所选苹果或 Chromecast 断开，其他设备连接中 | 保留所选设备的查找文案 |
| 所选设备连接成功 | 显示对应设备家族已连接 |
| 当前小米设备连接中、初始化或失败 | 保留对应阶段及错误文案 |

出现型号串用、语言残留、格式占位符或文字裁切时判定失败。
在生产窗口尺寸检查状态行。中文字号至少为 12pt。

## 稳定功能与日志

- 确认设备选择、重新连接按钮和按键页导航可用。
- 完成一次普通按键及按下／释放语音会话，确认原有行为。
- 失败时使用“文件 → 打开日志目录”收集受测时段日志。
- 对照连接事件与所选设备家族，不把查找文案视为扫描成功证据。

## 验证边界

自动化覆盖型号、语言和注入的连接状态。
离屏截图覆盖生产视图及隔离配置，只证明静态显示。
代理未完成真实遥控器、系统权限和语音输入流程验收。
用户现场验收按以上步骤记录实际设备、语言和最终结果。
