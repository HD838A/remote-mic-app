# Siri Remote 组合动作与键位方案本地测试包手册

## 适用版本

- 本地测试包：无线麦SayAll.app `1.9.21 (174)`
- 构建变体：Apple Silicon，最低 macOS 14.0
- 构建分支：`codex/complete-siri-pr16-20260907`
- 本手册只适用于已注入私有 Siri Remote 与 Button Profiles package 的测试包，不适用于社区版 App。

## 测试前准备

1. 使用 Apple Silicon Mac，macOS 14 或更高版本。
2. 准备已经配对的 Siri Remote（当前重点为 A2854）；A2540 仍属于待真实硬件确认型号。
3. 确认无线麦SayAll.app 已获得所需的蓝牙、辅助功能和输入监控权限。
4. 关闭旧版无线麦SayAll.app，避免旧进程持有 HID 或音频会话。

## 安装

1. 双击 [Install SayAll.pkg](../dist/Install%20SayAll.pkg)。
2. 在安装器的“自定安装”页面确认 `Siri Remote 支持` 初始未勾选，然后主动勾选它再继续。
3. 完成系统管理员授权，等待安装结束。
4. 从 `/Applications/SayAll.app` 启动 App。

预期：App、`MiRemoteV 2ch` 和 Siri Remote HCI Helper 均安装；关于页或诊断信息可确认 Siri Remote 功能已包含。若不勾选 Siri Remote，系统 Helper 不应被安装。

失败判定：安装器默认勾选 Siri Remote、主动勾选后缺少 HCI Helper、安装后 App 的 Siri Remote 页面消失，或仍显示 RC003 专属内容。

## 用例一：键位方案页面

1. 打开“设置 → 键位方案”。
2. 选择 Siri Remote 设备，确认预览显示 Siri Remote 图片。
3. 检查可配置按键：上、下、左、右、中心、返回、TV、音量加、音量减、播放/暂停、静音、电源。
4. 确认列表中没有 Home/Menu；Siri 语音键不出现在普通键位方案编辑器中。
5. 为 TV、播放/暂停、静音和电源分别设置一个无破坏性的动作，例如打开计算器、播放/暂停媒体、静音系统音量或打开一个测试 App。
6. 保存方案，退出设置后重新进入，确认绑定仍在。
7. 用遥控器逐个按键验证，观察页面活动描边和最终动作。

预期：页面只显示 Siri Remote 的真实按键集合；每个按键只执行配置动作，不额外叠加系统默认动作；重新进入后方案不丢失。

失败判定：出现 Home/Menu、缺少播放/暂停或静音、Siri 被当作可配置普通键、点击后没有活动描边、保存后丢失，或自定义电源/音量动作同时触发未配置的系统动作。

## 用例二：组合动作创建与绑定

1. 打开“设置 → 组合动作”，创建一个测试动作，例如“Remote smoke test”。
2. 添加两个或更多步骤：打开一个 App、等待短时间、发送一个标准快捷键或打开一个安全的 `https` 地址。
3. 保存后重新打开该动作，确认步骤顺序和参数保持不变。
4. 在“选择遥控器按键”中绑定中心单击或 TV 单击；不要绑定 Siri 语音键。
5. 先使用页面内“测试动作”执行一次，再使用 Siri Remote 的实际按键执行一次。
6. 再创建第二个组合动作，绑定另一个按键，确认两个动作互不覆盖。

预期：组合动作预览使用 Siri Remote 图片和真实热点；可绑定键集合与键位方案一致；页面内测试和实体遥控器触发产生相同动作；Siri 键始终保留实时语音输入路径。

失败判定：组合动作仍显示 RC003 图片、出现 Home/Menu、把 Siri 键作为普通触发器、实体触发与页面测试结果不同、保存后步骤丢失，或第二个动作覆盖第一个动作的绑定。

## 用例三：导入、导出与型号隔离

1. 导出当前 Siri Remote 键位方案，记录导出文件位置和 `remoteModel`。
2. 删除当前测试方案后重新导入该文件，确认预览仍显示 Siri Remote 型号和按键集合。
3. 尝试导入包含 RC003 专属 Home/Menu 的文件，观察是否明确拒绝或提示型号不兼容。
4. 切换到 RC003（若现场有该设备）后再切回 Siri Remote，确认绑定、活动状态和设备图片没有串用。

预期：导出文件使用稳定的 Siri Remote 型号 ID，不再写成 `xiaomi-remote-2-pro`；跨型号文件不会静默丢键或覆盖当前方案。

失败判定：型号字段错误、导入后出现错误按键、跨型号导入静默删除字段，或切换设备后沿用另一台遥控器的绑定状态。

## 日志收集

复现失败后，在 App 中使用“文件 → 打开日志目录”，只收集受测时间段的日志。重点记录：

- 当前设备型号分类和会话生命周期；
- 页面绑定选择、保存和执行结果；
- 组合动作步骤执行结果；
- Siri Remote HCI Helper 的连接、失败、重试和恢复状态。

日志不得包含语音内容、账户信息、蓝牙地址、凭据或本机绝对源码路径。
