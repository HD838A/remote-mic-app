# 常用语悬浮面板测试手册

## 适用版本

- 分支：`codex/quick-phrase-palette-pr`
- 当前 PR 候选构建
- 小米蓝牙遥控器 2 Pro / RC003；不修改遥控器固件、配对、身份或系统权限

## 测试前准备

1. 保持 SayAll 已获输入监控和辅助功能权限，遥控器状态为“已连接”。
2. 在“按键”页自行把 TV 长按映射为“打开常用语”，保持 TV 单击为“打开 Codex”。
3. 在“常用语”页新增至少五条不含敏感内容的测试常用语。
4. 在系统剪贴板中复制一段容易识别的文字，例如“原剪贴板”。

## 用例一：编辑和持久化

1. 打开“常用语”页，新增一条并填写名称和正文。
   - 预期：列表立即出现新条目，页面说明修改自动保存在本机。
2. 保持正文编辑器处于输入状态，依次单击左侧五条测试常用语。
   - 预期：每次只需单击一次，名称和正文立即切换；不需要等待或重复点击。
3. 修改一条正文后立即点另一条，再切回刚才的条目。
   - 预期：切换立即完成，刚才的修改已经保存。
4. 使用上移、下移改变顺序，再退出并重新打开 SayAll。
   - 预期：名称、正文和顺序保持不变。
5. 删除刚新增的条目。
   - 预期：只删除该条，其他测试内容不变。

失败判定：单击没有立即切换、需要重复点击、修改丢失、顺序丢失，或编辑一条却改变其他条。

## 用例二：悬浮面板和导航

1. 将光标放进 Codex 输入框，长按 TV。
   - 预期：屏幕中央出现常用语悬浮面板；Codex 仍是前台 App，TV 长按不会输入字符。
2. 依次按上下左右键。
   - 预期：蓝色选择框按两列网格移动；不会滚动 Codex、移动输入光标或执行原方向键映射。
3. 按返回键。
   - 预期：面板关闭，输入框内容不变。

失败判定：面板出现时切换到 SayAll、方向键同时作用于底层 App、返回键删除输入内容。

## 用例三：插入和剪贴板保护

1. 再次打开面板，选中任意一条测试常用语，按 OK。
   - 预期：面板关闭，完整提示词插入当前输入位置；不会自动发送。
2. 立即在其他位置粘贴。
   - 预期：得到测试前的“原剪贴板”，不是提示词。
3. 重复打开面板并按 OK；在 0.35 秒内手动复制一段新文字。
   - 预期：SayAll 不覆盖用户刚复制的新内容。

失败判定：只插入摘要、自动发送、换行丢失、剪贴板永久被提示词替换，或覆盖用户的新复制。

## 用例四：跨 App

分别在 Codex、WorkBuddy、Claude Code 和 Grok CLI 的可输入位置重复“打开面板 → 选择 → OK”。

- 预期：都只向当前焦点插入文字，不启动、切换或识别具体 App。
- 对没有焦点或不接受粘贴的位置，允许不插入；不得猜测输入框或向其他 App 写入。

## 用例五：稳定功能回归

1. TV 单击仍打开 Codex，且不泄漏特殊字符。
2. OK 单击仍发送 Return；菜单键仍按现有映射执行应用切换。
3. 语音键短按聚焦、长按千问输入和松开结束保持原行为。
4. 遥控器断连、SayAll 退出或系统休眠后，悬浮面板不应残留。

## 日志

通过状态栏菜单“显示日志”，搜索 `QUICK PHRASES` 或 `QUICK PHRASE EDIT`。设置页选择日志应包含操作编号、条目序号和耗时；保存日志只包含触发原因。日志不得记录名称或正文。

## 验证边界

- 自动化验证：默认不包含私人内容、编辑持久化、设置页单次发布、动作分类、两列导航、Command-V 事件和剪贴板条件恢复。
- 代理可验证：编译、完整测试、设置页静态截图、App 构建和安装包结构。
- 用户真机验证：RC003 长按入口、悬浮层不抢焦点、四类目标 App 的真实插入，以及 TV/语音键回归。
