# 遥控器操作 macOS Command-Tab 切换器测试手册

## 适用版本或分支

- 适用分支：包含 Command-Tab 临时会话实现的功能分支及后续预览版。
- 本手册覆盖第一阶段：启动系统切换器、保持 Command、再次按绑定键或 TV 键发送 Tab，以及停止/断连时释放 Command。
- 左右方向键、确定键、返回键、超时、失焦和多显示器完整操作不属于本阶段通过范围。

## 测试前准备

1. 使用 macOS 桌面会话，打开至少三个不同 App，并确认辅助功能和输入监控权限均已授予无线麦SayAll.app。
2. 进入“按键映射”，启用自定义映射，将任意按键（例如 OK）单击绑定为 `Command-Tab`。
3. 将 TV 键暂时绑定为普通动作（例如 Escape），用于验证切换器活动期间 TV 被临时接管；测试完成后恢复原映射。
4. 准备一只已连接并能稳定发送 HID 报告的 RC003 遥控器；记录 App 版本、Build、遥控器型号和当前前台 App。

## 用例 1：首次触发保持 Command

1. 让任意非无线麦 App 处于前台。
2. 按一次绑定为 `Command-Tab` 的按键并松开。

预期结果：系统原生 App 切换器出现，当前选项保持高亮，Command 仍保持在切换会话中；不会立即完成切换，也不会向输入框写入字符。

失败判定：只出现一次普通快捷键后切换器立即消失、没有显示系统切换器、Command 没有保持、出现输入字符或系统进入异常修饰键状态。

## 用例 2：TV 发送下一次 Tab

1. 在用例 1 的切换器仍显示时按一次 TV 键并松开。
2. 连续重复 TV 键 3 次，每次都完整按下和松开。

预期结果：每次 TV 按键只让系统切换器向下移动一个 App；TV 原先绑定的 Escape 或其他动作不执行；Command 一直保持到会话结束。

失败判定：TV 执行原有动作、一次按键跳过多个 App、切换器消失、输入框出现字符或 Command 被提前释放。

## 用例 3：Command-Tab 可绑定到其他按键

1. 将 `Command-Tab` 从 OK 改绑到菜单、主页或其他普通按键。
2. 使用新绑定按键启动切换器，再按 TV。

预期结果：新绑定按键可以启动相同的系统切换器；TV 仍发送一次 Tab；不依赖固定的 OK 或 TV 启动入口。

失败判定：只有 OK 能启动、改绑后仍触发旧按键动作、TV 不能移动选项或出现重复 Tab。

## 用例 4：断连与停止释放 Command

1. 启动切换器后，在其仍显示时关闭遥控器、断开蓝牙或停止按键映射监听。
2. 重新连接遥控器并在实体键盘输入普通文字及其他 Command 快捷键。

预期结果：切换会话被取消，Command 被释放；重新连接后普通键盘输入、系统快捷键和遥控器普通映射均恢复正常。

失败判定：Command 卡住、普通文字变成快捷键、后续快捷键持续带 Command，或必须重启 App 才能恢复。

## 稳定功能回归

- 普通自定义快捷键仍只发送一次按下/释放组合。
- TV 在没有切换会话时仍执行其保存的原有动作。
- 普通方向键、确定、返回、双击、长按和应用打开映射不因本功能改变。
- monitored 模式下原生键盘事件抑制仍有效，不能出现重复字符。

## 日志收集方式

1. 记录现场时间、App 版本/Build、前台 App、按键映射和遥控器连接状态。
2. 保存运行日志并重点搜索 `HID APP SWITCHER`、`HID GESTURE`、`HID BUTTON`、`HID RELEASED`。
3. 日志中的动作提交不等于系统切换器最终显示正确；失败时必须同时记录屏幕现象和是否出现字符/卡键。

## 验证边界

- 自动化测试覆盖 Command 按下、Tab 按下/释放、重复选择、取消释放和模拟遥控器任意绑定入口。
- 代理可以检查日志和事件序列，不能替代 WindowServer、真实系统切换器和真实 RC003 的最终屏幕验收。
- 本阶段尚未声称左右方向键、OK 确认、返回/超时/失焦、多显示器、全屏空间或系统动画关闭场景已完成。
