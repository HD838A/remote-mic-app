# 问题反馈入口测试手册

## 适用范围

适用于分支 `codex/fix-feedback-diagnostics-context`、合入后的 `main`，或对应 Preview staging artifact。

## 测试前准备

- Mac 可以访问互联网，并已配置默认浏览器。
- SayAll 工作台线上服务可用。
- 测试前关闭已有的 `my.sayall.app` 登录页面或使用无痕窗口，避免旧管理会话影响权限判断。
- 分别准备权限全部允许和至少一项未允许的状态；记录测试前遥控器连接、音频输出、按键映射和运行日志是否可用，不记录设备名称或标识。

## 用例一：打开反馈页面

1. 启动无线麦SayAll.app，打开设置并进入“关于”。
2. 点击“提交反馈”。
3. 确认默认浏览器打开 `my.sayall.app`，并自动进入公开排行榜页面。
4. 在浏览器地址或工作台反馈预览中确认包含当前 App 版本/Build、macOS/架构、权限状态，以及连接、音频、按键和日志可用性摘要。

预期结果：摘要与测试前记录一致；连接、音频和按键只显示布尔或有限枚举状态，不显示设备名称、设备标识或底层协议内容。

失败判定：没有打开浏览器、仍要求输入口令、进入空白页、出现服务端错误、摘要缺失或状态与点击时不一致。

## 用例二：最低权限边界

1. 在打开的页面查看可用导航和操作。
2. 确认可以查看公开排行、投票及提交问题反馈。
3. 确认看不到管理看板、内部规划、数据源和管理操作。

失败判定：能够查看内部内容、修改事项状态或执行任何管理操作。

## 用例三：脱敏边界

1. 检查反馈 URL、页面预览和最终提交内容。
2. 确认没有账号、Token、设备名称/标识、IP、蓝牙地址、输入文字、转写内容、音频、完整文件路径、Cookie、访客 ID、密码或动态口令。
3. 改变系统语言后重复检查，确认字段名称和取值仍是稳定的英文 key/value，而不是本地化状态文案。

失败判定：出现任一敏感字段、完整路径、用户内容，或工作台要求 App 自动上传日志。

## 用例四：可选日志入口

1. 返回“关于”页，点击“查看日志”。
2. 确认 Finder 打开无线麦自身日志位置；无线麦继续运行，反馈页面不会被自动提交。
3. 检查页面提示，确认日志不会自动上传，只有用户主动检查并选择时才可附加。

预期结果：入口仅显示无线麦自身日志位置，不读取其他 App 数据，不把完整本地路径加入反馈 URL。

失败判定：点击后崩溃、自动上传日志、反馈 URL 出现路径，或尝试读取其他 App 的日志/数据库。

## 用例五：反馈提交

1. 新建一条带标题和描述的测试反馈。
2. 不附日志提交一次；如确需验证附件，再检查日志内容并由测试者主动选择一份无线麦日志。
3. 确认页面明确显示提交结果。
4. 由管理员在对应 GitHub Issue 数据源确认昵称、北京时间日期、反馈内容和脱敏摘要正确。

失败判定：重复提交、内容或摘要缺失、未经选择自动带日志、身份提升或提交后无明确结果。

## 异常与回归

- 断网后点击入口，不应导致无线麦退出或影响遥控器、语音和设置功能。
- 默认浏览器不可用时，菜单点击不应导致无线麦崩溃。
- 关于页的官网、GitHub、分享、检查更新等相邻操作继续正常工作。
- 状态栏菜单不再重复显示“问题反馈”，其他菜单项继续正常工作。
- 在 `800 × 650` 或产品允许的最小窗口逐一进入“关于”页，确认反馈说明、“查看日志”和“提交反馈”均可通过页面滚动访问，中文不小于 12pt，窗口几何不改变。

## 日志与验证边界

本功能不新增遥测，也不自动上传运行日志。失败时只记录 macOS 版本、App 版本、发生时间、浏览器及页面错误信息，不要附带 Cookie、访客 ID、账号、设备标识或口令。

2026-08-16 线上只读验证已确认：

- `GET /api/guest-entry?source=mac` 返回 `302` 到工作台首页，跳转 URL 不包含 `code`、Token 或设备参数。
- 响应建立 `HttpOnly` + `Secure` + `SameSite=Strict` 的匿名 guest Cookie，`Max-Age=604800`（7 天）；验证记录不保存 Cookie 值或访客 ID。
- guest 读取 `/api/board` 返回 `200`，角色为 `guest`，公开条目包含“需求”和“Bug”类型；直接读取或尝试空载荷写入 `/api/items` 均返回 `403`，未创建或修改条目。

2026-08-29 线上只读探测补充：`guest-entry` 收到诊断查询参数后仍重定向到不带查询参数的工作台首页。Mac 端字段发送由本仓库自动化覆盖；工作台必须在独立 Web 前端/服务端仓库确认已在重定向前安全接收，并把脱敏摘要展示或带入反馈表单。若工作台没有接收，必须判定端到端用例失败，不能仅凭 Mac 生成 URL 宣称功能完成。

自动化边界：`FeedbackLinkTests` 可验证 URL 字段白名单、敏感字段不存在和关于页日志入口；`LocalizationTests` 可验证中英文资源完整。自动化不会启动真实默认浏览器，不能证明独立维护的工作台已经展示或保存摘要，也不能替代最小窗口页面检查。

代理实测边界：可检查本地生成的 URL、Finder 日志入口和生产视图，但不应代表用户提交真实反馈或替用户决定是否附加日志。

用户/管理员实测边界：从真实“关于”页分别在中文/英文、权限允许/拒绝和连接/断开状态点击入口，确认默认浏览器打开、工作台接收摘要，并提交一条真实问题反馈。未经明确人工验收不得将这些流程表述为已通过。
