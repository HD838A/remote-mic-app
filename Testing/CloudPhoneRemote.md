# 微信小程序 SayAll 连接测试

适用：本 PR 或已合入 main 的精确提交；Cloudflare-only，旧 VPS 不在本次范围内。

## 准备

使用经验证的完整私有构件及固定 MacRemote 依赖。缺少私有组件时公开宿主仍能运行实体按键和语音，但不得把云端遥控显示为可用。
测试包使用 staging；正式环境会员门禁仍生效。提前准备受支持虚拟麦克风和目标语音工具的公开设置。

本轮新行为须使用新 Remote 与统一会员私有构件重新构建宿主。旧固定 Remote 镜像仅验证编译兼容：旧开关恒隐藏、setter 无操作；小程序取码仍是旧规则，不能当作新功能包验收。原因见[固定 UI 合同记录](../Bugs/2026-10-03-remote-session-pinned-ui-contract.md)。

## 连接与权益

本轮生产组件截图与证据边界见[环境选择 UI 证据](../Screenshots/remote-environment-selection/README.md)；合成数据截图不能替代真实扫码或完整 App 验收。

1. 在「连接」查看三个移动端：无线麦 iOS App、Apple Watch、微信小程序 SayAll。右侧保留原连接状态、会员按钮和连接按钮；实体设备、音频与受信任设备区域仍可用。
2. iOS 副标题下显示「打开 App Store」和「复制链接」。中英文分别使用对应正式链接，不显示 TestFlight 或网页版入口。
3. 未登录、无有效 Plus 或授权过期时，production 显示会员按钮，不生成可用连接码。staging 按既有测试授权规则处理，release 渠道不得显示服务环境模块。
4. 有效 Plus 点击小程序连接后，只显示动态小程序码、扫码说明、等待状态和有效期。使用微信扫码一次，SayAll 打开后自动连接；不输入数字、不再次扫码、不手动批准。
5. 取码失败显示失败提示和重试，不显示固定码或浏览器 QR。覆盖超时、无效图片、断网、过期和重试；旧请求迟到不得替换新会话图片。
   - 超时应显示 `-1101`。
   - 其他取码错误应显示对应 `-1100` 至 `-1107` 支持码。
   - Mac、Relay 和微信取码网络请求的超时均为 30 秒。
6. 在允许切换环境的本地包中，staging 取 trial 码，production 取 release 码。等待取码、等待扫码及已连接时分别切换；旧连接应失效，生产不能继承测试授权。
7. 旧版 Mac 和浏览器协议继续按原批准流程测试；Mac 页面隐藏浏览器入口不改变已发布客户端的协议。

## 语音与稳定回归

1. 按一次开始、再按一次结束，重复三段；随后按住说话直到松开，三段均能正常结束。
2. 点按后切到按住；按住过程中保持手指不松开，并执行一次触摸移动。页面不能自行提前释放或留下 Mac 电平；松开后再次点按/按住不得报上一段仍在进行。
3. 极快开始/停止、快速连续两段、取消、页面后台/关闭、断网与重连，均不得串用旧 generation 或留下语音键/音频状态。
4. 正常停止尾包有序排空，不以 flush 换取结束；核对首包延迟、收到/播放/中断/pending 样本，文字上屏只由目标工具真实输入证明。
5. 实体 RC003 的 STREAM_START→AUDIO→STREAM_STOP、Nearby 手机语音、普通按键与现有用户设置不受影响。

失败判定：有效会话无法生成小程序码、出现验证码或二次批准、测试包被会员阻止、production 可绕过、迟到请求重启旧会话、录音残留、正常尾音丢失或第二段才成功，均不通过。

## UI、日志及验收边界

在生产 1020×772 最小窗口逐一访问连接、会员、通用及其他现有侧栏，确认导航、主要操作和滚动可达；中英文与明暗分别核对。
用 App 现有诊断入口收集 WEB REMOTE SESSION 和 REMOTE MINI_PROGRAM_CODE 的短期 operation/generation、请求超时预算、阶段、HTTP 状态类别、响应字节数、耗时、稳定支持码和语音完整性计数；不得收集/提交 Token、QR、数字、音频、转写或个人信息。系统与第三方不可观察状态明确为未知。
取码成功至少应出现 `request_started`、`response_received` 和 `completed`；取码失败还应出现 `failed`，并包含 `reason`、`support_code` 和 `elapsed_ms`。超时日志不得包含 URL 查询串、Bearer Token 或响应正文。
自动化、生产视图渲染、双架构构建、部署和真机分别记录在 PR。此前用户已确认点按/按住通过，不等于本轮新构件再次真机验收。一次扫码需配套 Mac、小程序和中继。未完成真实微信扫码、按键、音频及文字上屏时，保持待现场验证。
