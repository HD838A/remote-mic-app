# 微信小程序与网页版遥控主线接入

适用：本 PR 或已合入 main 的精确提交；Cloudflare-only，旧 VPS 不在本次范围内。

## 准备

使用经验证的完整私有构件及固定 MacRemote 依赖。缺少私有组件时公开宿主仍能运行实体按键和语音，但不得把云端遥控显示为可用。
测试包使用 staging；正式环境会员门禁仍生效。提前准备受支持虚拟麦克风和目标语音工具的公开设置。

## 连接与权益

1. 在「连接」直接打开微信小程序与网页版入口，无邀请码录入或 8586 校验。
2. 选择 staging 后自动免会员，无账号和 Plus 仍取得测试授权；连接页不再显示免会员开关。仍需合法安装身份，不能绕过服务端 staging 限制。
3. 选择 production 后恢复正式会员检查：Free 显示二维码及 Plus 提示、可进入会员页；不应把 Plus 提示变成二维码消失或连接成功。
4. 二维码下面不显示配对数字。手机请求连接后，Mac 的批准弹窗和手机数字保持一致；每次授权仍需 Mac 人工确认。
5. 同一个 Mac 包选择 staging 取 trial 小程序码，选择 production 取 release；不再按 App 构建渠道判断。小程序码失败时网页版 QR 保留。用不同网络的手机浏览器连接；小程序上线状态与体验成员权限需在真实微信核验。
6. 在「设置→通用」选择服务环境：切生产前需确认，取消不切换；切换后旧遥控会话断开、旧二维码消失，重新连接后取得新环境授权和二维码。等待取码/批准/已连接时分别切换，旧请求迟到不能恢复旧会话或旧小程序码，正式环境不能继承免检授权。两个环境仍使用同一 Web/Relay 地址。

## 语音与稳定回归

1. 按一次开始、再按一次结束，重复三段；随后按住说话直到松开，三段均能正常结束。
2. 点按后切到按住；按住过程中保持手指不松开，并执行一次触摸移动。页面不能自行提前释放或留下 Mac 电平；松开后再次点按/按住不得报上一段仍在进行。
3. 极快开始/停止、快速连续两段、取消、页面后台/关闭、断网与重连，均不得串用旧 generation 或留下语音键/音频状态。
4. 正常停止尾包有序排空，不以 flush 换取结束；核对首包延迟、收到/播放/中断/pending 样本，文字上屏只由目标工具真实输入证明。
5. 实体 RC003 的 STREAM_START→AUDIO→STREAM_STOP、Nearby 手机语音、普通按键与现有用户设置不受影响。

失败判定：二维码缺失、数字重复、测试包被会员阻止、production 可绕过、迟到请求重启旧会话、录音残留、正常尾音丢失或第二段才成功，均不通过。

## UI、日志及验收边界

在生产 1020×772 最小窗口逐一访问连接、会员、通用及其他现有侧栏，确认导航、主要操作和滚动可达；中英文与明暗分别核对。
用 App 现有诊断入口收集 WEB REMOTE SESSION 的短期 operation/generation、稳定原因和语音完整性计数；不得收集/提交 Token、QR、数字、音频、转写或个人信息。系统与第三方不可观察状态明确为未知。
自动化、生产视图渲染、双架构构建、部署和真机分别记录在 PR。此前用户已确认点按/按住通过，不等于本轮新构件再次真机验收。本轮只合并源码，不发布安装包或部署服务。
