# 鼠标控制（点击动作与鼠标模式）测试手册

## 适用范围

- 功能分支：含鼠标控制功能的候选构建（对应功能设计见 `feature/mouse-control/README.md`）。
- 功能状态：已实现并通过单元测试；**真实遥控器人工验收尚未执行**，本手册全部用例在真机通过前不得标记为完成。
- 测试目标：验证“鼠标左键 / 右键 / 中键”三个预设动作和“切换鼠标模式”内部动作在真实小米遥控器（RC001/RC003）上的行为。
- 本手册不把单元测试、构建成功或模拟按键等同于真机验收。

## 测试前准备

1. 退出其他已安装的无线麦版本，运行本次提供的测试包。
2. 在“系统设置 → 隐私与安全性”中确认无线麦已获得：
   - 辅助功能权限（鼠标事件注入必需；缺失时动作不执行并在日志中留下失败记录）。
   - 输入监控权限。
3. 打开无线麦“按键映射”页面，开启“自定义按键映射”，连接真实遥控器。
4. 准备一个可随时关闭的测试窗口（如 TextEdit 空白文档）用于观察点击效果。
5. 多显示器环境（如有）留到用例 6 再接入；先用单显示器完成用例 1～5。

## 用例 1：鼠标点击预设动作

1. 把“主页键双击”绑定为“鼠标左键”（“系统与媒体”分组内直接选择，无长下拉列表）。
2. 把光标移动到 TextEdit 文档中部，用遥控器双击主页键。
3. 依次改绑“鼠标右键”“鼠标中键”，重复触发。
4. 把某按键的“单击”绑定为“鼠标左键”，按住不放观察连发。

预期结果：

- 每次触发都在光标当前位置产生一次对应点击：左键产生普通点击，右键弹出上下文菜单，中键在支持的 App 中产生中键行为。
- 光标位置本身不移动。
- 按住绑定了单击鼠标动作的按键会产生连续点击（与方向键连发策略一致）。
- 音量、主页等其他未改绑按键行为不变。

失败判定：点击发生在错误位置、按键类型错误（如左键绑定点出右键菜单）、触发后无线麦 HID 监控停止，或触发一次后按键不再响应。

## 用例 2：进入与退出鼠标模式

1. 把“菜单键双击”绑定为“切换鼠标模式”（“自定义动作”分组）。
2. 双击菜单键进入鼠标模式。
3. 观察菜单栏图标。
4. 再双击菜单键（切换键）退出；确认按返回键不会退出鼠标模式（返回键在模式内恢复正常绑定）。

预期结果：

- 进入模式后菜单栏图标切换为高亮样式（与语音激活时相同的高亮图标），退出后恢复普通样式。
- 退出鼠标模式的唯一方式是再次按切换键；返回键、菜单键在模式内执行各自绑定，不被拦截。

失败判定：模式无法进入或无法用切换键退出、图标不切换、退出后图标仍保持高亮、返回键/菜单键在模式内被鼠标模式吞掉。

## 用例 3：鼠标模式内移动与点击

1. 进入鼠标模式。
2. 短按一下方向右键立即松开；再按住方向右键约 3 秒不松。
3. 同时按住“右 + 下”观察斜向移动。
4. 把光标移动到屏幕最右边缘后继续按住右键。
5. 把光标移到 TextEdit 文档上：短按 OK（快速松开，0.3 秒内不再按）应产生左键点击；快速双击 OK 应产生右键点击（弹出上下文菜单）；长按 OK 超过 0.55 秒应注入 Return（在聊天窗口中等于发送消息）。在桌面图标上按菜单键（菜单键已恢复正常绑定）。

预期结果：

- 短按只产生很小的位移；按住时移动按二次缓入曲线加速（约 1.2 秒内从 160px/s 加速到 1400px/s，前 0.3 秒为精调区，起步更慢更稳），松手立即停止。
- 斜向移动为 45° 方向，速度与单方向相当（不会因为两个方向叠加而翻倍）。
- 光标到达屏幕边缘后停止，不会越出屏幕或跳到异常位置。
- OK 键三手势：单击 = 松开时刻光标位置的左键点击（延迟约 0.3 秒待决窗口后触发）；双击（第二次也快速松开）= 右键点击，且不会先触发左键；任何一次按下按住到 0.55 秒 = 注入 Return，长按优先生效，触发后该次松开不再产生点击；第二次按下落入 0.3 秒窗口但按住到 0.55 秒 = 发送而非右键。
- 菜单键、返回键在模式内执行各自绑定（与其他未受管键一致），不产生鼠标点击。
- 模式激活期间方向键与 OK 键不再执行它们原本绑定的动作，也不会把方向键透传给前台 App（前台文本光标不应移动）。

失败判定：移动抖动、反向、加速突兀或停止后仍漂移；边缘越过屏幕；模式内方向键同时触发了原绑定动作或前台 App 收到方向键；OK 单击误发送 Return、长按误点击、双击先出左键再出右键、第二击窗口外误判为双击；菜单键/返回键被鼠标模式吞掉。

## 用例 3A：模式内方向键双击手势（固定映射，不可配置）

1. 进入鼠标模式，打开一个可翻页的长文档或网页（如 Safari 打开一篇长文）。
2. 快速轻点两下“方向上”（每次按下到松开小于 0.3 秒，两次间隔不超过 0.3 秒）。
3. 快速轻点两下“方向下”。
4. 在 Safari 中快速轻点两下“方向左”。
5. 打开一个可关闭的测试窗口，快速轻点两下“方向右”。
6. 先按住“方向上”超过 0.3 秒再松开（长按移动），随后在 0.3 秒内再按一次“方向上”。
7. 轻点一下“方向上”后停顿超过 0.3 秒，再按一次“方向上”。

预期结果：

- 双击上 = Page Up（文档向上翻一页）；双击下 = Page Down（向下翻一页）；双击左 = Command-[（浏览器返回上一页）；双击右 = Command-W（关闭当前窗口）。
- 每次双击发生时，光标先弹回第一次按下前的位置（第一次按下的短移动被撤销），第二次按下期间该方向不再移动光标，松开后方向键恢复正常移动。
- 第一次为长按（≥0.3 秒）时不构成轻点，随后 0.3 秒内的再按只是普通移动，不触发 Page Up。
- 单击后停顿超过 0.3 秒再按不触发双击动作。
- 模式外（未进入鼠标模式）方向键双击行为完全不变，不产生上述按键。

失败判定：双击未触发对应按键、触发了错误按键、光标没有弹回（停留在移动后的位置）、第二次按下期间光标继续移动、长按被误判为轻点，或模式外方向键行为发生改变。

## 用例 4：模式内其他键保持原功能

1. 进入鼠标模式。
2. 按音量 + / −、主页键、TV 键。

预期结果：音量键、主页键、TV 键按各自绑定正常执行，不受鼠标模式影响。

失败判定：这些键被鼠标模式吞掉，或它们触发了鼠标移动 / 点击。

## 用例 5：断开与重启自动退出

1. 进入鼠标模式后关闭遥控器电源（或令其蓝牙断开）。
2. 重新连接遥控器，直接按方向键。
3. 进入鼠标模式后彻底退出无线麦 App，再重新启动。

预期结果：

- 遥控器断开后鼠标模式自动退出，菜单栏图标恢复普通样式；日志中出现 `MOUSE MODE deactivated reason=remote_disconnected`。
- 重连后方向键立即恢复执行原绑定动作，不会继续移动鼠标。
- App 重启后鼠标模式为关闭状态（激活状态不持久化）。

失败判定：断开后模式残留、重连后方向键仍驱动鼠标、重启后图标错误保持高亮。

## 用例 6：多显示器（有条件时执行）

1. 接入第二台显示器（任意排列方式），进入鼠标模式。
2. 用方向键把光标从主屏移动到副屏，再移回。

预期结果：光标可以进入副屏并在副屏边界停止；不会卡在两屏之间或跳到错误坐标。

失败判定：光标无法进入副屏、进入副屏后消失，或坐标错乱。

## 稳定功能回归项

以下用例必须在同一测试包上重新通过（可参照各自既有手册）：

- 普通语音链路：按住语音键 → 说话 → 松开，第三方语音工具收到完整音频（`STREAM_START → AUDIO → STREAM_STOP`）。
- 自定义快捷键录入与执行（含 Command + Space 唤起 Spotlight）。
- 打开具体 APP 与自定义 APP 聚焦。
- 持续录音开关（如已启用实验开关）。
- 左右键原生透传：把左 / 右键绑定为方向左 / 右且无双击长按辅助动作时，在前台 App 按住可连续移动光标。
- 手机 / 网页遥控：手机端绑定“鼠标左键”后触发，应在 Mac 光标处点击（切换鼠标模式不影响手机按键的原有解析）。

## 日志收集

- 菜单栏菜单 → “打开日志所在文件夹”，收集测试时间段的日志文件。
- 关键日志标记：`MOUSE MODE activated`、`MOUSE MODE deactivated reason=...`、`MOUSE MODE double_tap button=up/down/left/right`、`MOUSE MODE double_tap_ok`（OK 双击注入右键）、`MOUSE MODE long_press_send`（长按 OK 注入 Return）、`HID BUTTON ... action=mouseLeftClick/mouseRightClick/mouseMiddleClick/toggleMouseMode`、`INTERNAL ACTION ignored_by_keyboard`（手机 / 网页来源触发内部动作时不应出现 mouse 模式误拦截）。
- 日志不包含语音内容；提交反馈前无需额外脱敏，但不要公开发布含本机路径的完整日志。

## 验证边界

- 已完成的自动化验证：`MouseModeControllerTests`（状态机、方向边沿驱动、加速数学、斜向归一化、边界钳制、OK / 菜单 / 返回行为、方向键双击映射与弹回、300ms 轻点/窗口边界、长按不构成轻点、第二次按下抑制移动、模式外不响应、新动作的 displayName / category / Codable 往返、辅助功能权限缺失拒绝注入）、本地化键一致性、既有 ShortcutCaptureMonitor / 手势识别 / Fn 会话回归。
- 自动化不能覆盖的部分：真实遥控器的 HID 边沿拦截、事件抑制器对方向键原生事件的抑制、真实光标移动手感、双击弹回的真实视觉表现、菜单栏图标真实渲染、多显示器坐标。
- **真机验收状态：全部用例均未经真实遥控器与真实用户环境验证。** 在完成用例 1～6（含 3A）和回归项前，本功能不得出现在正式版发布说明中。
