# 键位方案测试手册

## 适用版本或分支

- 宿主分支：`codex/button-profiles-sidebar`
- 私有模块分支：`codex/button-profiles-actions`
- 当前状态：Phase 1–3 代码完成，尚未发布，真实环境验证中。

## 测试前准备

1. 使用 `SAYALL_MACRO_PLATFORM_PATH` 注入对应私有模块构建无线麦。
2. 准备至少一只真实遥控器；双设备用例准备两只。
3. 安装 Codex、Claude、cmux；媒体回归准备网易云音乐。
4. 准备辅助功能和输入监控的已授权、未授权、撤销授权状态。
5. 备份本机 `Remote Mic/Macros` 配置目录，不提交真实配置、设备 ID 或输入框学习数据。

## 自动化已覆盖

- `button-profiles.json` 公开格式 v1 round-trip、未知未来格式安全拒绝和未发布旧文件隔离。
- 宿主动作与组合动作类型化绑定、宿主 payload 编解码和重启恢复。
- 编辑草稿在保存前不改变控制器，最后一次性提交名称、使用方式、App 规则和全部绑定。
- 方案创建、复制、重命名、删除、默认选择、手动切换和 20 字符限制。
- 精确 Bundle ID 自动规则、未命中回默认、Remote Mic 前台保持当前。
- 两只遥控器的方案和规则隔离；自动模式重启恢复。
- 删除当前或无关方案后的正确回退；组合动作新版本同步到所有方案。
- 功能访问关闭后停止监听和执行。
- 页面不使用 Sheet、Popover 或长 Menu；中英文静态 key 完整；设置按键步骤可在页面内录入并复用本机快捷键。
- 三步向导、每步 Return 默认操作、快捷键录入局部取消和长快捷键完整换行。
- 监听模式下 Left/Right 存在键位方案单击绑定时优先执行私有动作；没有覆盖绑定时继续使用原生方向键长按连发。
- 用户界面不会显示 App 内部标识或自动切换实现术语；方案为空时存在大号主创建按钮。

## 人工必测 1：三步创建向导与 Return

步骤：进入独立“键位方案”，点击“新建键位方案”，依次完成“基本设置（名称与使用方式）→ 设置按键 → 确认保存”。分别验证空名称按 Return、有效基本设置按 Return、第二步按 Return、确认页按 Return、自动模式未选择 App 和上一步。

预期：默认页面只显示已保存方案摘要；没有任何方案时，内容区中央显示大号醒目的“新建键位方案”主按钮；名称不单独占一步；空名称不能下一步，有效基本设置按 Return 与点击“下一步”等价，第二步 Return 进入确认，第三步 Return 保存；新自动方案没有 App 时不能下一步；步骤标题和固定底部操作始终可见；确认页准确汇总配置；最后保存后才创建方案。

失败判定：设置一股脑全部铺开、没有明确顺序、门禁失效、底部按钮不可达、确认摘要错误或未保存方案提前生效。

## 人工必测 2：草稿、取消与统一保存

步骤：编辑一个正在使用的方案，修改名称、使用方式、App 规则和多个按键；在步骤间来回切换后取消。重新编辑并在确认页保存。保存前后分别用真实遥控器触发。

预期：步骤切换不丢草稿；取消后所有已保存配置和实际执行保持原样；保存前仍执行旧绑定；最终保存后全部修改同时生效，不出现半保存。

失败判定：切换步骤丢内容、取消后部分修改已落盘、选择动作时立即影响运行或保存只更新部分字段。

## 人工必测 2A：方案管理与手动切换

步骤：创建、复制、重命名、设置默认、立即使用和删除非默认方案；重启 App 后复查。

预期：状态全部保留；“立即使用”明确进入手动模式；默认方案不能删除；复制保留绑定；切换后真实遥控器只执行当前方案。

失败判定：重启丢失、执行旧方案、删除默认方案或单击/双击/长按串扰。

## 人工必测 2B：实体按键仅在第二步用于选键

步骤：分别停留在摘要页、基本设置、设置按键和确认保存，逐一按真实遥控器可见按键；最后离开页面重复触发。

预期：只有“设置按键”步骤更新遥控器图片和当前按键，且不执行动作；摘要页、其他步骤和离开页面后都正常执行当前方案，不发出系统错误音。

失败判定：图片不更新、按键同时执行动作、有错误音，或离开页面后仍被拦截。

## 人工必测 2C：动作类型完整性

步骤：在“配置按键”步骤分别选择禁用、基础按键、系统与媒体、已保存自定义快捷键、页面内新录入快捷键、预置 App、自定义 App 和组合动作；进入确认页保存，重启后逐项执行。

预期：动作仅在当前步骤按语义分组平铺；新快捷键录入后直接进入本机快捷键库并可被组合动作复用；选择时只更新草稿，最终保存后统一生效；禁用会消费触发，取消绑定后沿用普通按键映射；各方案独立保存并执行。

失败判定：只能选组合动作、使用混合长下拉、动作串到其他方案、禁用仍执行或重启丢失。

## 人工必测 2D：快捷键完整显示与局部取消

步骤：在“我的快捷键”开始录入 `Command + Option + ←`，先点击“取消录入”；再次录入并保存，缩放窗口检查卡片，再继续完成向导。

预期：取消只停止本次快捷键录入，不退出方案、不丢草稿；完整快捷键可换行显示，不隐藏方向键或修饰键；录入期间 Return 不会误进入确认页。

失败判定：取消退出整个流程、草稿丢失、快捷键仍以省略号截断或录入按键推进向导。

## 人工必测 3：按 App 自动切换

步骤：分别把 Codex 和 Claude 分配给不同方案，设置默认方案并开启自动；依次切换 Codex、Claude、cmux 和未配置 App。

预期：精确命中对应方案；未配置 App 回默认；切换本身不执行动作；同一 App 重新分配后只命中新方案。

失败判定：按显示名称猜测、出现多个同时生效方案、未命中不回默认或切换时误触发动作。

## 人工必测 3A：暂停与恢复自动切换

步骤：让 Chrome 方案关联 Chrome 并开启自动模式；回到无线麦页面检查当前方案按钮。对另一套方案选择“改为手动使用”，再回到 Chrome 摘要点击“开启自动切换”；依次切换 Chrome 和未配置 App。

预期：自动状态下当前方案不能因误点“立即使用”而关闭监听；手动状态保留 App 关联但明确显示“自动切换已暂停”。恢复后 Chrome 前台使用 Chrome 方案，其他 App 使用默认方案。

失败判定：页面状态与关联规则矛盾、没有恢复入口、恢复后仍不监听或未配置 App 不回默认。

## 人工必测 4：Remote Mic、锁屏和功能关闭

步骤：让某 App 方案生效后打开 Remote Mic 设置页，锁屏/解锁，再关闭功能访问或切回手动模式。

预期：Remote Mic、锁屏和空 Bundle ID 保持当前；关闭后不继续自动切换、不执行私有绑定；普通按键、HID、蓝牙和语音不受影响。

失败判定：设置页导致方案跳变、关闭后仍监听、普通按键或 RC003 语音回归。

## 人工必测 5：双遥控器

步骤：两只遥控器分别配置不同方案、默认和 App 规则，在相同前台 App 下交替触发同一物理键。

预期：每只遥控器只执行自己的当前方案，页面和重启后均不串数据。

失败判定：方案、规则、当前选择或执行结果跨设备污染。

## 人工必测 6：第三方 App 与权限

步骤：覆盖 App 冷启动、后台、已在前台、窗口关闭、侧边栏抢焦点；分别执行打开 App、快捷键、学习输入框和 macOS 快捷指令步骤；撤销辅助功能后重试。

预期：动作顺序正确，失败原因准确；权限失败不停止 HID 监控，不把 App 缺失或输入框失效误判为权限失效。

失败判定：假成功、误聚焦、权限状态错误、HID 停止或配置被清除。

## 人工必测 6A：Chrome 方向键快捷键与 Fn 规范化

步骤：分别录入 `Command + Option + ←`、`Command + Option + →` 并绑定 Chrome 方案的左、右键单击；普通按键页保持 Left/Right 方向键。Chrome 前台打开多个标签页后使用真实遥控器执行；重启后复测，并检查升级前已保存且曾显示 `fn` 的方向键记录。

预期：新旧方向键记录均完整显示并只发送 Command、Option 与方向键，不附带 `fn`；遥控器左、右键切换 Chrome 标签页，不被普通方向键原生透传截走；非方向功能键仍保留真实 Fn。

失败判定：方向键仍显示或发送 Fn、旧记录继续失效，或真实功能键的 Fn 被删除。

## 人工必测 7：页面布局与本地化

步骤：在宿主最小支持窗口依次打开侧边栏“组合动作”和“键位方案”，创建足够多的方案、动作和 App 规则；检查中文、英文、浅色和深色。

预期：摘要页使用扁平信息分区，不把说明伪装成大按钮；查看状态的方案栏颜色足够浅，编辑时方案栏完全隐藏；第二步遥控器固定可见，仅右侧动作列表滚动；已设置按键在遥控器图上标记，点击摘要列表时对应位置加强高亮。三步标题、按法、操作搜索、App 网格、固定底部操作和滚动均可访问；长快捷键完整换行；中文字号不小于 12pt；无原始 key、长下拉或连续弹窗。App 只显示图标和名称，不显示 `com.xxx` 等内部标识；已卸载 App 使用普通的不可用提示。

失败判定：裁切、窗口几何变化、页面错乱、控件不可达、字体过小或本地化缺失。

## 稳定功能回归
