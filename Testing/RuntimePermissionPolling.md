# 运行时共享权限轮询回归

适用：共享权限监视器候选分支与支持订阅协议的私有 Siri Remote 包。
此改动不改变 UI、持久化或权限要求。全部实机项目尚待验证。

## 准备

- 使用带正确来源信息的候选 App。保留原设置。
- 准备现有 HID 遥控器和受支持 Siri Remote；权限操作由测试者手动执行。
- 不同时运行两个 SayAll 实例。收集 App 自产诊断，不记录输入内容。

## 步骤与预期

| 步骤 | 预期结果 | 失败判定 |
| --- | --- | --- |
| 只启用 HID 映射 | 首次按键可用；共享轮询启动 | 首次按键无效或重复启动 |
| 再启用 Siri Remote | 两类按键都可用；共享轮询仍只有一个 | 一类设备影响另一类或重复查询 |
| 手动撤销输入监控权限 | 下一次查询完成后走现有停止与取消路径 | 按键、修饰键、触摸或语音残留 |
| 恢复权限并走原有重新连接流程 | 第一次按键和第一次语音可用 | 必须多按一次或重启电脑 |
| 撤销辅助功能权限 | HID 按原规则停止；Siri 输入监控结果不被误判为撤销 | 混淆两类权限或错误清理 |
| 停止全部适配器 | 最后一个订阅取消后定时器停止 | 无订阅仍查询 |
| 快速关闭再启用映射 | 旧查询不停止新会话 | 迟到回调改变新代次 |
| 切换前后台、睡眠与唤醒 | 保持既有恢复行为 | 事件重复、丢失或不能恢复 |

## 稳定功能与日志

极速按下/释放至少十次，连续短句至少十次。
验证首字、尾字和第三方语音工具最终文字。
正常松键不得 flush；正常结束的 pending 与 interrupted 均为零。
检查普通按键、媒体键、App 切换器、触摸与多设备隔离。
检查默认关闭、明确关闭、开启、使用后再关闭四种 Siri 开关状态。

`RUNTIME PERMISSION POLL` 仅记录订阅数量、开始/停止和迟到代次。
状态不变时不得逐 tick 刷日志。
成功和失败以最终动作及语音结果为准，不以订阅成功为准。

## 自动化边界

`HIDPermissionPollTests` 验证调度、系统调用次数、线程与订阅状态。
私有 `PermissionObservationTests` 验证取消、重启与本地后台兜底。
这些测试没有证明真实权限变化、真实遥控器或文字上屏。
