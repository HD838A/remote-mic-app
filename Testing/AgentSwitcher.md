# Agent 切换面板验收

## 用户路径

在「按键」页选择遥控器的菜单键，将单击动作设为「自定义 → 切换 Agent」。在下方勾选需要的 App（默认 Cursor、Codex），可通过「添加 App」加入其他应用。旧按键映射不会自动改动。

按菜单键打开屏幕中央的 App 图标面板，左右键循环选择，OK 打开或切入选中的 App，返回或再次按菜单取消。打开应用后，面板确认目标已成为前台再关闭。鼠标可直接点选，键盘支持左右、Return 和 Escape。「预览切换面板」供鼠标/键盘试用，不绑定某台遥控器。

未安装的目标不会进入运行面板；全部不可用时显示空状态。打开失败保留面板供重试或取消；30 秒无操作、设备断开、输入监听重置、休眠或退出时关闭。其他普通按键退出面板并继续原动作；语音按钮仍使用原来的即时按下/释放链路。

## 自动化覆盖

- `AgentSwitcherControllerTests`：环绕选择、确认后前台验证、失败与重试、空状态、取消、超时、过期回调及 owner 隔离。
- `AgentSwitcherInputRoutingTests`：真实 HID report parser 到模态路由；方向和 OK 不泄漏原映射，关闭后的释放不触发双击/长按，重复 report 不重复移动，开启时清除旧计时器，断连/权限失败恢复，原生 Command-Tab 修饰键释放。
- `AgentSwitcherSettingsTests`：默认 Cursor/Codex、显式空列表、去重与 32 项上限、持久化、旧格式导入和配置隔离。
- 原快捷键录入、App 聚焦、HID、Apple Remote、移动端和语音测试仍作为回归集执行。

## 本机与真实设备步骤

1. 在当前构建中绑定菜单键，选择 Cursor 和 Codex。菜单 → 右 → OK 应只切入 Codex；菜单 → 左应从首项环绕至末项。
2. 连续开启/取消两次，再使用键盘左右与 Escape，确认面板重复打开后的监听正常。
3. 按住方向、OK、菜单，确认一次物理按下只生效一次；给 OK 配置双击/长按动作后再确认，不能触发这些原动作。
4. 用返回、菜单取消后按方向键，确认恢复原映射。语音按下和释放必须保持即时，不能因面板停留而延后。
5. 关闭所有 Agent、删除或移动一个所选测试 App，验证冷启动、不可用目标、空列表、失败重试。不得读取第三方 App 私有文件。
6. 面板打开时断开所属遥控器、关闭映射、撤销权限、休眠/唤醒，确认没有残留拦截。另一设备断开不能取消所属设备面板。
7. 检查中文浅/深色、英文，以及 2 个和超过 5 个目标。箭头选择滚动区域外目标时必须自动滚入视野。
8. 分别验证小米、Siri Remote 和移动端。手机与 Watch 目前沿用已有移动来源分组，不能据自动化 owner 测试宣称同时多移动设备完全隔离。

## 证据与边界

截图和自动化只证明对应 UI / 软件路径。真实蓝牙遥控器、系统权限切换、多屏/全屏、第三方 App 冷启动和输入焦点仍须单独记录，未实测项保持候选状态，PR 保持 Draft。此功能切换应用，不选择单个 Agent 内的任务，也不自动发送聚焦快捷键。

日志使用 `AGENT SWITCHER` 的 presented/navigate/submitted/completed/attempt_failed/cancelled 阶段；同次会话带进程内 `operation_id`，重试带 `attempt_id`；配置日志仅记录数量。不得写入设备 owner、App 内容、路径或键入文本。
