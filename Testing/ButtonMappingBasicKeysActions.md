# 按键映射新增窗口/系统动作测试手册

## 适用范围

- 分支：`feat/basic-keys-actions`（基线 `origin/main` `32f0ccd`，版本 1.9.21）
- 平台：macOS；任意已连接的遥控器或实体按键设备均可，动作本身与硬件型号无关
- 目标：确认「按键映射」新增的十个固定动作——`最小化窗口`、`关闭所有窗口`、`新建标签页`、`下一个标签页`、`上一个标签页`（基础按键）与 `切换全屏`、`调度中心`、`应用程序窗口`、`聚焦搜索`、`锁定屏幕`（系统与媒体）——分别投递正确的按键事件，不影响既有动作，且中英文名称完整不裁切。

## 测试前准备

1. 安装并启动包含本改动的 Mac App（`dist/SayAll.app`）。
2. 授予辅助功能权限并启用「自定义按键映射」。
3. 打开「设置 → 按键」，进入任意一个按键（如「确定键」）的动作编辑器。
4. 记录测试开始时间，完整保留 `~/Library/Logs/RemoteMic/runtime.log`。

## 用例一：动作选择器展示与选择

1. 打开动作编辑器，切换「基础按键」筛选。
2. 切换「系统与媒体」筛选。

预期结果：十个新动作分别出现在对应分组（`最小化窗口`/`关闭所有窗口`/`新建标签页`/`下一个标签页`/`上一个标签页` 在「基础按键」；`切换全屏`/`调度中心`/`应用程序窗口`/`聚焦搜索`/`锁定屏幕` 在「系统与媒体」），中文名称在默认窗口宽度下不换行裁切；切到英文时同样完整显示或按既有裁切规则省略（与 `Delete (Backspace)` 等既有长名称一致）。

失败判定：任一新动作缺失、分组错误、点击无响应或选中态未持久化。

## 用例二：窗口管理动作实际生效（真机）

针对以下每个动作，把测试按键映射为该动作，在一个已打开多个窗口的应用（如 Finder 或 Safari）中触发：

| 动作 | 触发前状态 | 预期系统效果 |
| --- | --- | --- |
| 最小化窗口 | 前台窗口未最小化 | 前台窗口最小化进入 Dock |
| 关闭所有窗口 | 目标应用打开 2 个以上窗口 | 该应用全部窗口关闭，应用本身不退出 |
| 新建标签页 | 前台应用支持标签页（如 Safari） | 新增一个标签页并成为前台标签 |
| 下一个标签页 | 前台应用打开 2 个以上标签页 | 切换到下一个标签页 |
| 上一个标签页 | 同上 | 切换到上一个标签页 |
| 切换全屏 | 前台窗口处于非全屏 | 前台窗口进入全屏；再次触发恢复窗口模式 |
| 调度中心 | 任意前台状态 | 打开 Mission Control 总览 |
| 应用程序窗口 | 前台应用打开多个窗口 | 打开该应用的窗口 Exposé |
| 聚焦搜索 | 任意前台状态 | 打开 Spotlight 搜索框 |
| 锁定屏幕 | 任意前台状态 | 系统锁屏，需要密码/生物识别解锁 |

失败判定：任一动作未触发对应系统效果、触发了错误的系统功能，或需要多次按键才生效。

## 用例三：连发策略

1. 长按映射为「最小化窗口」「关闭所有窗口」「新建标签页」「下一个/上一个标签页」「切换全屏」「锁定屏幕」的按键约 2 秒。
2. 长按映射为「调度中心」「应用程序窗口」「聚焦搜索」的按键约 2 秒。

预期结果：第 1 步中的动作只触发一次，与既有 `Command-W`/`Command-Q` 等命令组合键行为一致；第 2 步中的动作允许连续触发（与 `显示桌面`/`上下文菜单` 行为一致），但因系统侧本身是切换/呼出行为，重复触发不产生破坏性副作用。

失败判定：第 1 步中任一动作被连续触发多次（例如反复关闭新窗口、反复切全屏导致闪烁），或第 2 步动作完全无法通过长按重复呼出。

## 稳定功能回归

- 原有全部「基础按键」「系统与媒体」「自定义动作」下的动作分组、显示名称和连发策略不变。
- 「打开自定义 APP」「自定义快捷键」「聚焦输入框」等自定义动作分组不受影响。
- 双击、长按三种触发入口进入编辑器后自动滚动定位不变。
- 语言切换（中文简体/繁体/英文）后动作分组数量、既有动作名称保持不变。

## 验证边界

- 已完成（自动化）：`swift build --disable-keychain` 通过；`swift test --disable-keychain`（648 项，51 个 Suite）全部通过，其中新增 `newWindowAndSystemActionsPostTheExpectedKeyCodesAndModifiers` 覆盖十个新动作的按键码与修饰键组合，`buttonActionsAreSeparatedIntoClearFlatCategories`、`customShortcutsNeverRepeatWhileNavigationActionsStillCan` 覆盖分组与连发策略，`LocalizationTests` 确认三语言 key 完整对齐。
- 已完成（离屏截图）：使用 `scripts/build-app.sh` 产出的生产 `dist/SayAll.app`，通过 `REMOTE_MIC_SETTINGS_SCREENSHOT_*` 环境变量驱动隐藏离屏渲染入口，在 1020×772 生产默认尺寸下生成中文浅色、中文深色、英文浅色三张动作选择器截图（`Screenshots/button-mapping-basic-keys-actions/`），确认十个新动作正确显示、未裁切成空白、暗色模式对比度正常。
- 未完成（真机）：本手册用例二、用例三描述的实际系统效果（真的最小化窗口、真的锁屏、真的呼出 Mission Control/Spotlight 等）尚未在真实遥控器与真实前台应用上逐项验收；自动化测试只能证明 `KeyboardInjector.send` 调用了正确的 `keyPoster(keyCode, flags)`，不能证明 macOS 收到该 `CGEvent` 后确实执行了对应系统行为。
- 未完成（真机）：多显示器、Split View、全屏空间切换等窗口布局下的行为未覆盖。
