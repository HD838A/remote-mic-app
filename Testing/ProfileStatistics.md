# 个人中心统计页测试手册

适用版本：当前待验证 PR 或已合入 `main` 的精确 Commit；历史页面重构分支为 `codex/profile-sidebar-layout`，基线为 `ca2cd7c6e53e64de539621ef03529f529855e238`。

## 测试前准备

1. 使用包含本次改动的 Mac 构建包启动无线麦SayAll.app。
2. 确认应用语言分别设置为简体中文和英文，系统外观分别测试浅色与深色。
3. 如需验证真实数据，完成至少一次实体按键和一次语音输入，并确认目标 App 处于前台。

## 用例

### 个人中心布局

1. 打开设置并进入侧边栏“个人中心”。
2. 在默认窗口尺寸查看顶部四项 KPI、左侧按键/动作排行榜和右侧使用日历；语音时长排行榜应位于使用日历下方。宽窗口的四项 KPI 必须保持单行。
3. 使用 `SettingsScreenshotRenderer` 在 `800 × 650` 做窄宽压力渲染，再在真实生产窗口最小尺寸 `1020 × 772` 重复查看和点击；不得把离屏尺寸表述为生产窗口支持范围。
4. 在真实生产窗口中从个人中心页面顶部向下滚动到最底部，再向上滚回顶部。

预期：顶部主导航组整体上移到内容区顶部基准，不贴住窗口最上沿；底部个人中心入口保持固定；页面标题显示“个人中心”；个人中心位于侧边栏最底部，侧边栏不再显示独立分享入口；未登录时个人中心入口显示“我”，已登录时完整显示邮箱 `@` 前的文字，每超过 8 个字符换行，保持 13pt；个人中心标题下首先显示分享模块，之后才是四项 KPI；分享在页面内展开和收起，不影响统计数据；统计卡片、排行和日历采用与遥控器卡片一致的淡底色、10pt 圆角与细描边，不使用玻璃材质；本机隐私说明使用普通图标文字；宽窗口四项 KPI 单行排列，窄窗口可自适应为两列且不被截断；左侧显示按键/动作排行榜，右侧依次显示使用日历和单次语音时长排行榜；三个排行榜各最多显示 10 条；滚动到最底部后，单次语音时长排行榜的最后一条及“查看全部回眸”按钮完整可见，继续向上滚动可以回到页面顶部，不出现底部内容被裁切或滚动边界提前结束；日历只展示最近半年，并在面板内尽可能放大方格，方格宽高相等、颜色为 Codex 风格蓝色；固定 26 列、7 行，连续展示截至当天的 182 天；左上角为最老日期，按列先从上到下、再向右递增，右下角最后一格为当天，无首尾补位空格；星期标签从首格实际星期开始轮转，底行为当天星期；七个星期行必须全部可见，空间不足时可横向滚动查看完整半年日历且方格不会被压缩；月份 / 星期标签不重叠；浅色和深色均有足够对比度；不出现“少—多”图例。

失败判定：首项仍与窗口顶部保留大块空白、登录态文案泄漏完整邮箱、登出后仍保留用户名、出现横向裁切、方格变成长方形、同一行被错误显示为连续日期、星期标签与日期所在行不一致、出现首尾补位或未来日期、右下角不是当天、中文小于 12pt、排行榜或日历无法滚动查看、滚动到底部后最后一条排行或“查看全部回眸”仍不可见、无法回滚到顶部，或出现其他页面内容。

### 侧栏账号名

1. 使用邮箱前缀分别为 8 位、9 位和超过 16 位的测试账号登录。
2. 在 `1020 × 772` 窗口查看侧栏底部。
3. 退出 App，再打开 App，核对名称。
4. 切换中英文、浅色和深色，再退出账号。

预期：完整显示邮箱前缀，不显示 `@` 和域名；每八位换行，没有省略号；旧登录会话无需重新登录即可恢复完整名称；退出账号后显示登录入口。

失败判定：仍只有六位、漏字、文字小于 12pt、名称裁切，或退出后仍显示旧名称。

### 统计数据与兼容性

1. 检查累计按键、累计语音、本周按键和最长单次语音 KPI。
2. 检查常用快捷键 / 动作、实体按键排行和单次语音时长排行。
3. 使用没有历史数据的全新用户默认设置打开页面。
4. 使用旧版本产生的本地统计数据启动页面。

预期：总量统计仍保留；空数据有明确空状态；旧数据可正常解码，缺少目标 App 名称时显示“未知应用”；单次时长按时分秒显示，不截断长会话。

### 回眸联动

1. 点击日历中的任意有效日期。
2. 点击单次语音排行中的任意一行。
3. 点击排行榜底部“查看全部回眸”。

预期：三种入口均进入侧边栏“回眸”，不会打开弹窗，也不会修改其他模块的数据。

### 稳定回归

1. 执行现有按键映射操作和语音开始 / 结束流程。
2. 返回个人中心确认统计仍会增长。
3. 在浅色、深色和两种窗口尺寸下重复进入其他设置页。

预期：按键响应、语音生命周期、连接和回眸页面行为与改动前一致。

## 验证命令与边界

- 自动化：`swift test --disable-keychain --disable-sandbox`。
- 页面回归：`swift test --disable-keychain --disable-sandbox --filter SettingsPageRegressionTests`。
- 截图：使用 `SettingsScreenshotRenderer` 生成 `1606×979`、`1020×772`、`800×650` 的浅色 / 深色中文截图，输出到 `Screenshots/profile-share-card-style/`，另设置 `REMOTE_MIC_SETTINGS_SCREENSHOT_EXPAND_SHARE=1` 检查个人中心二维码展开状态。
- 代理截图验证不能替代真实遥控器、蓝牙、目标 App 前台切换和真实语音输入；这些仍需在实际 macOS 环境人工验收。

## 日志收集

复现统计或联动问题后，保留对应时间段的应用日志（设置页日志入口“在 Finder 中显示”），并记录系统版本、窗口尺寸、语言、外观、是否有旧统计数据及触发入口；不要收集语音正文、音频或其他 App 私有文件。

## 2026-10-10 当天末格回归

按新排列检查连续 182 天。分别覆盖今天为星期日至星期六，以及中英文标签。月标签对齐日期列，星期标签与方格等高。点击首格、末格和跨月日期，核对提示日期并进入回眸。

自动化与截图结果见 [Bug 记录](../Bugs/2026-10-10-calendar-ending-today.html)。日历日期、月份、今天描边和提示均使用现有上海时区。统计存储、排行、颜色和日期跳转行为保持。纯同步布局没有取消、超时或重试分支，不新增高频日志。实体硬件与第三方输入仍按原手册验收。

## 2026-10-12 日历显示与悬停回归

1. 在 `1020 × 772` 生产最小窗口打开个人中心。不要先横向滚动。核对右下角描边格为上海时区当天。
2. 调宽窗口后再调回最小尺寸。核对当天仍可见。向左滚动可看更早日期。
3. 悬停在当天、零记录日期和有回眸的日期。提示应含日期、回眸条数、按键次数和语音时长。中英文、浅深色均重复。
4. 同一次语音同时保存文字和录音，再保存一次只有录音的语音。当日回眸应计 2 条，不能计 3 条。删除后返回个人中心，数量应刷新。
5. 在上海时区午夜前打开页面并保持打开。午夜后下一次分钟刷新时，末格应改为新一天，旧当天移至前一格。睡眠后唤醒也应刷新。
6. 点击日期，确认日期选中卡出现；点击“在回眸中查看”进入回眸。逐一进入按键、连接、回眸、设置、个人中心，确认窗口几何与滚动正常。

预期：日历高度只包含月份、间距与七行方格，最小方格时为 142 点，最大方格时为 240 点。日历下方不保留原来的固定空白。没有历史时各数量为零。

失败判定：未滚动时看不到当天、缩放后当天被藏住、提示缺字段或重复计数、七行被裁切、末格日期未刷新、页面导航改变窗口几何。

证据见 [日历显示与悬停 Bug 记录](../Bugs/2026-10-12-calendar-details.html)。自动化验证几何、日期与数量；实际生产页面截图验证布局与本地化。跨午夜真实等待及用户已有数据需现场复验。此同步显示链路没有取消、重试、超时或网络请求，不写高频悬停日志，也不记录日期、回眸正文或历史身份。

## 2026-10-21 通用本地数值摘要

适用分支：`codex/local-usage-ledger`。本节只验证本地统计。

1. 使用旧版本的合成设置启动。核对累计按键、累计语音和最长单次没有清零。
2. 按一次普通按键，再执行一次长按连发。每个逻辑按下只增加一次。
3. 开始语音，等待首个音频包，再暂停音频。结束后核对只累计有效 16 kHz PCM 样本时长。
4. 连续开始、结束两次语音。核对会话独立，音频多路转发不重复累计。
5. 跨上海时区午夜完成一次语音。核对本地数值摘要按有效音频拆分日时长，完整单次归属开始日。
6. 语音期间中断 App，再启动。核对未完整记录的日期标为不完整，不补造时长。
7. 回退旧版并产生统计，再升级。核对旧累计值保留，缺失区间不推算为完整日报。

预期：旧统计键、页面日期口径和文件保持兼容。新增摘要独立保存数值，不保存按键内容、目标 App、音频或文字。未知摘要版本保持原数据。

失败判定：累计值被清零、等待或暂停被计时、同一音频被重复计数、跨日拆分丢失时长、回退后数据被覆盖，或语音首包与尾音出现回退。

自动化：`swift test --disable-keychain --filter LocalUsageLedgerTests`。覆盖日期、有效样本、跨日拆分、异常恢复和旧版兼容。

实机边界：自动化不能验证硬件首包、尾音或目标 App 最终文字。各硬件真实语音、极速按放、连续会话、断连恢复及跨午夜等待仍需按原手册验收。仅保留脱敏的计数、时长和结果；不要收集音频或文字。
