# 个人中心统计页测试手册

适用版本：`feature/profile-statistics`，基于 `origin/main` SHA `9945224cc9d411d21b6cc06a4eb378f8c9785270`。

## 测试前准备

1. 使用包含本次改动的 Mac 构建包启动无线麦SayAll.app。
2. 确认应用语言分别设置为简体中文和英文，系统外观分别测试浅色与深色。
3. 如需验证真实数据，完成至少一次实体按键和一次语音输入，并确认目标 App 处于前台。

## 用例

### 个人中心布局

1. 打开设置并进入侧边栏“个人中心”。
2. 在默认窗口尺寸查看顶部四项 KPI、左侧排行榜和右侧使用日历。
3. 将窗口调整为 `800 × 650`，重复查看。

预期：页面标题显示“个人中心”；顶部 KPI 不被截断；排行榜和日历并列；日历方格宽高相等、颜色为 Codex 风格蓝色；浅色和深色均有足够对比度；不出现“少—多”图例。

失败判定：出现横向裁切、方格变成长方形、中文小于 12pt、排行榜或日历无法滚动查看，或出现其他页面内容。

### 统计数据与兼容性

1. 检查累计按键、累计语音、本周按键和最长单次语音 KPI。
2. 检查常用快捷键 / 动作、实体按键排行和单次语音时长排行。
3. 使用没有历史数据的全新用户默认设置打开页面。
4. 使用旧版本产生的本地统计数据启动页面。

预期：总量统计仍保留；空数据有明确空状态；旧数据可正常解码，缺少目标 App 名称时显示“未知应用”；单次时长按时分秒显示，不截断长会话。

### 回眸联动

1. 点击日历中的任意有效日期。
2. 点击单次语音排行中的任意一行。
3. 点击排行榜底部“查看全部回眸”。

预期：三种入口均进入侧边栏“回眸”，不会打开弹窗，也不会修改其他模块的数据。

### 稳定回归

1. 执行现有按键映射操作和语音开始 / 结束流程。
2. 返回个人中心确认统计仍会增长。
3. 在浅色、深色和两种窗口尺寸下重复进入其他设置页。

预期：按键响应、语音生命周期、连接和回眸页面行为与改动前一致。

## 验证命令与边界

- 自动化：`swift test --disable-sandbox`。
- 页面回归：`swift test --disable-sandbox --filter SettingsPageRegressionTests`。
- 截图：使用 `SettingsScreenshotRenderer` 生成 `1020×772`、`800×650` 的浅色 / 深色中文截图，并与 `dist/designs/profile-v4/profile-v4-dark-refined.png` 对比。
- 代理截图验证不能替代真实遥控器、蓝牙、目标 App 前台切换和真实语音输入；这些仍需在实际 macOS 环境人工验收。

## 日志收集

复现统计或联动问题后，保留对应时间段的应用日志（设置页日志入口“在 Finder 中显示”），并记录系统版本、窗口尺寸、语言、外观、是否有旧统计数据及触发入口；不要收集语音正文、音频或其他 App 私有文件。
