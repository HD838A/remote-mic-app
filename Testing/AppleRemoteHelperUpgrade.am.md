本候选让 App 更新包携带系统 helper 升级所需文件。
苹果遥控器默认关闭。用户主动启用后才准备其服务。
后台恢复不弹安装或音频授权窗口。
组件缺失或过旧时，用户点击重新准备语音才请求授权。
此能力尚未完成真实 Sparkle、系统替换与实体音频验收。

## A 用户预期

| 场景 | 预期结果 |
| --- | --- |
| 未启用的普通用户 | 启动、更新、重启、设备发现均不安装或启动 Siri 服务 |
| 已安装旧 helper，更新 App | 启动保持静默；主动启用或重试时允许一次安装 |
| 安装完成后重启 App | 不再次请求同版本安装 |
| 系统 helper 已是新版本 | 直接继续，不自动降级 |
| 用户 Cancel | 保存等待状态，停止自动准备，不因连接重试新增窗口 |
| Cancel 后完整重启 App | 保留等待状态；点击重新准备语音才再试 |
| 旧内测配置 | 设备档案和旧向导选择不自动开启；需要主动启用一次 |
| 用户关闭功能 | 停止音频和 HID 服务；保留已安装组件及同意记录 |
| 未接入私有 Siri 包 | 不携带升级副本，也不请求安装 |

安装授权与首次音频同意是两项不同操作。
音频同意记录保留后，重启不应再次询问音频授权。
App 必须核对实际运行的 helper，才能准备音频。

helper 的升级副本放在 `Contents/Library/LaunchServices`。
原 `Contents/Helpers` 副本继续供 PKG 使用。

打包脚本明确构建私有包的 helper 产品。
不得从宿主旧公共产品目录选取同名文件。
App 校验脚本检查两份文件相同、签名有效和元数据存在。
未完成公证的本地候选不用于用户分发。
本地结构校验未启用生产 Web Relay 配置门禁。
发布构建仍须注入生产配置，并执行完整发布校验。

## C 实机步骤

准备：使用正式签名并公证的完整候选 App 更新包。
在 Apple Silicon 与 Intel Ventura 分别测试。
每轮记录 App 版本、系统版本与遥控器型号。
准备旧 PKG 环境及未安装 helper 的独立环境。

1. 从旧版 App 经真实 Sparkle 更新。
2. 确认 App 启动没有自动弹窗。
3. 在向导选择苹果遥控器，或在按键页主动启用。
4. 允许一次系统安装授权。
5. 核对新 helper 已运行及真实音频可用。
6. 完全退出并重新启动三次。
7. 确认没有同版本安装或音频授权窗口。

另测首次 Cancel：取消后等待 60 秒，并触发连接恢复。
预期不新增窗口；完全重启后仍不弹窗。
在苹果遥控器按键页点击“重新准备语音”，才可以再次请求授权。
向导的重新连接及失败恢复也能主动重试。
宿主保存等待用户操作的状态，重启后不自动准备音频。

在未安装 helper 的环境中，主动启用后允许安装，无需另找 PKG。
未启用时重复启动三次，系统 helper 必须仍未安装。
分别验证开关缺失、明确关闭、开启、使用后关闭四种状态。
关闭后再次开启，旧音频进程和连接的迟到回调不得改变新状态。

系统 helper 已是新版本时，另测取消首次音频授权。
取消后重启不得再弹；点击重新准备语音可恢复。
回滚旧 App 时，helper 不自动降级。

连续做 10 次极速短按和 3 次正常语音会话。
确认首字快、尾字全、MiRemoteV 2ch 与最终文字正常。
最后执行原卸载 PKG，核对系统配置恢复与废纸篓记录。
RC001、RC003 的稳定语音路径必须保持原行为。

## D 失败与日志

重复安装窗口、旧 helper 仍在运行或没有声音，均判定失败。
安装接口返回成功不能单独证明通过。
仅看到 ready 也不能替代遥控器真实声音与最终文字。

核对 `APPLE REMOTE HCI upgrade` 的检查与最终结果。
核对 helper 启动版本及音频授权链路。
收集同一时间段的脱敏日志，不提供密码或授权字节。
本轮尚未改动本机系统 helper。
