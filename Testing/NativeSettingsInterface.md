# 原生设置界面测试手册

## 适用范围

- 分支：`codex/native-system-settings-ui`；合入版本以目标提交为准。
- 平台：macOS 14 及以上；Intel 兼容构建最低 macOS 13。
- 页面：按键、统计、回眸、连接、权限、关于及关于页内的版本历史。
- 目标：验证设置窗口使用 macOS 原生标题栏、侧栏、搜索、导航、分组表单、字体、图标、间距和系统材质，并确认既有连接与语音功能没有回归。

## 测试前准备

1. 退出其他无线麦SayAll.app 实例。
2. 使用 Xcode 27 工具链构建：`DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer CONFIGURATION=debug scripts/build-app.sh`。
3. 启动 `dist/SayAll.app`，完成首次设置向导并打开设置窗口。
4. 分别准备中文和英文、浅色和深色外观；窗口至少检查默认 `920 × 700` 与最小 `800 × 650`。
5. 硬件用例准备一只可识别遥控器、MiRemoteV 2ch 或 BlackHole 2ch、iPhone、Apple Watch 和可用网页版客户端。
6. 记录测试开始时间，并打开 `~/Library/Logs/RemoteMic/runtime.log` 备用。

## 用例 1：侧栏、搜索与标题栏导航

1. 打开设置，确认红黄绿窗口按钮、返回/前进控件、当前页标题和搜索框均位于系统标题栏与侧栏结构中；工具栏不出现额外侧栏开关。
2. 依次进入按键、统计、回眸、连接、权限和关于，确认标题同步、侧栏选择正确且内容区不重复页标题。
3. 搜索“增益”“输入监控”和“分享”，确认结果显示“设置项名称 + 所属页面”；“分享”只定位到关于页内的分享区，不出现独立侧栏入口。
4. 点击搜索结果后确认页面滚动到目标分区且查询保留；使用 Return 激活首个结果，并用方向键与 Return 操作结果列表。
5. 连续访问多个页面和版本历史，检查返回、前进及两侧历史菜单；新导航应截断旧的前进分支。
6. 使用 ⌘F、⌘[、⌘]、⌘M、⌘H 和 ⌥⌘H，确认菜单项、启用态和窗口行为正确；macOS 14 上 ⌘F 禁用属于兼容预期。

预期结果：侧栏固定为 232pt，使用原生源列表选择态；20pt 系统色图标底板内使用 12pt SF Symbol，行首 9pt、图标与文字间距 7pt。搜索框保持系统高度；macOS 26/27 使用原生大号 Liquid Glass 导航组，macOS 14/15 使用同一组件的系统兼容样式。窗口关闭再打开时恢复位置，页面切换不改变几何尺寸。

失败判定：出现自绘导航按钮、额外侧栏按钮、重复页标题、搜索只过滤页面名、右侧内容因搜索消失、分享成为独立导航、搜索或交通灯被遮挡、历史错误、侧栏可拖宽，或页面切换改变窗口几何。

## 用例 2：页面层级、对齐与滚动背景

1. 在每个侧边栏页面分别检查首屏和滚动后的标题栏，确认正文不会清晰穿入导航组或标题，背景与分隔由系统统一工具栏生成。
2. 打开按键，确认开关行后是“遥控器”块标题与全宽设备卡；关系图沿分区左边线展开，左右模块高度 64pt、净间距不小于 16pt。
3. 打开统计，确认原生“日 / 周 / 全部”分段选择器位于首个 Section 的无底板 header，并随图表滚动离开；“数据仅存本机”只出现一次，排行仅解释排行口径。
4. 打开回眸，确认记录用途与隐私属于记录开关 footer；历史/空状态和本地 Agent 访问分别成区，说明不悬浮、不重复。
5. 打开权限，确认只有蓝牙、输入监控和辅助功能三个权限行；升级说明属于该分区 footer。
6. 打开关于，检查支持、版本与更新、个性化配置和应用偏好；“当前版本”的标题/状态在左列，版本号/唯一更新动作在右列；语言选择与其他尾部控件共线。
7. 进入版本历史，确认它是同一窗口内的关于子页面，并参与统一返回/前进历史。

预期结果：除遥控器关系图、统计图表、二维码和历史内容等业务可视化外，设置、状态和动作均使用原生 `Form`、`Section`、`LabeledContent`、`Toggle`、`Picker` 和标准按钮。同类内容遵循“左标签/右控件、业务块沿分区左边线、完整筛选控件占用整行”三类对齐；单项说明与控件同一行，整区说明才使用 footer。

失败判定：出现双重圆角容器、局部第三条对齐边线、说明与所属功能被分隔、内容穿透标题栏、统计筛选器有额外整行底板、版本状态悬浮在右侧、两个更新按钮并存、版本历史以 Sheet 打开，或最小窗口产生横向裁切。

## 用例 3：遥控器与按键映射

1. 分别在无遥控器、单遥控器和多遥控器状态进入按键与连接页。
2. 执行发现、选择、断开和重新连接，检查名称、连接状态、电量和选中状态。
3. 使用实体遥控器逐个触发按键与语音键，检查示意图高亮、映射定位和 HID 行为。
4. 在按键页滚动到 TV 键和底部系统设置，确认所有模块与操作可达。

预期结果：设备卡铺满分区宽度且不出现内外双描边；业务选择态、连接线、遥控器比例、原有映射和语音键 Fn 行为不变。

失败判定：设备卡缩入右侧控件列、卡片互相贴合或裁切、按键定位错误、映射丢失，或普通语音路径需要额外前置操作。

## 用例 4：音频与第三方语音工具

1. 分别选择 MiRemoteV 2ch、BlackHole 2ch、不可用设备和“不输出语音”。
2. 调节增益，确认“0 dB 保持原始音量…”与滑块同一行且中间没有分隔线。
3. 刷新音频设备、打开 BlackHole 获取页并发送测试音，覆盖播放、完成、取消、设备热插拔和失败状态。
4. 在真实第三方语音工具中执行 `STREAM_START → AUDIO → STREAM_STOP`，检查首次会话的完整音频与默认输入恢复。

预期结果：健康输出不重复显示“可发送测试音”；动态测试音反馈与三个音频操作位于同一 Form 行；路由说明属于 Section footer；Picker、增益和输出选择保持原行为。

失败判定：健康状态重复、动态反馈成为独立设置行、说明被错误分隔、音频设置未保存、设备切换后状态错误，或第三方工具收不到完整音频。

## 用例 5：iPhone、Apple Watch 与网页版

1. 对 iPhone、Apple Watch 和网页版分别执行开始等待、取消等待、连接和断开。
2. 等待期间确认状态文字旁显示系统小号 `ProgressView`，取消后消失。
3. 检查“打开 TestFlight / 复制链接”与 iOS App 的标题、说明、状态和连接动作位于同一个 Form 行，Apple Watch 前才出现下一条分隔线。
4. 扫描二维码、打开 TestFlight、复制链接并清除受信任设备，分别检查取消和确认路径。

预期结果：三个连接通道状态独立且不互相覆盖；iOS 辅助操作不成为第四个移动端入口；二维码、剪贴板、等待状态和受信任记录保持原行为。

失败判定：等待态没有进度指示、辅助按钮悬空或独立成行、状态串线、二维码或链接失效，或连接动作执行到错误通道。

## 用例 6：权限、外观与辅助功能

1. 分别触发蓝牙、输入监控和辅助功能权限请求，检查未决定、拒绝、已授权和升级后的状态。
2. 在浅色、深色、非激活窗口、降低透明度和增强对比度下逐页检查。
3. 使用完整键盘控制遍历 Picker、Slider、Toggle、Button、Link 和可选择卡片；使用 VoiceOver 检查图标按钮与版本历史导航。

预期结果：系统语义颜色和材质自动适配；中文最终字号不低于 12pt；普通说明不使用链接式蓝色；焦点环可见，所有操作可通过键盘和辅助技术到达。

失败判定：权限行数量或含义错误、暗色对比不足、中文小于 12pt、焦点不可见、VoiceOver 名称缺失，或任何主要操作不可达。

## 稳定功能回归

- [ ] 遥控器发现、选择、断开和重连不变。
- [ ] `STREAM_START → AUDIO → STREAM_STOP` 普通语音路径不变。
- [ ] 音频输出、增益、测试音和兼容麦克风选择不变。
- [ ] iPhone、Apple Watch、网页版与受信任设备操作不变。
- [ ] 按键映射、统计、回眸、权限、关于和版本历史均可滚动并访问主要控件。
- [ ] 设置窗口保留红黄绿按钮，可移动、缩放、全屏、关闭并恢复。

## 日志收集

视觉问题记录页面、系统版本、外观、窗口尺寸、滚动位置和截图。连接或音频异常同时记录测试时间段，并提供 `~/Library/Logs/RemoteMic/runtime.log` 对应片段；不得包含语音内容、验证码、Token 或设备唯一标识。日志中的“收到事件”“解码成功”或“入队成功”不能替代最终可见结果或完整音频。

## 验证边界

- 自动化：源码结构与行为回归测试、Swift 构建、本地化和 App 完整性校验只证明各自检查边界。
- 代理实测：生产 App 真实窗口与离屏生产视图可验证布局、滚动和部分交互，不能证明系统权限、辅助技术、真实硬件或第二设备链路。
- 用户实测：实体遥控器、真实音频设备、第三方语音工具、iPhone、Apple Watch、网页版、系统权限、VoiceOver 和不同前后台状态必须按本手册独立验收。
