# 本地语音转写记录测试手册

## 适用范围

- 分支：`codex/v1-9-0-history-mcp`
- 测试版本：无线麦SayAll.app `1.9.0` 候选（Build 待发布会话确定）
- 平台：Apple Silicon macOS 14 及以上
- 功能入口：设置窗口侧边栏“回眸”（英文为 “Reflections”），位于“统计”下方
- 当前阶段：候选代码验证；尚未发布

## 测试前准备

1. 准备已授予蓝牙、麦克风、输入监控和辅助功能权限的测试 Mac，并记录系统版本。
2. 准备 RC003、Nearby iOS 遥控器和手机网页版遥控器；三种来源分别测试，不互相替代。
3. 准备至少三个目标：macOS“备忘录”标准文本区、一个浏览器或 Electron 编辑器、一个明确的密码或 Token 输入框；浏览器另准备搜索框和地址栏。
4. 确保至少有一轮测试完全不安装或不启用私有 AI 功能，并且没有配置任何 AI API Key。
5. 测试前打开侧边栏“回眸”，确认开关默认关闭。不要清理用户真实数据；需要清空测试记录时使用页面内删除，并确认内容进入 macOS 废纸篓。
6. 发生问题时记录精确时间、语音来源、目标 App、开关状态、是否切换焦点及最终文字是否已经出现在目标 App。

## 用例 1：默认关闭与无 AI 基线

1. 全新偏好下启动 App，打开“回眸”页。
2. 保持“记录回眸”关闭，在备忘录完成一次语音输入。
3. 退出并重启 App，重新打开“回眸”页。
4. 开启开关，在没有 AI 功能和 API Key 的状态下再次完成语音输入。

预期结果：默认关闭时不新增记录；重启后仍保持关闭。开启后无需 AI 或 Key 即保存第二次语音文字，目标 App 内原有输入行为不变。

失败判定：默认自动开启、关闭时仍保存、开关重启丢失、要求配置 AI Key，或影响文字正常写入目标 App。

## 用例 2：RC003 标准输入框

1. 在备忘录已有文字中间放置光标，记下输入前全文。
2. 使用 RC003 执行正常 `STREAM_START → AUDIO → STREAM_STOP`，说一段可辨识文字。
3. 等待目标 App 文字稳定 2 秒，再打开“回眸”页。

预期结果：只保存本次光标处新增或替换的文字；记录归入“备忘录”和当天日期，不包含输入前的前后文。RC003 普通语音无需主动 `MIC_OPEN`，音频和 Fn 行为与稳定版一致。

失败判定：保存整段输入框全文、丢失本次文字、归入错误 App/日期、重复保存，或 RC003 语音基线退化。

## 用例 3：Nearby iOS 与网页版来源

1. 分别通过 Nearby iOS 和手机网页版连接 Mac。
2. 每种来源在不同目标 App 中完成一条语音输入。
3. 打开“回眸”页切换应用，并按日期检查记录。

预期结果：两种来源都使用同一公共记录逻辑；记录按实际目标 App 分组，不新增协议字段，不影响手机端按住说话、松开停止、弱网缓冲或互斥逻辑。

失败判定：某一来源不保存、保存到错误 App、一次语音生成多条记录，或移动端稳定语音行为变化。

## 用例 4：关闭、使用后关闭与重启

1. 开启功能并成功保存一条记录。
2. 开始下一次语音，在文字稳定前立即关闭开关。
3. 再完成一条语音输入，然后退出并重启 App。

预期结果：第一条旧记录保留；关闭时进行中的捕获被取消，之后不再新增；重启后开关仍关闭，旧记录仍可查看、复制和删除。

失败判定：关闭开关删除历史、进行中捕获仍落盘、关闭后继续保存，或重启后历史消失。

## 用例 5：快速发送、连续语音、焦点和前后台

分别执行以下独立场景：

1. 正常完成语音后保持焦点不动。
2. 目标输入框已经出现完整文字后，在 1 秒内按 Return 发送并清空输入框。
3. 第一段文字已经出现后，在 1 秒内立即开始第二段语音。
4. 语音结束但目标文字尚未出现时，立刻切到另一个输入框或 App。
5. 语音过程中切换到另一个 App。
6. 目标 App 进入后台后再回前台。
7. Remote Mic 自身进入后台和回前台，但目标输入框保持可编辑。
8. 用组合动作打开 Codex并聚焦已学习输入框，在页面刚出现时立即开始说话。

预期结果：正常稳定、快速发送和紧接下一段语音均保存已经观察到的合法候选，每段只生成一条记录；组合动作后焦点短暂未就绪时会自动等待，不要求用户手动点击输入框。文字尚未出现或语音过程中切换目标时不保存，也不把其他输入框或其他 App 的文字误记为语音结果。App 前后台变化不应影响蓝牙、音频和已有记录浏览。

失败判定：快速发送、连续语音或组合动作后立即说话仍丢失已经出现的文字、需要手动点击输入框、重复保存、把新焦点已有文字误存、跨 App 串记录、崩溃，或目标切换后继续轮询敏感区域。

## 用例 6：敏感和非正文输入区域

1. 分别聚焦密码框、Token/API Key 框、浏览器地址栏、页面搜索框、设置搜索框和普通正文输入框。
2. 在每个位置尝试一次语音输入。

预期结果：密码、Token、地址、搜索和设置类目标不保存；普通正文输入框正常保存。日志中不出现用户语音文字、输入框全文、URL、Token 或密码。

失败判定：任何敏感目标产生记录，或日志泄露正文和敏感值。

## 用例 7：应用、日期和时区

1. 在两个不同 App 各保存至少两条记录。
2. 在本地午夜前后各完成一条语音；条件允许时再切换系统时区后查看旧记录。
3. 退出并重启 App。

预期结果：应用分组互不混合；午夜前后进入各自的 `YYYY-MM-DD`；旧记录使用保存时的日期和时区显示，不因重启或当前时区变化错误移动到另一日。

失败判定：Bundle ID 不同的 App 混组、日期跨天错误、重启顺序变化，或文件不位于 `Application Support/RemoteMic/Transcripts/v1/<app-key>/<date>.json`。

## 用例 8：复制与可恢复删除

1. 复制一条记录并粘贴到纯文本编辑器。
2. 分别执行单条删除、删除当前 App、页面最底部的“全部删除”，每次检查确认提示。
3. 在 macOS 废纸篓检查对应 JSON 文件或目录。

预期结果：复制内容与该条文字一致；删除不影响目标 App 中已经输入的文字；删除对象进入废纸篓，可由用户手动恢复。单条删除后同日其他记录仍显示。

失败判定：无确认即批量删除、删除对象不可恢复、误删其他 App/日期、剩余记录损坏，或复制出输入框前后文。

## 用例 9：独立“回眸”页布局和本地化

1. 在中英文下分别打开统计页和“回眸”页，准备多个 App、多日期和长文本记录。
2. 在 `800 × 650` 窗口逐一点击全部侧边栏入口，确认“回眸”紧跟“统计”且窗口几何不变。
3. 检查“仅保存本次新增……”隐私说明位于页头标题右侧，宽度不足时可以换行；“记录回眸”开关固定在页头最右侧，英文显示为 “Save to Reflections”，页面底部不再重复显示隐私说明卡。
4. 首次进入页面时确认顶部“全部应用”处于选中状态，其余 App 按最近使用排序并在单行中横向排列；依次点击 App 图标或名称，确认时间线只保留该 App 的记录，再点击“全部应用”恢复总时间线。
5. 准备至少 10 个 App 的记录，点击应用栏最右侧“展开”，确认应用在页面内展开为自适应网格且“全部应用”始终可见；点击“收起”恢复单行，选中靠后的 App 后确认该项自动滚动到可见位置。
6. 准备至少两个日期，确认最新日期默认展开、较早日期默认折叠；分别点击日期整行和箭头，验证各日期可以独立展开或折叠，展开后的记录仍按时间倒序显示。
7. 检查每条记录均显示 App 图标和名称；说明文字和“全部删除”位于页面最底部且没有卡片或按钮描边；回到统计页检查日/周/全部、柱状图和原语音时长 Top 10。

预期结果：新增独立“回眸”入口并位于统计下方；默认总时间线严格按最新记录在前排列，点击顶部 App 后只显示对应记录；“全部应用”固定可见，其余 App 按最近使用排序，少量应用使用单行、较多应用可在页面内展开；选中项保持可见。最新日期默认展开，其他日期可独立折叠或展开。已安装 App 显示真实图标，无法解析图标时显示通用 App 图标。隐私说明紧邻标题并按需换行，开关始终位于最右侧，页面底部不再重复隐私卡；全部删除位于最底部且不使用包围样式。统计页原功能保持；内容可滚动且不改变窗口几何；所有新增中文文字最终字号不小于 12pt，无下拉列表、Popover 或连续 Sheet。

失败判定：入口顺序错误、默认选中某个 App、总时间线不是倒序、App 筛选混入其他应用、“全部应用”被横向滚出、10 个 App 无法展开查看、选中项不可见、日期无法独立折叠或展开、默认展开顺序错误、App 图标缺失且无回退、隐私说明仍在底部或挤压开关、开关不在最右侧、全部删除仍在顶部或带包围样式、原统计卡缺失、页面裁切、窗口被内容撑大、无法滚动、中文小于 12pt，或主流程依赖浮层。

## 稳定功能回归

- 功能开关缺失或默认关闭时，RC003、Nearby iOS、网页版和现有 AI 私有组件行为与基线等价。
- 明确关闭、明确开启、使用后再关闭四种状态均不改变蓝牙协议、PCM、CoreAudio、Fn 点按和按键映射。
- RC003 普通路径覆盖无需前置主动 `MIC_OPEN` 的 `STREAM_START → AUDIO → STREAM_STOP`。
- 原统计页今日、本周、全部、两种柱状图和单次语音时长 Top 10 均正常。
- 配置导入导出不包含语音正文；App 日志不包含语音正文。

## 日志收集方式

从 App“文件 → 打开日志所在文件夹”取得 `runtime.log`，并提供问题发生时间、系统版本、App 版本、语音来源、目标 App 名称和开关状态。不要把测试用密码、Token 或真实私人语音文字写入问题说明；必要时使用无隐私的固定测试句复现。

## 自动化、代理实测和用户实测边界

自动化覆盖 JSON 版本、按 App/日期写入、排序、目录和文件权限、可恢复删除、开关默认与持久化、连续差异、稳定等待、初始焦点短时重试、快速发送、下一段开始前最终快照、连续语音、敏感目标、焦点切换、取消原因日志和独立页面接线。构建通过只能证明编译边界。

Codex 代理可以完成源码测试、Release 构建、安装包结构检查和当前桌面页面检查，但模拟文本快照不能替代真实 Accessibility 树、输入法提交时序、RC003、Nearby iOS、手机浏览器、权限历史和第三方 App。上述真实流程必须由对应硬件和 App 完成人工验收；未执行项交付时必须明确标注。
