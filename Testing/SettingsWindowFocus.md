# 设置窗口失焦行为测试手册

## 适用范围

- 适用版本：当前待验证 PR 或已合入 `main` 的精确 Commit；原功能分支 `codex/fix-settings-window-focus` 只作为历史审计来源
- 平台：Apple Silicon macOS 14 及以上；Intel macOS 13 及以上
- 目标：确认无线麦 SayAll 设置窗口失焦后保留，并在关窗时应用保存的 Dock 偏好。

## 测试前准备

1. 退出其他无线麦 SayAll 实例，启动本分支构建的候选。记录 Dock 是否固定了候选。验证图标消失时，使用未固定的候选并区分系统最近使用区。
2. 打开设置窗口，确保它没有最小化或全屏。
3. 准备一个无模态窗口的其他 App，例如 Finder 或 TextEdit。
4. 记录测试开始时间；如果同时发生异常，保留 `~/Library/Logs/RemoteMic/runtime.log` 对应时间段。

## 用例 1：开关与关窗

1. 在“设置 → 通用”关闭“在 Dock 中显示应用图标”。图标在窗口打开时保留。
2. 点击红色关闭按钮。窗口关闭，App 继续运行，运行图标消失。
3. 从菜单栏选“打开主界面…”。窗口和 Dock 图标都恢复。
4. 使用 `⌘W` 重复关窗。打开主界面后开启 Dock 开关，再关窗。图标保留。点击图标可重新打开原窗口。

失败判定：关闭开关时图标立即消失、关闭窗口后偏好不生效、图标或菜单栏入口无法打开原窗口，或关窗导致 App 退出。

## 用例 2：遮挡及最小化

1. 关闭 Dock 开关，保持设置窗口打开。切换到一个非默认页面并滚动。
2. 用 Finder 或 TextEdit 挡住窗口。点击 Dock 图标，确认原窗口恢复到前面并保留页面和滚动位置。
3. 点击黄色最小化按钮。确认 Dock 应用图标仍显示，点击后恢复原窗口。
4. 分别观察 Dock 应用图标与最小化窗口缩略图的小 Logo。

失败判定：失焦后图标消失、点击 Dock 未带回同一窗口、最小化变成关闭，或圆角图标变为方形。

## 用例 3：后台启动和旧配置

1. 关闭 Dock 开关与“启动时自动打开主面板”，保留菜单栏图标。退出并重启。确认主窗口不自动打开，Dock 运行图标隐藏。
2. 关闭菜单栏图标。退出并重启。确认主窗口自动打开，Dock 图标可见。
3. 分别导入 Dock 开关为开和关的旧配置。确认开关立即同步，导入期间窗口仍可操作，关窗后的图标按导入值显示或隐藏。
4. 在 Intel Mac 上重复用例 1 和 2。分别检查 Dock 应用图标与最小化窗口缩略图的小图标，均应保持圆角。

失败判定：两个入口都关闭后重启无主窗口、导入值未生效，或切换策略后 Intel 图标变成方形。

## 稳定功能回归

- [ ] 设置窗口可移动、缩放和进入/退出全屏。
- [ ] 全部侧边栏入口、主要控件和滚动在真实生产最小窗口 `1067 × 760` 下未裁切；`800 × 650` 仅作为离屏压力截图检查。
- [ ] 鼠标左键和右键均可显示状态菜单，第一项“打开主界面…”可恢复并激活原窗口。
- [ ] Onboarding 已完成后启动或重新打开设置窗口，默认进入当前侧边栏第一项；调整侧边栏顺序后无需同步修改启动入口。
- [ ] 关闭设置窗口不影响蓝牙连接、音频状态或按键映射。

## 日志收集

筛选 `UI DOCK_POLICY`，按 `operation_id` 对照请求和结果。保存值见 `show_dock`，窗口状态见 `window_open`。开关关闭时，开窗应记录 `target_policy=regular`，关窗应记录 `target_policy=accessory`。屏幕图标以实机观察为准。

## 验证边界

- 自动化：覆盖 Dock 偏好与窗口状态组合、两个入口都关闭时的启动决策，以及启动、切换、开窗、关窗和导入的策略接线。检查失焦、最小化、恢复和 `⌘W` 保留既有窗口路径。实际 Dock 点击和图标变化仍需在运行的 App 中验收。
- 代理实测：Apple Silicon Release App 已启动并显示生产设置窗口；截图和摘要见 `历史截图证据已按仓库清理规则移出`。该结果不替代 Intel Dock 外观验收。
- 用户实测：build 248 的右侧窗口缩略图标记仍为方形。需要在实际 Intel 系统运行用例 1–3，独立记录左侧应用图标与右侧窗口标记，并检查最小化、恢复、退出、重启及白底回归；通过后才能确认现场问题已经消除。
