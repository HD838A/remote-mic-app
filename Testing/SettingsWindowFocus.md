# 设置窗口失焦行为测试手册

## 适用范围

- 适用版本：当前待验证 PR 或已合入 `main` 的精确 Commit；原功能分支 `codex/fix-settings-window-focus` 只作为历史审计来源
- 平台：Apple Silicon macOS 14 及以上；Intel macOS 13 及以上
- 目标：确认无线麦SayAll.app 设置窗口在失去应用焦点后保持可见；窗口只通过系统红色关闭按钮或 `⌘W` 关闭。

## 测试前准备

1. 退出其他无线麦SayAll.app 实例，启动本分支构建的 App：`./script/build_and_run.sh`。
2. 打开设置窗口，确保它没有最小化或全屏。
3. 准备一个无模态窗口的其他 App，例如 Finder 或 TextEdit。
4. 记录测试开始时间；如果同时发生异常，保留 `~/Library/Logs/RemoteMic/runtime.log` 对应时间段。

## 用例 1：关窗后从 Dock 重新打开

1. 使用旧配置中 Dock 开关为关闭的账号启动候选。确认 App 在运行时显示 Dock 图标。
2. 点击红色关闭按钮，确认 Dock 图标仍显示。点击图标，确认重新打开主窗口。
3. 以 `⌘W` 重复关窗并从 Dock 重开。
4. 选择退出或按 `⌘Q`。确认进程停止。未固定且关闭系统最近使用 App 显示时，图标消失。

失败判定：启动后缺少运行图标、关窗时图标消失、点击 Dock 不能重开主窗口，或关窗导致 App 退出。

## 用例 2：遮挡及最小化

1. 打开设置窗口，切换到一个非默认页面并滚动。
2. 用 Finder 或 TextEdit 挡住窗口。点击 Dock 图标，确认原窗口恢复到前面并保留页面和滚动位置。
3. 点击黄色最小化按钮。确认 Dock 应用图标仍显示，点击后恢复原窗口。
4. 分别观察 Dock 应用图标与最小化窗口缩略图的小 Logo。

失败判定：失焦后图标消失、点击 Dock 未带回同一窗口、最小化变成关闭，或圆角图标变为方形。

## 用例 3：后台启动与固定入口

1. 关闭“启动时自动打开主面板”并退出。再启动时应仅在后台运行，Dock 图标仍显示。
2. 关闭菜单栏入口，确认仍可从 Dock 打开窗口。
3. 按设置页“Dock 图标”的说明，从 macOS Dock 图标菜单开启“选项 → 在程序坞中保留”。退出后入口保留，可点击重新启动 App。
4. 再从系统 Dock 菜单取消固定。App 继续运行时图标仍显示。退出后，固定位置不再保留入口。测试后恢复系统原有固定状态。
5. 导入旧版配置，分别包含开启和关闭的 Dock 偏好。运行图标应始终显示。

失败判定：后台启动没有 Dock 入口、关闭菜单栏或导入配置隐藏 Dock，或退出后固定入口消失。

## 稳定功能回归

- [ ] 设置窗口可移动、缩放和进入/退出全屏。
- [ ] 全部侧边栏入口、主要控件和滚动在真实生产最小窗口 `1020 × 772` 下未裁切；`800 × 650` 仅作为离屏压力截图检查。
- [ ] 鼠标左键和右键均可显示状态菜单，第一项“打开主界面…”可恢复并激活原窗口。
- [ ] Onboarding 已完成后启动或重新打开设置窗口，默认进入当前侧边栏第一项；调整侧边栏顺序后无需同步修改启动入口。
- [ ] 关闭设置窗口不影响蓝牙连接、音频状态或按键映射。

## 日志收集

筛选启动时的 `UI DOCK_POLICY`，确认 `target_policy=regular` 及 `result=applied`。从 Dock 重开时检查 `UI ENTRY_POINT` 的 `source=application_reopen`。屏幕上的图标、固定入口和最近使用区需要现场观察。

## 验证边界

- 自动化：检查启动时设置常规 App 激活策略，菜单入口和窗口关闭路径保留。检查失焦、最小化、恢复和 `⌘W` 保留既有窗口路径。实际 Dock 点击和图标变化仍需在运行的 App 中验收。
- 代理实测：Apple Silicon Release App 已启动并显示生产设置窗口；截图和摘要见 `历史截图证据已按仓库清理规则移出`。该结果不替代 Intel Dock 外观验收。
- 用户实测：build 248 的右侧窗口缩略图标记仍为方形。需要在实际 Intel 系统运行用例 1–3，独立记录左侧应用图标与右侧窗口标记，并检查最小化、恢复、退出、重启及白底回归；通过后才能确认现场问题已经消除。
