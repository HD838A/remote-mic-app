# 千问输入法兼容模式测试

## 适用范围

- 平台：macOS 14 及以上
- 硬件：小米蓝牙遥控器 2 Pro / RC003
- 音频：`MiRemoteV 2ch`
- 第三方工具：千问输入法 Mac 版

## 测试前准备

1. 千问保留“右 Command”语音快捷键，并把麦克风明确选择为 `MiRemoteV 2ch`，不使用“系统默认”。
2. SayAll 中确认 RC003、输入监控、辅助功能和 `MiRemoteV 2ch` 均可用。
3. 打开 `~/Library/Logs/RemoteMic/runtime.log`。

## 用例 1：默认关闭

关闭“千问兼容模式”，重启 SayAll 并按住遥控器语音键。

预期：行为与稳定版一致，语音键映射为 Fn；系统默认麦克风不变化。

## 用例 2：按住说、松开停

1. 开启“千问兼容模式”，点击普通文本输入框。
2. 按住语音键说话，再松开。

预期：SayAll 选择 `MiRemoteV 2ch`；千问启动、收到完整语音并自动结束，不需要再点对勾，输入框不残留蓝色组合输入线。日志每次只有一组 `QIANWEN COMMAND DOWN` 和 `QIANWEN COMMAND UP`。

失败：千问不启动、使用内置麦克风、丢开头或尾音、松开后仍未结束，或右 Command 保持按下。

## 用例 3：VoiceOver 与全局按键状态

1. 短按和长按语音键各三次。
2. 每次结束后点击不同 Dock 图标，并按一次 Command-F5。

预期：遥控器语音键不会打开 VoiceOver；Dock 正常打开 App，不会在 Finder 中显示 App；实体 Command-F5 仍由 macOS 正常处理。

## 用例 4：快速重按

第一次松开后立即再次按住语音键说话，再松开。

预期：旧会话的尾音排空不会提前松开新会话的右 Command；第二次松开后才结束，且最终不残留按键状态。

## 用例 5：断连、关闭与退出

分别在语音进行时断开 RC003、关闭千问模式、退出 SayAll。

预期：立即释放右 Command；重新连接或启动后可再次使用。系统默认输入、输出始终不被千问模式修改。

## 用例 6：Fn 点按互斥

依次开启千问模式和“语音键模拟 Fn 点按”。

预期：任一模式开启都会关闭另一模式，一次语音不会同时产生右 Command 和 Fn。

## 用例 7：配置兼容与 Icon

1. 导出开启千问模式的配置并导入到干净设置。
2. 导入缺少新字段的旧配置。
3. 检查 Dock 与“应用程序”中的图标。

预期：新配置恢复千问模式；旧配置默认关闭；App 使用圆角透明 Icon，不显示白色直角方块。

## 自动化与人工边界

- 自动化覆盖 F5 屏蔽、右 Command 按下/排空后松开、快速重按、强制释放、开关互斥、配置兼容和设置页结构。
- 自动化不能证明真实 RC003、千问和 macOS VoiceOver 的最终联动，必须按以上用例人工验收。
