# 侧边栏页签快捷键（⌘1–⌘9）手工验收

本手册覆盖「前往」菜单、⌘1–⌘9 固定映射，以及「保存为方案」弹层的 Esc / 回车。
自动化回归见 `Tests/RemoteMicTests/SettingsNavigationShortcutTests.swift`。

## 前置条件

- 完成首次引导，设置窗口可打开且为 key window。
- 语言分别用简体中文与 English 各跑一遍（菜单文案来自 `menu.go` 及各页签标题）。
- 分别覆盖「公开构建（无私有组件）」与「含私有组件构建」两种情况，验证可见页签变化时的行为。

## 固定映射

| 键 | 页签 |
| --- | --- |
| ⌘1 | 按键 |
| ⌘2 | 聚焦与翻页 |
| ⌘3 | 组合动作 |
| ⌘4 | 按键方案 |
| ⌘5 | 会员 |
| ⌘6 | 连接 |
| ⌘7 | 回眸 |
| ⌘8 | 设置 |
| ⌘9 | 个人中心 |

映射是**固定身份**：⌘3 永远指向「组合动作」。会员开通或私有功能启停增删侧边栏行时，
⌘3 只会从「无效」变「有效」，不会变成别的页。超过 9 个的 supplemental 动态页没有快捷键，
只能在「前往」菜单或侧边栏里点选。

## 用例 1：快捷键切换

| 步骤 | 期望 |
| --- | --- |
| 在任意页面按 ⌘1 | 切到「按键」页，侧边栏选中态同步 |
| 依次按 ⌘2 … ⌘9 | 每次切到表中对应页签 |
| 连续按同一个 ⌘N 两次 | 停留在同一页，不闪烁、不重复触发页面副作用 |
| 切页后打开「前往」菜单 | 当前页签在列表中，菜单项显示对应 ⌘N 标签 |

## 用例 2：不可见页签

| 步骤 | 期望 |
| --- | --- |
| 在公开构建（无私有组件）下按 ⌘3 / ⌘4 / ⌘5 | 无任何反应：不跳到别的页签、不弹窗、不提示音 |
| 打开「前往」菜单（公开构建） | 只列出当前可见页签；「组合动作」「按键方案」「会员」不出现 |
| 会员状态变化后重开「前往」菜单 | 列表按最新可见性重建，标题与快捷键标签正确；⌘N 身份不变 |

## 用例 3：「前往」菜单

| 步骤 | 期望 |
| --- | --- |
| 打开「前往」菜单 | 位于「编辑」与「窗口」之间；标题不为空（含私有页签） |
| 点选某个可见页签 | 切到该页，效果与点击侧边栏一致（含「标记更新已读」等既有副作用） |
| 切换中英文后重开菜单 | 菜单标题与页签标题按当前语言更新，快捷键标签不变 |

## 用例 4：保存为方案弹层

| 步骤 | 期望 |
| --- | --- |
| 在「按键」页打开「保存为方案」弹层，按 Esc | 弹层关闭，不保存 |
| 重新打开，填写方案名，按回车 | 提交保存，弹层关闭 |
| 重新打开，清空方案名，按回车 | 「保存」按钮为不可用状态，回车不提交、不产生空名方案 |

## 用例 5：回归重点

- **标准编辑快捷键仍可用**：在任意输入框里验证 ⌘A / ⌘C / ⌘V / ⌘Z / ⇧⌘Z。
- **窗口快捷键仍可用**：⌘Q 退出、⌘W 关闭、⌘M 最小化。
- **⌘F 不受影响**：若已合入 ⌘F 搜索快捷键，⌘F 仍聚焦当前页主搜索框。
- **语音链路**：切页后语音按下/释放、双击/长按判定与聚焦前台输入框行为不变。
- **页面外观**：侧边栏项数量、顺序、布局、控件样式与改动前完全一致。

## 通过判据

用例 1–5 全部符合期望，且页面布局与既有功能无变化。
