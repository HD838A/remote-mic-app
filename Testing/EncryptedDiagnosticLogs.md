# 加密诊断日志与主动发送测试手册

## 适用范围

- 分支：`codex/encrypted-diagnostic-logs-2026-08-15`
- 版本：下一个 macOS 预览版候选
- 平台：Apple Silicon macOS 14 及以上；Intel 独立包 macOS 13 及以上
- 测试目标：验证本地加密、按天轮转、容量和保留期，以及只有用户主动点击后才向 Sentry 发送今天和昨天的脱敏日志。

## 测试前准备

1. 准备一个通过 `REMOTE_MIC_SENTRY_DSN` 注入测试项目 DSN 的候选 App；DSN 只能使用项目公开 ingest 地址，不能使用管理 Token。
2. 在 Sentry 测试项目中记录测试前的日志条数和最后接收时间，避免把其他设备事件算入本次结果。
3. 准备可以观察 HTTPS 请求的网络工具，按测试 DSN 的 host 过滤；不解密其他应用流量。
4. 记录测试 Mac 的本地日期、时区和测试开始时间。跨日用例优先使用专用测试账号或自动化，不修改日常使用账号的系统时间。
5. 如需验证升级，先准备带有 `~/Library/Logs/RemoteMic/runtime.log` 和最近 5 天测试用 `runtime-YYYY-MM-DD.rmlog` 的旧版测试环境；不要使用包含真实隐私内容的历史日志。

## 用例 1：升级与加密落盘

1. 启动候选 App并执行连接、按键和语音等会产生运行日志的操作。
2. 从“文件 → 打开日志所在文件夹”或设置页“打开日志文件夹”进入 `~/Library/Logs/RemoteMic/`。
3. 检查当天文件名、文件大小和权限，并使用文本编辑器或 `strings` 检查原始文件。
4. 升级场景额外确认旧 `runtime.log` 和保留期内旧 `runtime-YYYY-MM-DD.rmlog` 的处理结果。

预期结果：只生成 `sayall.app-YYYY-MM-DD.rmlog`；文件权限为当前用户读写，日志目录只允许当前用户访问；原始文件中找不到刚才操作对应的明文；旧 `runtime.log` 已删除，保留期内不存在同日期新文件的旧加密日志已迁移到 `sayall.app-` 前缀。

失败判定：继续写入 `runtime.log`、磁盘可搜索到完整日志文本、其他本机用户可直接读取文件，或文件头和记录损坏导致当天全部诊断无法发送。

## 用例 2：每日文件与上传日期范围

1. 在本地日期切换前后分别产生带有唯一测试标记的日志，确保昨天、今天和更早日期都有文件。
2. 不点击发送按钮，先观察 Sentry 和网络请求。
3. 点击一次“发送诊断信息”，等待页面内结果。
4. 在 Sentry 按唯一标记查询收到的条目及 `diagnostic.day`。

预期结果：每个自然日只有一个文件；未点击前没有 Sentry 请求和 SDK 缓存目录；点击后才加载官方 SDK，只出现今天和昨天的标记，更早日期不上传；页面显示已提交条数，临时 SDK 缓存随后删除。

失败判定：未点击已经上传、同一天产生多个日志文件、上传第三天或更早日志、漏掉存在内容的今天/昨天，或按钮触发重复并发发送。

## 用例 3：10MB 上限与 5 天保留

1. 运行 `swift test --filter RemoteMicTests.AppLoggerTests`，确认小容量夹具覆盖达到上限后的行为。
2. 在专用测试目录生成连续 7 个日期的日志夹具，再触发当天写入或重新启动日志器。
3. 检查所有 `.rmlog` 的最终大小和日期。

预期结果：生产配置单个每日文件不超过 10,485,760 字节；只保留今天及此前 4 天，共最多 5 个日期；达到上限后不会生成额外明文或无限分卷。

失败判定：任一文件超过上限、保留 6 天及以上、删除仍在 5 天窗口内的日志，或容量限制破坏已有记录解密。

## 用例 4：脱敏

1. 在测试环境中写入专用假数据：测试用户名、测试主目录、假 Mac 名称、邮箱、UUID、MAC 地址、IPv4、Bearer token 和 `api_key=` 形式。
2. 点击发送诊断信息。
3. 在 Sentry 查看每一条 body。

预期结果：所有假敏感值都替换为 `<redacted...>`；时间、事件类型和排障所需状态仍可读；不出现音频、语音识别文字或密钥。

失败判定：任一完整敏感值到达服务端，或脱敏把全部事件内容清空到无法排障。

## 用例 5：无配置、断网与服务拒绝

分别执行：未注入 DSN、点击前断网、使用会返回非 2xx 的隔离测试 endpoint。每次只点击一次并等待页面状态，然后恢复网络但不要再次点击。

预期结果：未配置时页面显示服务未配置；断网导致 SDK 留下待发送 Envelope 时页面显示发送失败；App 不崩溃、不弹连续确认框、不在恢复网络后自动重试，临时 SDK 缓存被删除，只有用户再次点击才发起下一次请求。本地加密文件保持不变。非 2xx 是否能由 Sentry Cocoa 的公开 flush API反馈给页面需单独记录；无论页面状态如何，服务端未收到内容都不能算真实发送成功。

失败判定：启动即请求 Sentry、失败后后台自动重试、临时 SDK 缓存未删除、日志被失败请求删除，或 UI 一直停留在发送中。

## 用例 6：启动环境快照与隐私边界

1. 记录测试 Mac 的系统版本、`system_profiler SPHardwareDataType` 显示的型号标识、App 版本/Build、系统首选语言，以及 App 当前麦克风增益、脱敏输出类别、自定义按键总开关、Fn 点按、Dock、启动窗口、预发布更新和引导状态。
2. 完全退出并重新启动 App，不点击发送诊断信息，确认此时没有 Sentry 网络请求。
3. 点击一次“发送诊断信息”，在 Sentry 查找本次启动的 `APP ENV` 条目。
4. 检查条目中是否出现用户名、完整姓名、Mac 自定义名称、序列号、音频设备 UID/名称、自定义快捷键、App 配置名称、设备标识、IP、语音文字或音频内容。

预期结果：每个 App 进程启动记录一次 `APP ENV`；系统版本、Mac 硬件型号、App 版本/Build、系统与 App 语言、麦克风增益/输出类别以及非个性化布尔或枚举设置准确；输出只使用 `not_configured`、`sayall_virtual`、`blackhole` 或 `other`，不出现原始 UID/名称；未点击前仅写本地加密日志，不访问 Sentry；所有列出的个性化字段均不存在。

失败判定：同一进程重复记录多次、缺少必需环境字段、设置值明显错误、启动时已经联网，或任一禁止字段出现在本地解密结果或 Sentry。

## 用例 7：设置页界面

1. 在中文和英文、浅色和深色下打开“权限与隐私”。
2. 先以项目默认最小窗口 `1020 × 772` 检查，再尝试缩小至 `800 × 650` 检查规则要求的兼容边界。
3. 点击发送按钮，观察发送中、成功和失败状态；同时确认“打开日志文件夹”仍可使用。

预期结果：标题、隐私说明、状态和两个按钮可见且不重叠；中文最终字号不低于 12pt；窗口几何不跳变；没有 Sheet、Popover、下拉框或裁切。

失败判定：主要按钮不可点击、状态推动页面产生异常裁切、控件覆盖其他权限项，或窗口自动改变大小。

## 稳定功能回归

- App 启动、退出和第二次启动正常；没有配置 DSN 时其他功能不受影响。
- RC001/RC003 连接、普通语音、按键映射、双击和长按保持原行为。
- iPhone 与 Apple Watch 附近连接不会因为诊断上传器初始化而启动或改变网络状态。
- “文件 → 打开日志所在文件夹”和菜单栏“显示日志”都打开新的加密日志目录。

## 日志收集方式

`.rmlog` 是加密文件，不能要求用户用文本编辑器打开或直接粘贴内容。现场问题应记录发生时间、App 版本和操作步骤，然后由用户在“权限与隐私”中点击“发送诊断信息”。若发送本身失败，保留今天和昨天的 `.rmlog` 原始文件及页面状态截图，由受控调试工具在授权环境中处理；不要索要或上传 Keychain 文件。

## 自动化、代理实测与用户实测边界

自动化可以验证文件格式、密文不可见、日期选择、容量、保留期、旧前缀迁移、脱敏、SDK 配置、启动环境字段和按钮调用边界。本机代理可以构建最终 App、检查静态链接、文件权限、页面布局和是否产生网络请求。真实 Sentry 接收、服务拒绝反馈、跨自然日长时间运行、真实断网、不同 macOS 账号权限和普通用户发送流程必须由最终签名候选 App 人工验收；未完成时不能表述为已经上线可用。
