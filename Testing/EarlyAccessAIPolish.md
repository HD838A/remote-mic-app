# 邀请制 AI 整理测试手册

## 适用版本与分支

- 候选分支：`release/pre-v1.8.12`
- 目标版本：Remote Mic `v1.8.12 (104)` Pre-release
- 功能：通用 Early Access 资格控制下的 DeepSeek“AI 整理（实验）”

## 测试前准备

- macOS 14 或更高版本，建议同时覆盖当前正式支持版本和最新 macOS。
- 一个未加入体验的全新 App 环境，以及一个由管理员提供的有效单设备体验码。
- Remote Mic 已完成首次设置，MiRemoteV 2ch 可用，辅助功能与蓝牙权限正常。
- RC003 真机；附近 iPhone 和网页版遥控器用于各自独立回归。
- 豆包输入法可真实语音上屏；授权用例另需有效 DeepSeek API Key。
- 不在截图、日志或问题报告中记录体验码、匿名设备 ID、刷新凭证、签名授权或 DeepSeek API Key。

## A. 首次请求与默认隐藏

### A1 未加入体验

1. 断开网络并首次启动 App。
2. 依次打开连接、按键、统计、权限和关于页。
3. 不点击“验证并启用”，完成一次 RC003 普通语音输入。

预期：侧边栏没有“AI 整理”；不会创建资格网络请求；普通按键、音频和豆包上屏与上一预览版一致。任何自动请求、AI 入口可见或普通语音失败均判定失败。

### A2 人工兑换

1. 恢复网络，在“关于”页输入体验码。
2. 只有在手动点击“验证并启用”后观察网络和界面。

预期：点击后才出现一次兑换请求；成功后显示可复制请求编号和“资格有效”，侧边栏出现“AI 整理”；AI 本地开关仍为关闭。体验码或匿名凭证出现在日志中判定失败。

## B. 四态门禁

### B1 资格缺失或默认关闭

完成普通 `STREAM_START → AUDIO → STREAM_STOP` 语音，不发送前置主动 `MIC_OPEN`。

预期：豆包正常上屏，不访问资格服务或 DeepSeek，不出现 AI HUD，不二次替换文字。

### B2 有资格但明确关闭

授权后保持 AI 开关关闭，再完成 RC003、附近 iPhone、Web Remote 各一次按键和语音。

预期：所有稳定路径与 B1 等价；打开 AI 页面本身不发资格刷新或 DeepSeek 请求。

### B3 有资格且开启

1. 保存 DeepSeek API Key 并测试连接。
2. 开启 AI 整理，在 TextEdit 中口述一段含改口和重复的文字。

预期：豆包先上屏；语音结束并稳定后最多一次 DeepSeek 请求；请求阶段出现不抢焦点的 HUD；只替换本次语音范围，失败时保留原文。

### B4 使用后撤销或退出

1. 在 AI 请求期间由管理端撤销资格，或在关于页退出体验。
2. 继续输入，并再次完成语音。

预期：本地开关立即关闭，进行中的任务取消，迟到结果不写回，AI 页面切回关于并隐藏；API Key 和术语仍保留。下一次语音只走稳定基线。

## C. 资格状态与网络

- 有效缓存下断网刷新：显示“离线有效”，只在签名到期前继续允许。
- 无有效缓存时断网：保持隐藏，不影响其他功能。
- 暂停、版本阻止、签名错误、Grant/Subject 不匹配：全部关闭功能，不使用旧授权绕过。
- 睡眠唤醒和 App 回到前台：已加入用户可按 `refresh_after` 低频检查；未加入用户仍不得请求。
- 退出服务失败：显示失败，允许用户明确点击“仅清除本机资格”；不得自动删除 DeepSeek Key 或术语。

## D. 设置页与稳定功能回归

在 `1020 × 772` 默认窗口和强制 `800 × 650` 内容检查环境中逐一点击全部可见侧边栏入口，确认页头、主要控件、滚动和窗口几何无裁切。中文最终字号不得低于 12pt。

稳定回归至少包含：

- RC003 方向、确认、返回、主页、菜单、TV、音量和语音；
- RC003 无前置 `MIC_OPEN` 的普通语音事件顺序；
- 附近 iPhone 按键与按住/点按语音；
- Web Remote 人工点击连接、按键、按住说话和尾音释放；
- Fn 点按模式、虚拟音频恢复、豆包兼容、快捷键映射、统计和更新检查；
- 开关关闭时的 CPU、网络、音频回调和日志不得新增按语音频率发生的资格行为。

## 日志收集

通过菜单栏“显示日志”收集 App 日志，并记录测试版本、Build、macOS、入口、目标 App、操作时间和可复制的资格请求编号。不得粘贴体验码、资格 Keychain 内容、DeepSeek Key、语音内容或整理结果。

## 验证边界

- 自动化：签名、Claims、请求字段、Keychain、资格状态、四态门禁、AI 文本目标和稳定协议事件。
- 代理实测：生产 App 构建、设置页截图、Cloudflare 兑换/刷新/撤销、公开下载字节、签名与公证。
- 用户或真实环境：RC003 射频和音质、真实豆包上屏、DeepSeek 整理质量、不同第三方 AX 输入框、附近 iPhone、Safari Web Remote 和长时间使用。

稳定语音与按键路径必须有通过的自动化事件回放或可用真机证据，否则不得发布 Pre-release。AI 整理实验自身的真实邀请码、第三方 App 与整理质量可以继续标记为“验证中”，但必须保持普通用户默认隐藏且关闭，不得写入应用内版本历史、Sparkle 更新说明或 GitHub Release Notes，也不能描述为已完成真机验收。
