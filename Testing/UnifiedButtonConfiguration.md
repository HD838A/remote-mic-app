# macOS 统一按键设置测试手册

## 范围与准备

- 宿主和私有平台分支：`codex/unified-button-configuration`，源码候选；产品行为见[按键规范](../feature/button-mapping/PRODUCT_SPEC.md)。
- 免费 `macos-combination-actions` 与付费 `macos-button-profiles` 必须来自同一候选私有 checkout。
  当前发布用固定二进制仍使用兼容接口，未由本轮升级或发布。
- 使用独立测试账户/数据目录，先导出旧配置并保留原免费模块绑定文件。不得用测试导入覆盖日常配置。
- 准备两台可配置遥控器、两个目标 App、本机辅助功能/输入监控权限，以及具备 Plus 权益的方案环境。
  测试脚本只使用 `printf`、`sleep` 和简单 AppleScript 返回值，不读取第三方 App 私有数据。
- 实现阶段的 ad-hoc Release App 仅用于代理 UI 检查；2026-10-03 已另行构建 Developer ID 签名、公证的用户本地测试包，见文末交付记录。

## 自动化入口

本地命令全部保留 `--disable-keychain`。三种宿主配置使用不同 scratch，避免旧模块产物影响 `canImport`：

```sh
SAYALL_COMBINATION_ACTIONS_PATH='' SAYALL_BUTTON_PROFILES_PACKAGE_PATH='' \
swift test --disable-keychain --scratch-path .build/unified-public

SAYALL_COMBINATION_ACTIONS_PATH=/path/to/private/packages/macos-combination-actions \
SAYALL_BUTTON_PROFILES_PACKAGE_PATH='' \
swift test --disable-keychain --scratch-path .build/unified-free

SAYALL_COMBINATION_ACTIONS_PATH=/path/to/private/packages/macos-combination-actions \
SAYALL_BUTTON_PROFILES_PACKAGE_PATH=/path/to/private/packages/macos-button-profiles \
SAYALL_TEST_BUTTON_PROFILES_FREE=1 \
swift test --disable-keychain --scratch-path .build/unified-paid
```

测试权益变量仅用于源码自动化和隔离 UI 数据，不得进入发布包。私有两 Package 分别执行完整 `swift test --disable-keychain`。
宿主继续执行 `scripts/test.sh`、`scripts/check-repository-boundaries.sh`、`scripts/verify-repository-governance.sh` 和 `git diff --check`。

## 页面和绑定

| 操作 | 预期 | 失败判定 |
| --- | --- | --- |
| 在按键页选设备 A、主页单击，指定快捷键 | 仅修改 A 的基础单击 | B 或双击/长按被修改 |
| 为 A 创建方案，打开“编辑键位” | 在原方案页进入“设置按键”，显示当前设备图片和普通键 | 跳转到另一设备、方案或改变原布局 |
| 不添加覆盖，查看主页键 | 显示继承及实际基础行为 | 空覆盖被视为禁用或默认动作 |
| 明确指定方案快捷键，再指定“不执行” | 分别覆盖/停止，基础绑定保留 | 禁用后执行基础动作 |
| 清除方案覆盖 | 恢复继承，基础值未修改 | 失去原基础参数 |
| 从按键编辑区进入组合动作，创建并保存，然后返回 | 回到原设备/按键，用户明确选择动作 | 保存即自动绑定或返回别的设备 |
| 编辑被多个位置引用的动作 | 引用位置均使用最新保存内容 | 只影响其中一处或按名称猜测 |
| 在动作页查看引用，点击引用 | 跳到对应设备/方案/按键/触发方式 | 串到默认小米设备或生效方案 |
| 删除动作前查看影响范围，再删除 | 引用保留并提示不可用；触发安全停止 | 自动执行基础、其他宏或默认动作 |
| 删除当前编辑方案或撤销 Plus | 显示可用编辑对象，不把失败保存当成功 | 页面继续写不存在/无权益的方案 |

简单快捷键/App/聚焦必须仍可就地设置；切换动作不清除已录入参数。
组合动作页保留输入框学习、重新学习、单步测试与整组测试；不再捕获实体按键用于绑定。

## 三步编辑与旧数据

1. 新建或复制：进入基本设置，库列表隐藏；名称同排录入，选择首个动作后进入编排。
2. 编排：左侧选步骤、添加、删除、排序，右侧只显示当前参数。快捷键录入、重新学习和单步测试可用。
3. 测试与保存：显示完整步骤与参数摘要、整组测试的逐步结果；不执行测试也可保存有效草稿。
4. 任意步骤取消；原动作定义、ID、已绑定位置和旧快捷键/输入框目标保持不变。新建/复制取消不得留下空动作。
5. 用旧 0.1/0.2/0.3 库与 button-bindings.json 升级；检查稳定 ID、绑定、快捷键与学习数据保留；
   执行后编辑同一动作并保存，所有引用使用新内容；原文件与旧版本仍可恢复。
6. 返回动作库，浏览或切换动作不得自动保存。保存后回原按键位置，明确选择才能绑定。

## Siri Remote 与 Chromecast 键位方案

| 操作 | 预期 | 失败判定 |
| --- | --- | --- |
| 选择 Siri Remote A2540/A2854，进入方案摘要和设置按键 | 各自图片和热点准确，包含播放暂停、TV、静音，语音键不可编辑 | 显示小米图片、热点堆在中心、出现 YouTube/Netflix/输入源 |
| 选择 Chromecast，进入设置按键 | 14 个普通物理键，默认左/右/确定锁定；包含 YouTube、Netflix、输入源 | 显示小米菜单/TV、锁定键可以被选中编辑 |
| 在原按键页只放开 Chromecast 左键，回方案设置按键 | 左键可编辑，右键和确定仍锁定 | 两页策略不一致 |
| 已放开的键重新锁定 | 不能编辑或被方案接管，原数据保留供再次放开使用 | 系统键被编辑拦截或原绑定静默丢失 |
| 为两种遥控器专有键分别绑定单击/双击/长按，重启并导出导入 | 设备、按键、手势和动作保留 | 未识别专有键、串到另一设备、导出型号错误 |
| 自动切换前台 App 时仍停留在草稿 | 当前生效方案改变，编辑对象固定 | 草稿随前台切换或被自动保存 |

在生产最小 `1020 × 772` 窗口逐一点击按键、组合动作、键位方案，分别记录浅色/深色的画布、
编辑器、每个向导步骤和硬件预览。截图只验证界面；实体键、系统媒体副作用、首次语音、连续会话和尾音仍需真机。

## 场景与手势

1. 为同设备同 App 配置规则并重复修改；只能有一条有效规则。
2. 自动模式依次执行“已配置 App → 无线麦 → 前台未知 → 已配置 App → 未配置 App”。
   已配置命中专用方案；无线麦/未配置 App 使用默认；未知沿用当前，不能抖动。
3. 编辑另一个方案时重复第 2 步。当前生效状态改变，正在编辑对象保持固定。
4. 换到手动模式，再恢复自动；两台设备各自按规则执行，不互相覆盖。
5. 在双击等待、长按阈值前、按住连发及 App 切换器期间切换方案；未完成普通交互被取消，
   不补发旧动作，不遗留修饰键；下一次完整按键使用新方案。
6. 运行耗时动作时切换方案或保存动作的新内容。正在运行的根动作仍使用启动快照，下一次触发使用新定义。
7. 缺省/明确关闭自定义映射、开启、使用后关闭分别验证；关闭时原稳定路由不被私有方案接管。

任一串设备、旧动作补发、重复启动或第三方未实际响应均为失败。
前台切换自动化只证明规则/路由，不证明真实 App 已收到输入。

## 迁移、备份与回滚

1. 准备旧基础快捷键、旧免费宏绑定和同一按键的方案覆盖；记录旧执行优先关系。
2. 启动新版，确认迁移前宿主配置、设备映射已备份，原免费绑定文件仍在；宏定义全部保留。
3. 方案覆盖仍优先；移除覆盖后使用已迁入基础的宏；旧快捷键/App 参数未丢失。
4. 再次启动，不能重复迁移或覆盖已编辑的新绑定。
5. 恢复 A 的基础默认：A 不再执行旧全局宏，B 的映射保持原值；恢复方案只清除方案覆盖。
6. 导出/导入格式 2，新绑定/旧参数保持；格式 1 继续读取。旧版必须拒绝格式 2。
7. 导入无效明确宏绑定：报告拒绝并保存为“不执行”，不得暴露旧下层绑定。
8. 回滚使用保存的原宿主备份、原设备映射和原免费绑定文件。新功能数据保留在独立键/授权文件中。

## 脚本

| 操作 | 预期 | 失败判定 |
| --- | --- | --- |
| 缺省高级开关、明确关闭时触发脚本 | 拒绝执行 | 导入/绑定即执行 |
| 开启，授权 `printf 'ok'`，测试/整组运行 | 退出 0、测试显示 ok | 按键/音频线程阻塞 |
| 改源码或 sh/zsh，再触发 | 重新授权前拒绝 | 沿用旧内容授权 |
| 用户选择 UTF-8 脚本，保存后改外部文件 | 本机保存源码不跟随文件 | 后续隐式读取外部版本 |
| 脚本 `exit 7`，后接第二步 | 非零退出，第二步不执行 | 失败后继续或回退绑定 |
| AppleScript `return 42` | 系统解释器返回 42 | 通过其他解释器运行 |
| `sleep 30 & wait`，测试超时或点击取消 | 所属进程组结束，页面恢复可用 | 子进程残留或取消无终态 |
| 子进程忽略 TERM，或关闭高级开关 | 强制结束该进程组 | 父进程退出后子进程继续 |
| 输出超过 64 KiB | 页面输出截断，继续排空管道 | 卡死/无限内存增长 |
| 宏运行期间重复触发 | 第二次拒绝；原运行继续 | 取消原运行重启或产生第二组副作用 |
| 导出后在本机/另一 Mac 导入同一内容 | 不携带授权，重新授权后才能执行 | 导入后自动恢复授权 |
| 社区/官方预设含脚本 | 导入/导出严格拒绝 | 社区代码变成本机授权代码 |

首次 AppleScript Automation 权限的系统拒绝与恢复需真实测试，不得用简单返回值替代。
脚本测试输出只在页面内存，运行日志不能含脚本源码、参数正文、路径或原始输出。

## 2026-10-03 用户反馈修复回归
