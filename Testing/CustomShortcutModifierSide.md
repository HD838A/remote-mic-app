# 自定义快捷键左右侧修饰键测试

## 适用版本或分支

- 改动：自定义快捷键保留并注入左/右侧修饰键（`CustomKeyboardShortcut` + `KeyboardInjector.postShortcut` + `postModifierState`）
- 缺陷记录：[`Bugs/2026-09-05-custom-shortcut-loses-modifier-side.md`](../Bugs/2026-09-05-custom-shortcut-loses-modifier-side.md)
- 注意：本修复的 `flagsChanged` 注入只用于组合快捷键路径；语音键左/右 Command 长按与独立左右修饰键动作不在范围内
- 平台：macOS 14 及以上
- 设备：RC003（RC001 如可用可一并回归）
- 第三方软件：区分左右侧修饰键的语音/热键软件（本例：右 Command + 逗号）

## 测试前准备

1. 启用“自定义按键映射”，并授予**输入监控 + 辅助功能**权限（ad-hoc 包重签名后需重新授权）。
2. 打开 `~/Library/Logs/RemoteMic/runtime.log`，关注 `HID BUTTON`。
3. 在目标软件中把热键设为右 Command + 逗号。
4. **重要**：升级后必须**重新录制**快捷键——旧配置不含侧别信息。

## 用例 1：重新录制并确认显示侧别

1. 「按键映射」→ 选电源键 → 单击动作选“自定义快捷键”→ 点击录入 → 按**右 Command + 逗号**。
   - 预期：显示为带侧别的形式（中文界面显示“右⌘,”；英文显示“R⌘,”）。
2. 退出并重开 App，回到该页。
   - 预期：仍显示“右⌘,”，侧别已持久化。

失败判定：显示为不带“右/R”的 `⌘,`，说明侧别仍被丢弃。

## 用例 2：目标软件被右 Command 触发（核心）

1. 让目标语音软件在后台运行、其热键设为右 Command + 逗号。
2. 按遥控器电源键。
   - 预期：软件被触发（与手按右 Command+逗号等效）；日志出现 `HID BUTTON button=power trigger=singleClick action=customShortcut`。

失败判定：软件无响应。此时请确认它是否要求“按住”而非“点按”，并收集日志。

## 用例 3：左侧修饰键对照

1. 重新录制为**左 Command + 逗号**。
   - 预期：显示“左⌘,”/“L⌘,”。
2. 按电源键。
   - 预期：目标软件（只认右侧）**不**被触发——证明左右确实被区分。

失败判定：左右无差别，说明侧别未真正生效。

## 用例 4：⌘+, 的固有冲突（须如实记录结果）

1. 让 Safari 或“备忘录”等 App 处于前台，按电源键。
   - 观察：是否打开该 App 的“设置/偏好设置”。
   - 说明：`⌘+,` 是 macOS 全局约定的设置快捷键，且 Cocoa 匹配不区分左右。若目标软件消费了事件，则不会打开；若未消费，仍会打开。
2. 若仍打开设置：把电源键改用无人占用的组合（如 `⌃⌥⌘+某键` 或 F13–F20），并在目标软件中配同一组合。
   - 预期：不再误触其他 App 的逻辑。

失败判定：改用无冲突组合后仍误触其他 App。

## 用例 5：连按与卡键回归

1. 连按电源键 10 次以上。
   - 预期：无卡修饰键（键盘输入正常、无 ⌘ 残留）；每次都发送完整组合。
2. 在按下瞬间退出 App。
   - 预期：不残留按下的修饰键。

失败判定：出现修饰键卡住、系统卡顿或输入异常。

## 稳定功能回归

- 旧配置（升级前录制、不含侧别）继续按原方式工作，行为与上一版一致。
- 固定组合动作（Command-C/V/W/Q 等）不受影响。
- 自定义 App 的“激活后发送聚焦快捷键”策略仍能正常聚焦。
- 语音键（Fn/地球键、左/右 Command 长按）与语音链路不受影响，其注入路径本次未改动。
- 方向键长按连发、双击/长按映射不受影响。

## 日志收集

1. 复制 `~/Library/Logs/RemoteMic/runtime.log`。
2. 标注用例、录制的快捷键（含侧别）、目标软件与其热键设置、前台 App、开始/结束时间。
3. 重点搜索：`HID BUTTON`、`APP FOCUS`。

## 验证边界

- 自动化仅覆盖进程内的记录与注入顺序：设备位保留、侧别键码、`down → 主键 → 逆序 up`、失败仍释放、旧配置 flags-only。
- **右侧 Command 能否被目标软件真正识别、以及 `⌘+,` 是否仍被其他 App 抢走，必须真机验收**；本改动尚未完成真机验收。
