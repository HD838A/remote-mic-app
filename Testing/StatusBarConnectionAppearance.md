# 状态栏连接外观测试手册

## 适用范围与准备

- 适用分支：`codex/status-bar-connection-437`，对应 [Issue #437](https://github.com/HD838A/remote-mic-app/issues/437)；验收时记录精确 Commit、App 版本和 Build。
- 重点系统为 macOS 15；兼顾 Apple Silicon 最低 macOS 14、Intel 最低 macOS 13 及当前主版本。
- 使用对应 Commit 的生产 App，退出其他实例。记录系统版本、语言、外观及每个用例的时间段。
- 分别准备小米遥控器、Siri Remote、iPhone、Apple Watch 和手机网页版；移动来源与 Siri Remote 需要具备相应组件的集成构建。公开兼容层无法代替这些来源的真实连接。
- 悬停文字和无障碍标签应包含产品名及当前状态。图标只表达连接与语音活动，不证明音频设备、输入权限或第三方文字输入已可用。



## 用例 1：无设备启动与入口可用性

1. 断开所有来源，启动 App，保持菜单关闭。
2. 观察图标并悬停，再用 VoiceOver 检查状态说明。
3. 左键点击图标打开窗口，关闭窗口后右键点击图标打开状态菜单。

预期：首次显示即为普通图标的系统灰化外观；文字为“未连接设备”；左键、右键、菜单操作均可用，灰化不等于按钮禁用。

失败判定：启动时持续正常显示、必须打开菜单才灰化、按钮无法点击、图标消失或错误显示某个硬件型号。



## 用例 2：逐个来源连接、失败与重连

分别对小米遥控器、Siri Remote、iPhone、Apple Watch 和网页版独立执行，其他来源保持断开：

1. 开始扫描或等待连接，暂不建立有效会话。
2. iPhone、Watch 和网页版停留在等待授权；网页版另覆盖等待扫码、中继连接中、失败及重试。
3. 完成有效连接，保持菜单关闭并观察图标。
4. 主动断开或取消连接，再建立连接；另覆盖设备失联和休眠唤醒后的恢复。

预期：扫描、仅开启监听、等待扫码或授权仍灰化；有效连接自动恢复普通图标和“设备已连接”；最后一台设备断开自动灰化；重连无需重启或打开菜单。音频未配置或输入权限不足不会将有效连接伪装为断开。

失败判定：等待状态被当作在线、真实连接后仍灰化、取消或失败后状态残留、一个来源更新只能靠另一个来源事件触发。



## 用例 3：多来源与多实体设备

1. 两只实体遥控器同时连接，逐只断开。
2. 实体遥控器与一个移动来源同时连接，分别交换断开顺序；再覆盖移动来源与网页版并存。
3. 保留离线历史设备档案并断开全部来源。

预期：仅在最后一个有效连接结束后灰化；当前选中设备和离线历史档案不影响结果。每只在线设备的按键和配置保持独立。

失败判定：断开一台就灰化、历史档案令图标永久正常显示，或图标逻辑改变连接与设备选择。



## 用例 4：语音优先级与稳定路径

1. 在有效连接上开始语音，观察活动图标与“正在传输语音”。
2. 正常松键，确认语音结束后恢复已连接普通图标。
3. 收音中断开最后一个来源，观察会话结束后的灰化；快速连续开始和结束两次语音。
4. 分别在实体遥控器与移动来源执行普通按键和一次完整短句输入。

预期：模型仍报告语音活动时优先显示活动图标，结束后按当前连接状态恢复。图标更新不引入语音等待、不清空音频、不改变按键和权限流程。

失败判定：正常收音期间错误灰化、结束后残留活动图标、首次按键或语音失效、尾音丢失。音频验收继续遵守 [通用硬件语音音频合同](HardwareVoiceAudioContract.md)。

对于 RC001 和 RC003 追加以下步骤：

1. 连续保持一次语音会话，观察达到约 50 秒时活动图标变为黄色。
2. 继续保持同一会话，观察达到约 55 秒时活动图标变为红色。
3. 松开语音键或让遥控器结束会话，确认图标恢复为当前连接状态；重新开始下一次会话时从普通活动图标开始。

预期：颜色只表示当前 RC001/RC003 语音会话接近遥控器时限，不显示精确倒计时，不影响音频接收、松键收尾或下一次会话。

失败判定：其他型号出现黄色或红色、RC001/RC003 未达到阈值就变色、停止后颜色残留，或颜色状态改变语音生命周期。



## 用例 5：外观、语言与菜单回归

1. 中文浅色、中文深色分别检查未连接、已连接、普通收音、RC001/RC003 黄色收音和红色收音五个状态及右键菜单选中外观。
2. 在每个状态切换为英文再切回中文，检查悬停和无障碍文字立即更新。
3. 开启增强对比度、降低透明度，重复观察和点击检查；恢复测试前设置。
4. 确认 Dock 偏好、关闭窗口、重新打开窗口、菜单重连与日志入口行为不变。

预期：图案与大小保持原样，灰化由系统处理；深浅色与选中态可辨，语言切换不会恢复错误外观、重复挂载菜单或改变状态。

PR 截图必须来自该 Commit 的生产 App，记录系统、版本、Build、外观和生成方式，提供 GitHub 可访问的持久证据。隔离按钮测试或设计图不代替实际菜单栏截图。



## 日志收集与判定

通过右键菜单“显示日志”收集对应时间段，查找 `UI STATUS_ITEM`：

```text
UI STATUS_ITEM operation_id=1 phase=completed result=applied from=none to=disconnected rendering=image
```

- 首次应用及展示状态变化各记录一次；重复连接通知、无状态变化的菜单打开或语言切换不重复记录。
- `from` / `to` 使用 `none`、`disconnected`、`connected`、`streaming`、`streaming_warning`、`streaming_critical`；`rendering` 区分图片与文字回退。
- 操作编号只在当前进程内递增。日志不得包含设备名称、标识、授权码、URL、音频或输入内容。
- `result=applied` 仅表示已设置按钮属性，不能证明实际屏幕像素、硬件完整可用或第三方语音成功。
- 真机断连、拒绝、取消、失败和恢复应结合原有连接日志核对，不增加或改变底层连接事件。



## 自动化与验收边界

定向命令：

```bash
swift test --disable-keychain --filter StatusItemPresentationTests
swift test --disable-keychain --filter LocalizationTests
git diff --check
```

- 自动化覆盖各来源独立变化、Web 非连接状态、部分断开、收音优先、RC001/RC003 的 50 秒和 55 秒阈值、其他型号不变色、会话结束复位、重复事件去重、初始快照、发布值早于属性写入、原生按钮属性及双语资源。
- 按钮属性测试不能证明真实状态栏左右键路由、系统菜单选中态或最终像素；这些必须按上述步骤实测。
- 本地依赖由用户准备，不自动安装；按当前任务约束不额外运行构建脚本。
- 已完成 Apple Silicon 本地 Debug 构建的实际菜单栏与 Tooltip 截图，覆盖中文浅色下的未连接、已连接和语音活动三态；截图证明状态栏展示行为，不等同于完整的生产发布验收。
- 英文、深色、VoiceOver、增强对比度、全部真实来源连接和完整语音流程仍需后续矩阵验收；这些是发布级完整性检查，不改变本 PR 已完成的局部实测结论。
- 若 PR #379 已合入，追加隐藏图标、连接状态变化、重新显示后的状态检查；若 PR #150 已合入，追加鼠标模式活动提示与语音优先级回归。
