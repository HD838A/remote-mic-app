# 遥控器鼠标移动测试手册

## 适用版本与分支

- 功能：遥控器普通按键的鼠标移动动作，以及移动后按 OK 单击（P1）。
- 分支：`feat/mouse-actions-20261127`。
- 产品规范：[`feature/mouse-control/PRODUCT_SPEC.md`](../feature/mouse-control/PRODUCT_SPEC.md)。

## 测试前准备

1. 使用公开模式构建或安装包：`SAYALL_PRIVATE_PLATFORM_MODE=public`。
2. 准备 RC001 和 RC003 各一只，并在 Mac 上完成连接。
3. 在系统设置中授予辅助功能和输入监控权限。
4. 打开按键映射页，在「打开 App」后面的「鼠标」分类里，把方向键分别设置为“↑ 鼠标向上 / ↓ 鼠标向下 / ← 鼠标向左 / → 鼠标向右”。
5. 为测试键选择“按住时 → 重复执行单击动作”。
6. 打开诊断日志，记录测试开始时间。

## 自动化与真实环境边界

- 自动化覆盖速度曲线、亚像素、松手补位移、15 秒上限、32ms 卡顿上限、事件创建失败、光标不可用、屏幕边界、权限拒绝、开始/结束生命周期，以及 OK 单击的 5 秒窗口、开关、按下消费和注入失败回退。
- 自动化不证明真实 HID 报告、真实辅助功能权限、真实显示器布局、真实鼠标单击落点和真实目标 App。
- 本手册必须在 RC001 和 RC003 上分别执行。未完成真机矩阵时，功能只能标记为候选。
- Windows 由独立仓库实现和验收，本手册不证明 Windows 的鼠标移动、OK 单击或点击落点。

## 用例

### M1 冷态首按

- 步骤：App 启动后不按其他键，直接按住“→ 鼠标向右”键 100ms 后松开。
- 预期：按下后立即开始移动，不等 350ms；松手立即停止；光标向右移动约 20 点。
- 失败：首按无移动、等待 350ms、松手后继续移动。

### M2 精细窗口

- 步骤：按住“→ 鼠标向右”500ms 后松开。
- 预期：前 500ms 保持较慢初速；总位移约 100 点；没有明显跳动。
- 失败：一秒内飞过半个屏幕、移动不连续、松手后继续移动。

### M3 长按加速

- 步骤：按住“→ 鼠标向右”2 秒后松开。
- 预期：约 1.2 秒达到最大速度；2 秒总位移约 1100 点（20 点档）；松手立即停止。
- 失败：速度无变化、加速度突变、长按过冲、松手后继续移动。

### M4 距离配置

- 步骤：在按键映射页把“→ 鼠标向右”距离改为 40，保存；按住 100ms 后松开。
- 预期：约 40 点；重开设置页后仍显示 40；重启 App 后仍为 40。
- 失败：距离被重置、移动到 1–100 之外、保存后不生效。

### M5 连续会话

- 步骤：快速短按 5 次，每次间隔小于 1 秒。
- 预期：每次都有小幅移动；5 次后停止；没有残留会话。
- 失败：某次无响应、连续移动不停、光标漂移。

### M6 双方向

- 步骤：同时按住“→ 鼠标向右”和“↓ 鼠标向下”300ms 后松开。
- 预期：光标向右下移动；两个方向都停止。
- 失败：只移动一个轴、松手后继续移动、方向反转。

### M7 屏幕边界

- 步骤：把光标移到屏幕右侧，持续按住“→ 鼠标向右”2 秒。
- 预期：光标停在屏幕边界内；日志记录 requested/observed 差异；松手后停止。
- 失败：光标消失、跳到另一块屏幕、越界后继续累积。

### M8 多显示器与 Retina

- 步骤：在双显示器、不同缩放和 Retina 屏幕上重复 M1、M3、M7。
- 预期：光标在显示器并集内移动；速度手感一致；点单位与系统光标一致。
- 失败：坐标错位、跨屏跳变、速度随缩放明显变化。

### M9 断连与重连

- 步骤：按住“→ 鼠标向右”时断开遥控器；重连后再按一次。
- 预期：断连立即停止；重连后不自动恢复旧会话；新按下可以重新移动。
- 失败：断连后继续移动、重连后自动移动、无法重新开始。

### M10 睡眠与唤醒

- 步骤：按住“→ 鼠标向右”时让 Mac 睡眠；唤醒后检查光标和日志。
- 预期：睡眠路径停止会话；唤醒后不自动移动。
- 失败：唤醒后光标继续移动、日志缺少结束原因。

### M11 权限撤销

- 步骤：按住“→ 鼠标向右”时在系统设置撤销辅助功能权限。
- 预期：移动立即停止；日志记录权限或输入重置原因；不吞掉其他按键。
- 失败：继续移动、光标卡住、其他按键失效。

### M12 语音键

- 步骤：按住“→ 鼠标向右”时按下语音键。
- 预期：语音会话开始时鼠标移动停止；语音首字和尾音不受影响。
- 失败：说话时光标乱跑、语音首字延迟、松手后继续移动。

### M13 切换器与常用语

- 步骤：按住“→ 鼠标向右”时打开 App 切换器；另一次按住时打开常用语面板。
- 预期：会话开始即停止鼠标移动；切换器和面板自身按键语义正常。
- 失败：光标在切换器中移动、面板按键被鼠标会话抢走。

### M14 配置与来源切换

- 步骤：按住“→ 鼠标向右”时切换设备、键位方案或修改动作。
- 预期：当前移动立即停止；新配置下一次按下才生效。
- 失败：旧会话继续、配置修改后仍用旧距离。

### M16 移动后按 OK 单击

- 步骤：在「鼠标」分类打开「移动后按 OK 单击」（默认关闭）；按住“→ 鼠标向右”约 200ms 后松开，5 秒内按一次 OK。
- 预期：光标移动到目标位置后，OK 在光标处产生一次左键单击；释放 OK 不产生第二次点击；OK 原绑定不执行。
- 失败：没有点击、点击位置不是光标位置、双击或长按窗口延迟点击、点击两次、同时执行 OK 原绑定。

### M17 窗口过期与无移动

- 步骤：不移动鼠标直接按 OK；再移动鼠标后等待超过 5 秒按 OK；关闭「移动后按 OK 单击」后重复移动和 OK。
- 预期：三种情况都执行 OK 原绑定，不产生鼠标点击。
- 失败：无移动也点击、过期后仍点击、关闭开关后仍点击。

### M18 点击失败与上下文

- 步骤：撤销辅助功能权限后在移动窗口内按 OK；另在 App 切换器、常用语面板和快捷键录入期间按 OK。
- 预期：权限不足时不伪造点击并继续原有失败处理；切换器、常用语和录入期间按各自语义处理，不产生鼠标点击。
- 失败：权限不足仍声称点击成功、切换器或常用语被鼠标点击抢走、OK 原绑定被静默吞掉。

### M19 OK 原绑定明确可见

- 步骤：把 OK 原绑定设为一个可观察动作（例如“返回”），分别测试移动窗口内和窗口外。
- 预期：窗口内只点击；窗口外执行“返回”；日志能区分两条路径。
- 失败：行为随上一次按键偶发变化、窗口内仍执行“返回”、日志无法定位路径。

### M15 无权限

- 步骤：撤销辅助功能权限后按“→ 鼠标向右”。
- 预期：不移动；显示既有权限提示；不伪造成功。
- 失败：无提示、日志声称成功、其他动作被阻断。

## 稳定功能回归

- 方向键本身仍可按配置发送方向键。
- 滚动、翻页、打开 App、组合动作和常用语不因新增分类或动作而改变。
- 按住重复的 350ms 启动时间对非鼠标动作保持不变。
- 旧配置加载后默认距离为 20，不出现迁移失败。
- 完整配置备份导出/导入后距离保留。
- 含鼠标动作的社区键位方案导出保留动作和距离；旧宿主缺少字段时按版本不兼容处理。
- 按键映射页是鼠标分类和距离的唯一编辑入口；键位方案页只显示概览并跳转到按键页，不出现距离编辑控件。

## 日志收集

- 过滤 `MOUSE MOTION`、`MOUSE MOVE`、`MOUSE CLICK`、`HID INPUT_RESET`、`BUTTON HOLD`。
- 记录 start/completed 的 `operation_id`、`result`、`duration_ms`、`ticks`、`requested_pt`、`observed_pt`、`dropped_ms`、`errors`；OK 单击记录 `result`、`reason=ok_after_move`、`since_move_ms` 和 `elapsed_ms`。
- 日志不得包含绝对光标坐标、用户内容、设备身份或第三方 App 私有状态。

## 失败判定汇总

以下任一情况判失败：

- 按下后等待 350ms 才移动。
- 松手后光标继续移动。
- 到达边界后越界或跳到其他屏幕。
- 断连、睡眠、权限撤销、语音、切换器、常用语、配置切换后仍有移动会话。
- 距离或按住行为被静默重置。
- 移动后按 OK 单击开关无效、窗口边界错误、点击两次或吞掉 OK 原绑定。
- 日志声称成功但真实光标没有移动或没有真实单击落点。
- 自动化通过但 RC001/RC003 真机未执行，却被报告为已验收。
