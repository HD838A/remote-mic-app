# 实体方向键抑制修复测试手册

## 适用范围

- 分支：`codex/fix-issue-137`（包含原修复及 Issue #137 丢失 release 自愈）
- 平台：macOS；RC001 或 RC003 处于非独占 `HID CONNECTED mode=monitored` 监听路径
- 目标：确认遥控器方向键连发、松开、断连和状态重置后，不会继续拦截 MacBook 实体方向键。

## 测试前准备

1. 安装并启动包含本修复的 Mac App。
2. 同时授予输入监控和辅助功能权限，并启用“自定义按键映射”。
3. 连接 RC001 或 RC003，确认运行日志出现 `HID CONNECTED mode=monitored`。如果只出现 `mode=seized`，本机没有进入受影响路径，应换用能够复现兼容监听模式的环境。
4. 将遥控器上、下、左、右分别映射为对应方向动作。
5. 记录测试开始时间，完整保留 `~/Library/Logs/RemoteMic/runtime.log`。

## 用例一：四个方向键正常长按与松开

对上、下、左、右分别执行：

1. 在普通文本或列表界面按住遥控器方向键至少 1 秒，确认产生连续移动。
2. 松开遥控器。
3. 立即短按和长按 MacBook 实体键盘的同方向键，再测试另外三个方向键。

预期结果：遥控器保持既有 350ms 后连发行为；松开后立即停止。MacBook 同方向和其他方向键均正常，短按、长按和系统自动重复均可用。

失败判定：实体同方向键无响应、只能松开不能按下、必须退出无线麦才恢复，或遥控器松开后仍持续移动。

## 用例二：音量键正常长按与松开

对音量加、音量减分别执行：

1. 按住遥控器音量键至少 1 秒，确认产生连续音量变化。
2. 松开遥控器后，立即短按和长按 MacBook 实体音量键。
3. 再测试另一个方向的实体音量键。

预期结果：遥控器保持既有连发行为，松开后立即停止；MacBook 实体音量加减均可正常短按和长按。

失败判定：实体音量键无响应、必须退出无线麦才恢复，或遥控器松开后系统音量仍持续变化。

## 用例三：按住期间断连

分别使用方向键、音量键、确定、Home、菜单、TV 和关机键执行：

1. 按住遥控器目标按键。
2. 在保持按住状态时让遥控器断开，或关闭其蓝牙连接。
3. 日志出现 `HID DISCONNECTED` 后，测试 MacBook 对应实体键或系统功能。
4. 重新连接遥控器，再执行一次正常短按和长按。

预期结果：断连时立即清除连发和抑制状态；对应实体键或系统功能正常；重连后的遥控器映射继续可用。

失败判定：断连后对应实体键仍被拦截、重连后重复触发，或必须重启 App 才恢复。

## 用例四：休眠、权限和开关重置

分别在遥控器方向键刚使用完和正在按住两种状态下执行：

- 关闭再开启“自定义按键映射”；
- 撤销输入监控或辅助功能权限并返回 App；
- Mac 休眠后唤醒并等待遥控器恢复。

预期结果：每次状态重置后 MacBook 实体四个方向键均正常；权限恢复并重新启用映射后，遥控器方向键可以继续使用。

失败判定：任一状态重置留下实体键盘阻塞、系统持续错误音、遥控器重复动作或监控无法恢复。

## 用例五：丢失 release 后实体键盘自愈

自动化按以下事件顺序执行；真机环境若能稳定制造蓝牙报告丢失，则使用相同顺序复验：

1. 在 `mode=monitored` 下交付遥控器左键或右键 `down` 以及系统原始首击。
2. 不向 monitor 交付对应 `up`，再交付一次带 autorepeat 标记的原始重复事件。
3. 使用 MacBook 内置键盘按同方向键一次，再保持按住触发系统自动重复。
4. 对另一个方向和外接键盘重复以上步骤。

预期结果：遥控器原始首击和自动重复不会绕过自定义映射；实体键盘第一次非重复首击立即通过，同时清除陈旧抑制状态，随后自动重复也正常。

失败判定：实体键盘第一次首击被吞掉、只能移动一次但无法连续移动、必须等待超时或退出无线麦才能恢复，或正常遥控器长按产生重复的系统原始事件。

## 稳定功能回归

- 四个遥控器方向键在其他 App 中仍可按住连续移动。
- 无线麦自身位于前台时，方向键不会持续触发系统错误音。
- 返回键和音量加减的既有连发不退化。
- 返回键不应拦截 MacBook Delete 键；该遥控器按键没有对应的原生抑制事件。
- 两只遥控器同时连接时，一个设备的按下、松开或断连不会释放或阻塞另一设备的按键状态。
- 两只遥控器正常按住同一方向键时，系统 autorepeat 在两者均松开前继续被抑制。
- 自定义快捷键、单击、双击和长按仍按各自配置执行一次。

## 日志收集

出现失败时记录：App 版本、遥控器型号、是否双遥控器、连接模式、具体方向、按住时长、断连或权限操作时间，以及完整运行日志。重点核对 `HID CONNECTED mode=...`、`HID BUTTON`、`HID DISCONNECTED` 和权限失效前后顺序。

## 验证边界

- 既有自动化覆盖生产 HID parser、monitor、定时连发、suppressor 和断连重置。Issue #137 新增生产 suppressor 事件回放，覆盖左键缺失 release 后实体键盘首击与 autorepeat 自愈；需由 PR CI 完成执行确认。
- 自动化不能证明真实 CGEvent tap、系统键盘来源、蓝牙固件 release 丢失、休眠唤醒和最终实体键盘体验。
- 用例一至五必须在真实 `mode=monitored` 环境完成后，才能将本 Bug 标记为真机验收通过；若无法稳定制造丢包，必须明确记录用例五未完成，不能用正常松开或断连替代。
