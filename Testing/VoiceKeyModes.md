# 语音键模式测试手册

## 适用范围

- 适用分支：`codex/voice-key-command-modes` 及包含该功能的 macOS 版本。
- 功能范围：Fn/地球键（默认）、左 Command 长按、右 Command 长按。
- 本手册不把模拟 HID、单元测试或构建结果视为 RC003、iPhone、Apple Watch、网页版或第三方语音应用的真机验收。

## 测试前准备

1. 使用 macOS 14 或更高版本，安装待测无线麦 SayAll.app；授予输入监控和辅助功能权限。
2. 准备 RC003、小米蓝牙遥控器 2 Pro，确认能连接并选择 `MiRemoteV 2ch` 或其他已验证的回环设备。
3. 准备一个支持 Fn 长按的语音应用，以及明确支持左/右 Command 长按的测试应用。记录应用版本和快捷键设置。
4. 如测试 iPhone、Apple Watch 或网页版，先完成对应连接授权，并确保目标 Mac 语音输入应用已聚焦。

## 配置与界面

1. 打开“按键映射”，确认语音键区域显示三种模式：Fn/地球键、左 Command、右 Command。
2. 在 `800 × 650` 设置窗口逐一检查映射页侧边栏、页头、语音键区域、滚动区域和底部说明，没有裁切或改变窗口几何。
3. 选择 Fn/地球键，确认“语音键模拟 Fn 点按”可配置；选择任一 Command 模式，确认该开关被停用或不可编辑，并显示辅助功能和目标应用兼容性说明。
4. 关闭并重新打开 App，确认选择持久化。导入没有 `voiceKeyMode` 字段的旧 JSON，确认回退到 Fn/地球键；导出后确认包含当前模式。

失败判定：选项缺失、左右 Command 显示为同一个模式、旧配置被拒绝或默认变成 Command、Command 模式仍能同时开启 Fn 点按、中文文字小于 12pt。

## Fn 基线回归

1. 选择 Fn/地球键，关闭 Fn 点按模式。
2. 聚焦目标输入框，按住 RC003 语音键讲话，松开并等待文字上屏。
3. 重复两次，覆盖短句、约 10 秒语音和连接重建后第一次语音。

预期：目标应用看到 Fn/地球键按下与释放，音频完整进入所选回环设备，普通按键映射和 Fn 点按兼容模式不受影响。

## 左右 Command 长按

分别对左 Command 和右 Command 执行以下用例：

1. 选择对应模式，重新连接 RC003。
2. 聚焦目标应用，按住遥控器语音键讲话，松开后等待结束。
3. 检查目标应用是否只收到一次对应侧的 Command keyDown 和 keyUp，且语音文字正常出现。
4. 在同一会话中短暂按另一个普通键，确认没有意外执行未声明的 Command 快捷键；记录目标应用的实际行为。
5. 连续开始/结束三次，覆盖短于 1 秒、约 10 秒和快速重新开始。

失败判定：只收到按下没有释放、左右侧被合并但目标应用声称支持区分、一次会话重复发送、松开后 Command 仍影响普通输入、音频链路被阻断。

## 移动和网页语音入口

对 iPhone、Apple Watch 和网页版分别执行：开始语音、讲话、停止语音；重复两次，并覆盖停止后立即重新开始。预期与 RC003 使用相同的所选 Command 长按生命周期，且只能释放本次来源持有的键。

## 异常与清理

- 语音进行中断开 RC003 或手机连接：Command 必须释放，重新连接后可再次开始。
- 语音进行中退出 App、切换模式或撤回辅助功能权限：Command 必须释放，不得留下系统修饰键卡住。
- 正常使用实体键盘 Command：不得单独触发语音输入源切换或开始语音会话。
- 在 Fn 模式开启 Fn 点按：确认 pre-roll、音频排空和配对 Fn tap 回归；切到 Command 后不再发送 Fn tap。

## 自动化、代理与用户实测边界

- 自动化应覆盖枚举和配置迁移、左右 Command 键码、keyDown/keyUp 幂等、失败回滚、F5 中和/恢复、断连和退出清理，以及 Fn 基线。
- 自动化和代理可以证明状态机、注入调用和资源清理，但不能证明真实 RC003 固件事件、macOS 辅助功能权限、第三方应用是否区分左右 Command、真实移动设备链路或前后台行为。
- 交付前必须单独记录自动化结果、代理检查结果和用户真机结果；未执行的 RC003、iPhone、Apple Watch、网页版或第三方应用用例必须标记为“未验收”。

## 日志收集

保存 `~/Library/Logs/RemoteMic/runtime.log` 中测试时间段的日志，重点检查 voice session start/stop、voice key mode、keyDown/keyUp、mapping neutralize/restore、permission 和 cleanup 事件。日志不得包含语音内容、文字、设备地址、UUID、密钥或账号信息。
