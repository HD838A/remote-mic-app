# 语音时长倒计时测试手册

## 适用范围

- 适用版本：包含「语音时长倒计时」功能的 Mac 构建，当前为 `codex/voice-limit-countdown-20261118`。
- 适用型号：RC001、RC003。其他来源（Siri Remote、Chromecast、iPhone、Apple Watch、网页版）不显示本浮层。
- 相关合同：[通用硬件语音音频合同](HardwareVoiceAudioContract.md)、[状态栏连接外观](StatusBarConnectionAppearance.md)。
- 背景：RC001/RC003 的语音会话由遥控器固件在约 60 秒处自行结束，Mac 无法延长。本功能只做提示，不改变会话。

## 测前准备

- 一只 RC001 或 RC003，已连接并完成按键映射。
- 已选中虚拟麦克风（`MiRemoteV 2ch`）。
- 一个持续显示语音识别文字的第三方工具，并已切到「长按说话」模式（例如豆包输入法长按模式）。
- 目标 App 已打开一个可输入的文本框，光标在其中。

## 本机快速验证位置（不用等 50 秒）

带参数启动可以让浮层立即显示，用于先确认位置和外观：

```bash
pkill -f "SayAll.app/Contents/MacOS/RemoteMic"
nohup ~/Applications/SayAll.app/Contents/MacOS/RemoteMic --voice-countdown-preview 10 >/dev/null 2>&1 &
```

浮层显示 12 秒后自动消失。把 `10` 换成 `0` 可以看到「录音已结束」的形态。
日志会记录实际窗口坐标：`x_center_delta=0` 表示水平居中，`y_from_bottom` 是距屏幕底部的点数。
该参数只用于本机检查，不会自动开启任何语音或录音行为。
- 记录开始测试的时间点，便于事后在日志中定位。

## 用例 1：倒计时出现与逐秒递减

1. 把光标放到目标输入框，按住语音键开始说一段持续的话。
2. 在第 45 秒左右留意屏幕：此时不应出现任何提示。
3. 继续按住不说话或继续说话，观察第 50 秒前后。
4. 一直观察到第 60 秒，注意浮层位置与数字。

预期：

- 前 50 秒没有任何浮层。
- 约第 50 秒在**屏幕下方居中区域**（语音输入提示条的上方）出现深色圆角浮层，主数字为 `10`，下方小字为「秒后自动结束」。
- 数字每秒减 1：`10 → 9 → … → 1`，不会跳过数字，也不会停在 `1`。
- 浮层位于屏幕下方居中，与语音输入提示条处于同一片视线内，且不遮挡提示条本身。
- 浮层位置只和屏幕大小有关，不随光标、窗口或输入框位置移动。

失败判定：前 50 秒提前出现、第 50 秒以后才出现、数字跳变或倒退、浮层压住语音输入提示条、浮层明显偏离屏幕水平中心。

## 用例 2：到 0 秒的提示与遥控器实际停止

1. 重复用例 1，保持按住语音键一直到遥控器自行停止。
2. 观察第 60 秒浮层的文案变化。
3. 观察遥控器停止后浮层何时消失。
4. 说完最后一个词后立即松开语音键，读取输入框里的文字。

预期：

- 第 60 秒浮层文案变为「录音已结束」，不再显示秒数。
- 遥控器在约 60 秒发送停止后，浮层在约 3 秒内自动消失。
- 最后一句话的文字仍然进入目标输入框（与功能改动前一致）；这是一次正常收尾，不是异常中断。
- 停止前后不出现音频卡顿、爆音或长时间静音。

失败判定：到 0 秒仍然显示秒数、浮层一直不消失、浮层消失过早导致用户看不到结束提示、最后的文字丢失、音频被截断。

## 用例 3：提前松键

1. 在第 50 秒之前松开语音键。
2. 再次开始一次会话，在第 52 秒左右松开。

预期：两次都没有出现浮层；第二次在浮层已经显示后立即消失，不残留。

失败判定：提前松键后浮层残留、下一次会话立刻就把上次的数字继续显示出来。

## 用例 4：连续快速会话

1. 连续进行三次约 3 秒的短会话，每次说完立刻松开并马上再次按下。
2. 然后进行一次持续到倒计时出现的会话，再立刻开始下一次短会话。

预期：短会话从不显示浮层；长会话结束后浮层消失，下一次短会话从干净状态开始，数字不会继承上一段。

失败判定：数字继承、浮层闪烁、连续会话时浮层卡住不更新。

## 用例 5：非 RC001/RC003 来源不显示

1. 分别用 Siri Remote、iPhone、Apple Watch、网页版开始一次持续 60 秒以上的语音。
2. 全程观察屏幕下方居中区域。

预期：任何时刻都不出现倒计时浮层，也不出现「录音已结束」浮层。

失败判定：任一其他来源出现浮层。

## 用例 6：浮层不拦截操作

1. 在倒计时显示期间，继续用鼠标点击目标 App、切换窗口、在浮层位置点击。
2. 在倒计时显示期间滚动页面。

预期：所有点击和滚动都到达下面的 App/窗口；浮层不接受任何点击，也不抢焦点。

失败判定：点击浮层位置没有反应、目标 App 失焦、浮层获得键盘焦点。

## 用例 7：屏幕尺寸与多屏

1. 在默认屏幕尺寸下测一次倒计时，确认水平居中且位于中下区域。
2. 在第二块显示器上重复，确认浮层跟随鼠标所在的那块屏幕。
3. 改变分辨率或缩放后重复一次。

预期：浮层始终完整可见、水平居中，垂直方向位于屏幕中下区域，不跑到屏幕外。

失败判定：浮层被裁切、跑到屏幕边缘外、在非当前屏幕或错误屏幕出现、明显偏心。

## 用例 8：设置页语音状态行

1. 让设置窗口保持打开并显示「连接」页，同时在目标输入框长按语音。
2. 观察「语音状态」这一行。

预期：会话正常时显示「正在传输遥控器语音」；剩余 10 秒起追加「10 秒后结束」并逐秒递减；到 0 秒显示「录音已结束」；会话结束后恢复「已就绪」或「正在传输遥控器语音」。

失败判定：文字裁切、换行挤压布局、语言切换后残留旧数字、结束后仍显示结束文案。

## 日志收集

在 App 内打开日志，筛选以下关键字：

- `UI VOICE_COUNTDOWN phase=started result=armed`：会话开始，倒计时已武装（只对 RC001/RC003）。
- `UI VOICE_COUNTDOWN phase=displayed result=counting`：浮层每次显示新数字，含 `remaining_s` 与 `anchor=caret|fallback`。
- `UI VOICE_COUNTDOWN phase=ended result=notified`：显示「录音已结束」。
- `UI VOICE_COUNTDOWN phase=stopped result=hidden reason=...`：浮层收尾，`reason` 说明是会话结束还是其他来源。
- `UI VOICE_COUNTDOWN phase=stopped result=held reason=...`：到点后遥控器自行停止，浮层保留 hold 期。

日志只包含型号、秒数和原因，不包含用户语音内容、输入文字、窗口标题或设备标识。`placement=screen_bottom_center` 表示浮层固定在屏幕下方居中显示。

## 自动化、实测与验收边界

自动化（已通过，`.swift` 侧）：

```bash
swift build --disable-keychain          # 公开兼容模式构建
swift test --disable-keychain --filter VoiceLimitCountdown
```

覆盖范围：倒计时窗口的上下边界（49.9/50/59/60 秒）、向上取整规则、hold 期、刷新时机（窗口开始前不得提前结束定时器）、非法时间值、只对 RC001/RC003 生效、浮层水平居中与屏幕内收。

自动化**不能**证明的部分：

- 浮层与真实语音输入提示条的实际相对位置和层叠关系；
- 遥控器是否在 60 秒精确停止、以及停止后最后一句文字是否完整进入第三方工具；
- 多显示器、全屏 App、分辨率/缩放变化下的实际位置；
- 浮层的真实像素、对比度与深浅色外观。

以上必须用真实遥控器 + 真实输入法按用例 1–8 验收。本手册的验收结果应记录在对应 PR 中；未完成的部分保持「候选」状态，不得表述为真机验收通过。
