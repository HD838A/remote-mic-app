# 手机与手表连接会员验收

## 范围

iOS、Apple Watch、小程序与 Web 使用连接的 Mac 的 Plus，手机和手表不再次登录。会员判断和会员入口 UI 由可选私有 Host Adapter 提供；公开无私有包时仍可构建，遥控服务不可用。

## 用例

1. Free / 退出：连接页手机、Watch、Web 显示私有“打开会员页面”按钮；点击进入会员页。不能启动附近服务或生成可用连接二维码。
2. 登录有效 Plus：手机和 Watch 可启用共同连接服务，原配对批准、语音与按键流程保留；Web 由会员服务再次授权。
3. 退出：现有手机、Watch 和 Web 连接停止，二维码消失；会员页重新加载可购买方案，迟到回调不能恢复旧入口。
4. 切换 staging / production：旧连接和二维码清除；新环境按权益判断，staging 不自动免检。
5. 会员不足的 Web 会话显示会员按钮；小程序会员拒绝跳 Plus，过期码显示重新生成，失败后不可恢复另一个 Mac。
6. 有效离线租约允许附近连接；过期、无效、撤销时停止附近连接，已信任设备、配对、按键与语音不能复用过期授权。退款的既有短期会话边界沿用支付产品文档。
7. Onboarding 的 Phone/Web 入口同样使用私有会员按钮，可打开会员界面后返回向导。

自动化/构建与真实设备分别记录。待验收：iPhone/Watch 真机蓝牙、实际退出对端断线、线上 scene 失败日志、部署后的扫码。
