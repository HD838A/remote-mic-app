# 无缝续录与底部倒计时灯条测试手册

## 适用范围

小米 RC001 / RC003。无缝续录用于语音键「模拟 Fn 点按」模式，底部倒计时灯条可独立开启。

## 测试前准备

- 遥控器已连接，输入监控和辅助功能已授权，普通语音输入正常。
- 目标语音工具设置为 Fn 点按触发，开启「语音键模拟 Fn 点按」和「无缝续录」。

## 用例一：松手续录

1. 将触发门槛设为 50 秒，松手缓冲时间设为 1 秒。
2. 按住语音键说话超过 50 秒，松手后在 1 秒内再次按下，继续说话。
3. 连续续录三次，最后松手等待缓冲时间结束。

预期结果：每次重新按下可在同一次语音输入中继续录音一分钟；最后松手超时后结束输入，文字完整、顺序正确。

失败判定：续录时输入提前结束、文字缺失或重复。

## 用例二：触发门槛与缓冲时间

1. 连续续录后，下一段短于 50 秒便松手。
2. 将触发门槛设为 0，分别选择 0.5～3 秒的各档缓冲时间，测试期限内重新按下和超时结束。

预期结果：每段独立计算按住时长；短于门槛时松手立即结束。门槛为 0 时，每次松手均进入所选缓冲时间。

失败判定：短段沿用上一段时长获得等待，或实际等待时间与设置不符。

## 用例三：结束与恢复

1. 在续录等待期间，分别关闭续录、断开遥控器、退出 App、切换 Fn 模式。
2. 恢复连接和设置，再开始一次语音输入。
3. 关闭 Fn 点按，按住语音键时移动和点击鼠标，再松手。

预期结果：等待中的输入正常结束，恢复后可以重新录音；Fn 长按时鼠标操作期间持续录音，松手结束。

失败判定：Fn 卡住、重复触发、恢复后无法录音或长按录音被鼠标操作打断。

## 用例四：底部倒计时灯条

1. 分别选择「仅最后 10 秒」和「全程显示」，录音至一分钟，并测试松手续录。
2. 调节灯条宽度和发光强度，检查屏幕底部预览；将前台窗口移到另一屏幕后再次录音。
3. 关闭灯条，检查菜单栏提醒及提示音；重新打开 App，检查设置保存。

预期结果：灯条按所选时机出现，第 57 秒变红并收缩，续录时补满；宽度和强度随设置变化，预览在 3 秒后隐藏，录音光效跟随前台窗口所在屏幕。关闭灯条后保留菜单栏提醒及提示音，设置可正常保存。

失败判定：显示时机错误、预览持续停留、挡住点击、出现在错误屏幕或设置丢失。

## 日志收集

出现问题时记录遥控器型号、设置值、操作顺序和目标 App，保留对应时段的运行日志。相关日志前缀：`VOICE FN TAP continuation`、`VOICE CONTINUATION`、`VOICE GLOW`。

## 验证结果

- RC003 无缝续录已实测可用。
- 自动化测试已覆盖门槛、续录期限、录音段交接、关闭与恢复、设置保存和灯条状态。
- 已检查设置页布局和灯条离屏渲染。

## 2026-11-13 会话补充记录

### 与 60 秒问题的关系

- 本功能只适用于语音键「模拟 Fn 点按」模式；硬件 Fn 长按路径仍由远端固件和普通语音键生命周期控制。
- #1024 删除的是不可用的 `--rc003-voice-extension-test` 实验入口（物理 `STREAM_STOP` 后自动 `MIC_OPEN` + 定时 `MIC_EXTEND`），不是本 PR 的 Fn 点按无缝续录。
- #1026 处理远端 60 秒超时后强制发出一次软件 Fn 抬起；#1029 处理正常停止的尾音排空；#1030 处理本地转写候选。它们与本 PR 是独立改动，不能互相替代。
- #766 的历史测试记录：完整 Swift 测试 1079 项 / 80 suites、`scripts/test.sh` 48 项通过；作者报告 RC003 无缝续录已实测可用。该结果早于 2026-11-13 的 build 348，当前会话没有把 build 348 的 1399 项组合测试当作本 PR 的重新验收。
- 当前 build 348 未合并本 PR；没有真实 RC003 的重新续录、松手超时、关闭续录、断连恢复和灯条矩阵结果。
- 合入前必须重新执行本手册的 RC001/RC003 用例，并确认正常 Fn 长按、鼠标移动、目标工具文字和设置保存没有被续录逻辑改变。

### 边界

本 PR 不解决 60 秒固件硬停后的音频尾段，也不保证所有第三方输入法都能接受 Fn 点按续录；没有真机结果前保持 Ready 也不等于已验收。
