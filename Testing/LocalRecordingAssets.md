# Mac 本地原始录音测试手册

## 适用范围

- 分支：`codex/local-recording-assets`
- 平台：Apple Silicon macOS 14+
- 入口：侧边栏“统计”下的“回眸”
- 当前状态：候选代码，尚未完成真实硬件验收

## 测试前准备

准备 RC003、Nearby iPhone、Apple Watch 和 Web 遥控器；准备备忘录、Codex 或其他标准文本输入框；确认麦克风、蓝牙、辅助功能和输入监控权限。不要直接删除测试目录，页面删除必须确认对象进入废纸篓。

## 核心用例

1. **默认关闭**：全新偏好打开“回眸”，确认“保存原始录音”关闭；完成语音后不应出现录音资产。
2. **仅录音**：只开启保存原始录音，分别用 RC003、Nearby iPhone、Watch、Web 完成语音；确认时间线显示应用图标、名称、日期、时长和“仅录音”，不要求 AI 或 API Key。
3. **文字+录音关联**：同时开启两个开关完成一段语音；确认同一 session 只显示一条联合记录，文字和录音的应用、时间一致。
4. **独立开关**：关闭文字开关但保留录音开关，确认新录音仍保存且应用元数据正确；关闭录音开关但保留文字开关，确认文字仍保存且不产生新音频。
5. **播放与导出**：播放录音、停止后再次播放；导出到用户选择的位置；在 Finder 中显示；用系统播放器确认 M4A 可读。
6. **筛选与日期折叠**：准备多个 App 和日期，确认顶部 App 筛选同时过滤文字和录音，时间线倒序，日期可以独立折叠。
7. **删除**：删除单条录音、当前 App 录音和全部历史；确认录音目录进入废纸篓，关联文字按独立开关规则保留或删除。
8. **异常**：录音中关闭开关、切换前后台、快速连续两段、目标 App 切换、磁盘空间不足、强制退出；不得让蓝牙/移动语音链路崩溃或阻塞，失败时不得留下可见的 `.partial.m4a`。

## 失败判定

录音默认开启、音频写入阻塞实时播放、文字和录音 session 错配、应用图标/名称错误、M4A 无法播放、导出覆盖时永久删除原文件、删除不进废纸篓、MCP 返回音频路径或二进制、日志出现正文/音频路径，均判定失败。

## 日志与验证边界

日志只允许出现开始、结束、字节数和失败类别，不得包含音频、正文、路径或 App 私密内容。`swift test --filter RecordingAssetStoreTests` 只证明存储、权限、排序和设置默认值；真实 RC003、iPhone、Watch、Web、第三方 App 和音质必须人工验收，当前尚未完成。
