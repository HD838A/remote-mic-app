# 快捷指令私有模块集成测试手册

## 适用版本或分支

- 分支：最新 `main` 或由其直接创建的预览候选。
- 适用版本：`1.8.20 (112)` 及以后；`1.8.18 (110)` 因打包资源路径导致首次打开设置窗口崩溃，不得发布。

## 测试前准备

1. 本机存在私有仓库 `sayall-macro-platform`，并通过 `SAYALL_MACRO_PLATFORM_PATH` 注入构建。
2. 无线麦已获得输入监控和辅助功能权限。
3. 准备有效、无效、过期三种快捷指令邀请码或服务端测试资格。
4. 准备真实遥控器；另准备 iOS 或 Web Remote 检查同一绑定入口。
5. 至少安装 Codex、Claude 或 Chrome 中一个目标 App。

本地构建命令：

```bash
SAYALL_MACRO_PLATFORM_PATH=/Users/andy/Develop/Src/AISrc/sayall-macro-platform \
EARLY_ACCESS_SERVICE_URL=https://config.sayall.app \
REQUIRE_SAYALL_MACRO_PLATFORM=1 \
REQUIRE_EARLY_ACCESS_CONFIGURATION=1 \
./scripts/build-app.sh
```

构建结果位于 `dist/Remote Mic.app`。使用以下命令检查资源包、包含标记和签名结构：

```bash
REQUIRE_SAYALL_MACRO_PLATFORM=1 \
./scripts/verify-app.sh "dist/Remote Mic.app"
```

验证最终 ZIP 时必须先临时挪开同版本 `/private/tmp/remote-mic-swiftpm/<版本>-<Build>` 构建缓存，再从全新目录解压并打开设置窗口；否则 SwiftPM 生成的绝对构建路径可能掩盖安装包资源错误。验证结束后恢复原缓存目录。

## 用例一：公开构建回归

步骤：不设置 `SAYALL_MACRO_PLATFORM_PATH` 构建并启动 App。

预期：关于页没有快捷指令邀请码入口，侧边栏没有快捷指令；普通单击、双击、长按映射全部维持原行为。

失败判定：公开构建依赖私有仓库、出现空白入口或任意按键被私有模块接管。

## 用例二：未授权与邀请码

步骤：注入私有模块后，按受控预览测试说明从“关于”页显示邀请码入口，依次输入无效和有效邀请码。

预期：标题、说明、状态、输入提示、按钮和隐私说明均显示当前语言，不得出现 `early_access.*` 或 `macro.early_access.*` 原始 key；输入、验证、状态和隐私说明集中在一个紧凑区域，中文字号不小于 12pt。无效邀请码显示明确错误且不显示快捷指令侧边栏；有效邀请码能够解析生产服务带小数秒的 `server_time`，通过签名、版本和有效期校验后立即显示入口。完全退出并重新启动 App 后资格仍有效。关闭或撤销资格后入口消失，已有宏绑定不再执行。

失败判定：点击后没有成功或失败反馈、服务端成功但本机没有保存资格、重启后资格丢失、未授权即可执行、无效资格被接受、资格关闭后仍接管按键。

### 用例二 A：共享资格协议回归

步骤：分别在快捷指令和另一项使用共享资格客户端的内测入口使用各自有效邀请码，确认首次激活；重启 App 后检查恢复；执行“重新检查”；再输入同一邀请码确认服务端重复兑换不会让页面停在无反馈状态。

预期：两项功能都能处理生产服务返回的小数秒 ISO 8601 时间；失败时页面显示可理解状态，诊断日志只记录错误码和请求编号。

失败判定：任一功能服务端已产生 `grant.redeemed` 而本机没有 `grant-bundle`，或日志泄露邀请码、设备 ID、刷新凭据、授权令牌和用户内容。

### 用例二 B：邀请码输入框编辑快捷键

步骤：聚焦邀请码输入框，依次验证 `Command-A`、`Command-C`、`Command-V`、`Command-X`、`Command-Z` 和 `Shift-Command-Z`；再切换到其他普通文本输入框重复验证。

预期：快捷键由 AppKit responder chain 交给当前聚焦输入框，选择、复制、粘贴、剪切、撤销和重做均按标准 Mac App 行为执行；不触发退出、关窗、遥控器映射或邀请码验证。

失败判定：任一标准编辑快捷键无效、被全局监听吞掉、作用于错误输入框或触发其他 App 行为。

## 用例三：页面与本机配置

步骤：创建快捷指令，分别添加打开 App、等待 App、录入快捷键和学习输入框步骤；保存、重新进入并测试执行。

预期：页面内完成主要配置；中文字号不小于 12pt；数据重启后保留；学习记录可测试和重新学习；敏感输入框被拒绝。

失败判定：数据丢失、需要连续弹窗、输入框误聚焦或敏感输入框可被学习。

## 用例四：真实遥控器绑定

步骤：把同一快捷指令分别绑定到单击、双击和长按，使用真实遥控器触发；再撤销资格重复测试。

预期：有效资格时对应手势执行一次且不会继承导航长按重复；撤销后恢复原按键配置。

失败判定：触发次数错误、普通映射被永久覆盖、撤销后仍执行。

## 用例五：手机遥控

步骤：使用 Nearby 和 Web Remote 触发同一按键的单击、双击、长按。

预期：行为与实体遥控器一致，未授权时全部回落到原映射。

失败判定：不同入口行为不一致或未授权仍执行。

## 稳定功能回归

- RC003 普通语音：`STREAM_START → AUDIO → STREAM_STOP`。
- Fn 语音、Nearby、Web Remote、虚拟音频和普通按键映射。
- `800 × 650` 窗口逐一点击全部侧边栏入口，确认页面和滚动不裁切。

## 安装与覆盖升级

### 用例六：覆盖已安装版本

步骤：记录 `/Applications/Remote Mic.app` 当前版本和 Build；确认测试包的 Build 更高；从最终 DMG 运行图形化 Installer。

预期：Installer 成功；App 被原子更新为测试包版本；MiRemoteV 2ch 健康时不重复替换；App 能自动或手动启动；用户设置仍保留。

失败判定：出现通用安装错误、PackageKit 跳过 App payload、App 被删除、驱动无故重装或 App 无法启动。

### 用例七：旧包失败保护

步骤：在已安装更高 Build 的夹具环境运行较低 Build 的安装包；记录安装前后 App 版本、Build、签名和 SHA-256。

预期：安装在 `preinstall` 明确停止；提示现有版本更新；原 App 的版本、Build、签名和文件摘要均不变化。

失败判定：旧包覆盖新版、原 App 被退出后未恢复、任何 App 文件被删除或修改。

安装失败日志：

```bash
tail -n 300 /var/log/install.log
log show --last 30m \
  --predicate 'process == "Installer" OR process == "installd"' \
  --style compact
```

## 日志收集

通过 App 内诊断导出或 Console 收集 `Remote Mic` 日志。记录邀请码请求 ID、资格错误码、资格状态变化、按键、触发方式和是否由私有模块接管；不得记录邀请码、匿名设备 ID、刷新凭据、资格令牌、输入框文本或学习到的完整特征。

## 验证边界

已由自动化和代理验证：快捷指令私有模块 34 项、另一共享资格私有模块 23 项、宿主注入两个模块后的 222 项完整测试、42 项项目自检、Apple Silicon Release App 构建、资源和 ad-hoc 签名校验、仓库边界检查。当前 Mac 已使用真实生产服务完成无效码错误可见性、有效资格恢复、侧边栏出现、完全退出后重启恢复和“重新检查资格”。Build 67 曾因降级安装与破坏性 `preinstall` 在当前 Mac 真实安装失败；`1.8.17 (109)` 已在当前 Apple Silicon Mac 完成用例六和用例七，详见 `Bugs/2026-08-14-macro-preview-installer-deleted-newer-app.md`。

`1.8.18 (110)` 最终 Developer ID ZIP 在移除同版本构建缓存后可稳定复现首次打开设置窗口崩溃；崩溃源于快捷指令 SwiftPM 资源访问器从 App 根目录查找 Bundle，而宿主按 macOS 标准放在 `Contents/Resources`。修复后的私有组件改为优先解析 `Bundle.main.resourceURL`，并保留非 App 环境的 `Bundle.module` 回退；发布前必须用最终签名 ZIP 对原复现再次验收。

自动化只能验证编译边界、资格门禁、事件路由和 App 结构。快捷指令的真实邀请码服务与本机持久化已由代理验收；另一共享资格私有模块本轮只完成生产响应格式回归和宿主注入测试，没有独立邀请码的完整页面兑换。当前构建为 ad-hoc 签名；Developer ID 预览包、Intel Mac 安装、真实遥控器、第三方 App 输入框、系统权限、`800 × 650` 全侧边栏点击以及不同前后台状态仍需验收，未完成部分不得表述为已完成真机验证。

2026-08-14 增加本地化与编辑菜单回归：`sayall-ai` 25 项、`sayall-macro-platform` 30 项、宿主设置页专项 13 项通过。自动化已确认中英文资源不会回退为原始 key，并确认 Edit 菜单将常用编辑快捷键转发给聚焦输入框；最终签名 App 的 `800 × 650` 页面点击、真实键盘操作和两种系统语言仍需人工验收。
