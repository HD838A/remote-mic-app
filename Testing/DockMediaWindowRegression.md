# Dock、系统媒体与窗口菜单回归测试

## 适用范围

- 分支：codex/integrate-pr428-bug-fixes
- 对应问题：#386、#407、#412、#413
- 平台：macOS

## 测试前准备

1. 使用包含本分支提交的无线麦SayAll.app。
2. 准备一个响应 macOS 系统媒体控制的播放器，并播放至少三首内容的列表。
3. 保持菜单栏入口可见，避免关闭 Dock 图标后失去设置入口。
4. 记录 App Commit、macOS 完整版本与 Build。

## 用例一：Dock 图标偏好

1. 打开关于页面，关闭“在 Dock 中显示应用图标”。
2. 保持设置窗口打开并观察 Dock。
3. 重新开启该选项，再次观察 Dock。

预期：关闭后 Dock 图标立即消失；设置窗口仍可操作且菜单栏入口仍存在；开启后图标恢复。
失败判定：设置窗口打开时强制保留 Dock 图标，或切换后设置窗口无法继续使用。

## 用例二：系统音量摘要

1. 在按键映射中选择系统音量增加和系统音量降低。
2. 返回遥控器映射总览，并分别检查中文、英文界面。

预期：摘要显示为 Vol+ 和 Vol-，两者可清楚区分。
失败判定：仍显示单独的 + / −、显示为空或出现裁切。

## 用例三：上一首与下一首

1. 把两个普通遥控器手势分别映射为上一首和下一首。
2. 将播放器切到后台。
3. 分别触发两个动作。

预期：系统当前媒体会话切换上一首或下一首，不向前台文本或页面发送方向键。
失败判定：只有播放器在前台时生效、移动前台应用光标、方向相反或一次触发多首。

## 用例四：标准窗口菜单

1. 打开无线麦主窗口。
2. 检查应用菜单中的“隐藏无线麦”“隐藏其他”“全部显示”。
3. 检查窗口菜单中的“最小化”。
4. 分别测试 Command+H、Option+Command+H 与 Command+M。

预期：菜单项存在并遵循标准 macOS 行为，不退出 App，也不改变 Dock 偏好。
失败判定：菜单缺失、快捷键无效、操作导致 App 退出或无法从菜单栏重新打开设置。

## 稳定功能回归

- 普通方向键、自定义快捷键和系统音量实际执行路径保持不变。
- 语音键按下/释放生命周期、音频输出与遥控器连接不受影响。
- 切换语言后菜单文案更新且没有重复菜单项。

## 日志与验证边界

这些用例的最终结果由 macOS Dock、菜单和系统媒体会话呈现，现有运行日志只能作为辅助，不能代替可见结果。收集日志时不得包含用户内容、路径、设备身份或凭据。
