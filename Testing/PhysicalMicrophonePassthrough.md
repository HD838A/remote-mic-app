# 电脑麦克风直通测试手册

## 准备

- 安装并选择 `MiRemoteV 2ch` 作为语音输出和目标语音工具的麦克风。
- 连接一个 USB 麦克风和小米蓝牙遥控器 2/2 Pro。
- 允许无线麦的蓝牙、输入监控、辅助功能和麦克风权限。

## 用例

1. 默认关闭：启动后确认“混入电脑麦克风”关闭，键盘触发时 USB 声音不会进入虚拟麦克风，遥控器语音保持原行为。
2. 等待状态：选择 USB 麦克风并开启，确认页面显示“等待右 Command”，且 macOS 不显示无线麦正在使用麦克风。
3. 成功开启：第一次按右 Command，确认页面显示“已接入”；说话后文字正常出现。
4. 正常释放：再次按右 Command，确认页面恢复等待状态，且 macOS 麦克风使用提示消失。
5. 遥控器回归：保持功能开启，按住遥控器语音键说话并松开，确认首字与尾字完整、文字只提交一次，且物理麦克风不启动。
6. 交替使用：连续执行键盘 USB 语音、遥控器语音、键盘 USB 语音，三次均可用且无需切换目标工具麦克风。
7. 关闭：关闭开关后，确认右 Command 不再启动物理麦克风，遥控器仍可用。
8. 插拔恢复：等待或采集中拔掉 USB 麦克风，确认显示设备不可用；重新连接并刷新后恢复等待。
9. 权限拒绝：移除麦克风权限后重新开启，确认显示需要权限且不伪报运行。
10. 异常恢复：睡眠唤醒、切换语音输出和快速启停后，确认没有崩溃、反馈啸叫或重复采集。

## 失败判定

- USB 麦克风无法通过虚拟麦克风产生文字。
- 遥控器原有语音出现新增首字延迟、尾字丢失或松键不结束。
- 关闭后仍读取物理麦克风，或日志包含语音内容、设备 UID。

## 日志

检查 `MIC PASSTHROUGH` 的 `requested`、`completed`、`failed` 与 `stopped` 结果；设备仅记录公开显示名称和 CoreAudio 数字 ID，不记录 UID 或音频内容。

## 验证边界

自动化与构建只证明配置兼容和代码路径。USB 麦克风、虚拟麦克风、真实遥控器及微信输入法文字上屏必须分别完成真机验收。
