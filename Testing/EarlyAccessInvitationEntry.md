# 邀请功能隐藏入口测试手册

## 适用范围

- 分支：`codex/next-preview-early-access`
- 功能：在“关于”页连续点击当前版本号 5 次，显示私有组件提供的邀请码入口。
- 构建必须注入兼容版本的 `SayAllAI` 私有 Swift Package；不含私有组件的公开 fallback 不响应五击手势，也不展示提示或邀请页面。

## 测试前准备

1. 使用未加入 Early Access 的干净测试账号或测试 Keychain。
2. 准备一个有效邀请码和一个无效邀请码。
3. 准备可观察资格请求的代理日志，但不得记录邀请码、匿名设备 ID、凭证或用户文字。
4. 确认 AI 整理本地开关初始为关闭。

## 用例 A：默认隐藏与五击入口

1. 启动 App，打开“关于”页。
2. 确认页面默认没有邀请码输入区域。
3. 点击当前版本号 1～2 次。
4. 点击第 3 次，确认提示还需 2 次；点击第 4 次，确认提示还需 1 次。
5. 点击第 5 次。

预期：第 5 次后页面原地显示邀请入口；前四次不显示入口。五次点击均不创建匿名设备 ID，也不触发资格网络请求。提前显示、点击即联网或要求通过命令行重启均判定失败。

## 用例 B：人工验证邀请码

1. 在已显示的入口中输入无效邀请码并手动点击验证。
2. 确认错误状态可见，稳定功能仍可使用。
3. 输入有效邀请码并手动点击验证。

预期：只有手动点击验证后才发起资格请求。有效授权后显示私有功能页面，但 AI 整理本地开关仍保持关闭。日志出现邀请码、资格凭证、语音或文字内容均判定失败。

## 用例 C：稳定功能回归

分别在入口缺失、入口已显示但未验证、授权有效、授权撤销后执行：

1. RC003 `STREAM_START → AUDIO → STREAM_STOP` 普通首次语音路径，不发送前置主动 `MIC_OPEN`。
2. 普通遥控器按键、自定义映射、Nearby iPhone 和 Web Remote 基线。
3. 在 `800 × 650` 窗口依次打开所有设置页，检查页头、主要控件和滚动无裁切，窗口几何不变化。

预期：Feature Flag 状态不改变稳定语音、按键、连接和设置导航行为。任何稳定功能退化均判定失败。

## 日志收集

通过 App“文件 → 打开日志目录”收集必要时间段日志。提交前人工检查并移除邀请码、Token、设备标识、用户语音文字及其他私密内容。

## 验证边界

- 自动化覆盖五击计数、私有组件展示接口以及点击不创建身份的边界。
- Swift 测试和 Release 编译不能替代真实 RC003、第三方语音工具、生产资格服务、真实邀请码生命周期及 `800 × 650` 界面验收。
- 本次不生成测试包；后续统一预览版打包时再执行签名、公证、安装包和公开下载字节验证。
