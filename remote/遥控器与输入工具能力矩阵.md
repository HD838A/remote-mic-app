# 遥控器 × Mac 端输入工具：语音收音能力矩阵

本文说明各款遥控器与各款 Mac 端输入工具在「怎么开始收音、怎么结束收音」上的能力差异，
以及**哪些搭配必须用哪种模式**。选购与配置时按本文对照即可。

记录时间：2026-09-20。表中标注「未测试」或「待确认」的项目在实测确认前不作为已知能力使用。

## 一、两种收音方式

| 收音方式 | 怎么操作 |
| --- | --- |
| **长按收音** | 按住语音键说话，松手结束 |
| **按一次收音** | 按一下开始，之后不用再按就能一直收音；结束收音需要再按一次 |

## 二、遥控器能力

| 遥控器 | 长按收音 | 按一次收音 | 触摸面 |
| --- | --- | --- | --- |
| 小米遥控器（RC001 / RC003） | ✅ | ❌ | ❌ |
| Chromecase 语音遥控器 | ✅ | ✅ | ❌ |
| Apple Siri Remote（A2854 / A2540） | ✅ | 未测试 | ✅ |

- **按一次收音**目前只有 Chromecase 支持；小米遥控器只能按住收音，Siri Remote 的按一次尚未测试。
- **触摸面**指手指在遥控器表面滑动/移动光标的交互，只有 Siri Remote 具备。

## 三、Mac 端输入工具能力

| 输入工具 | 长按收音 | 长按默认快捷键 | 按一次收音 | 按一次默认快捷键 |
| --- | --- | --- | --- | --- |
| Typeless | ❌ | 不支持 | ✅ | Fn |
| 豆包输入法 | ✅ | Fn | ✅ | 右 Command |
| 微信输入法 | ✅ | Fn | ✅ | 右 Command |
| Vokie | ✅ | 待确认 | ✅ | Fn |
| 腾讯 ChatterFly | ✅ | 待确认 | ✅ | Fn |

以上快捷键由用户于 2026-09-20 补充。表中的「默认快捷键」只表示输入工具默认使用的键，
不代表无线麦已自动完成第三方工具配置；最终仍需让无线麦发送的快捷键、工具的收音模式与
遥控器能力保持一致。

豆包输入法在设置里就是两个开关，含义与上表对应：

- **长按模式**：按住说话、松手结束；
- **免按模式**：按一次即可开始说话，**再按任意键结束**。

## 四、搭配规则

1. **遥控器只能按住收音时**，要配「长按收音」的工具；如果所配工具只认「按一次」（如 Typeless），
   就需要在无线麦的设置里开启 **「语音键模拟 Fn 点按」**，由它把「按住」模拟成一次点按。
   选择 Typeless 时该开关会自动开启。
2. **遥控器支持按一次收音时**（Chromecase），键盘页的「语音键模式」决定成套手感：
   选「按一次说话」，工具就要选「按一次收音」的那种模式（如豆包免按模式）；选「按住说话」，
   工具就选「长按收音」的模式（如豆包长按模式）。
3. **触摸面类设置**（滑动、光标）只有具备触摸面的遥控器才有。

### 推荐搭配

| 遥控器 | 遥控器语音模式 | 输入工具应选 | 「语音键模拟 Fn 点按」 |
| --- | --- | --- | --- |
| 小米 RC001 / RC003 | 只能按住 | 豆包长按模式 / 微信输入法 / Vokie / 腾讯 ChatterFly | 不需要 |
| 小米 RC001 / RC003 | 只能按住 | Typeless | **必须开启** |
| 小米 RC001 / RC003 | 只能按住 | 豆包免按模式 | 需要开启 |
| Chromecase | 按一次说话 | 豆包免按模式 等「按一次收音」的工具 | 不需要 |
| Chromecase | 按住说话 | 豆包长按模式 等「长按收音」的工具 | 不需要 |
| Apple Siri Remote | 只能按住 | 豆包长按模式 / 微信输入法 / Vokie / 腾讯 ChatterFly | 不需要 |
| Apple Siri Remote | 只能按住 | Typeless | **必须开启** |

**一句话记法**：遥控器怎么收音，工具就配对应模式；两边不是同一类时，才需要「语音键模拟 Fn 点按」充当转接。

## 五、搭配错了会看到什么

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 按一下结束，收音没有真的结束（如豆包的语音面板/电平图不消失），要再按一下才结束 | 工具是「按一次」型（如豆包免按模式），却被按「按住—松手」的方式驱动——它只在按键**按下**时切换状态，松手不起作用 | 让遥控器与工具改为同类：或按第四节开启「语音键模拟 Fn 点按」，或把工具改成「长按」型模式 |
| 按下后话还没说几句就结束了 | 反过来：工具是「长按」型，却被按一次点按的方式驱动——按下的同时立刻松开，收音随即结束 | 把工具改成「按一次」型模式，或关闭「语音键模拟 Fn 点按」 |
| 语音工具没有反应，但录音软件能收到声音 | 工具自己的麦克风没选对（应在工具设置里选无线麦提供的虚拟麦克风） | 在该工具的设置中把麦克风改为无线麦的虚拟设备 |
