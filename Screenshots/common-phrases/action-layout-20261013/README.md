# 常用语入口布局证据

生产 `SettingsView`，版本 2.0.0。逻辑窗口尺寸与 PNG 像素尺寸不同；Retina 截图为 2 倍像素。每张原图的格式、尺寸、字节数和 SHA-256 见 [manifest.json](manifest.json)。

- [修复前公开构建](before-public-zh-hans-light.png)：三个入口位于单个网格单元格，只剩图标。
- [修复后实际窗口](interactive-zh-hans-light.jpg)：中文浅色、1020 × 772，点击“常用语”筛选后名称完整。逐一切换按键、连接、回眸、设置、我的，再返回按键；编辑与筛选上下文保留。
- `zh-Hans/` 和 `en/`：公开构建，中英文、浅深色、1020 × 772 及 800 × 650 离屏截图。最小生产窗口的三个名称完整。800 × 650 只为窄宽压力检查，首屏未显示下方常用语，不声称该尺寸的常用语区域通过。
- `integrated-nonmember/zh-Hans/`：私有辅助组件、非会员、中文浅深色、1020 × 772。三个名称和开通入口完整。辅助组件提交为 `ecfc6318f818db8c44381dc6af9cce8e8a1eb155`；没有修改发布 pin。

使用已有生产截图入口及隔离测试设置。图片保留原始字节，没有裁剪、缩放或重绘。截图不证明会员登录、绑定、插入、音频或升级通过。
