SayAll · 提示气泡 · 已定稿 · 未开发

气泡，而不是提示条

上一版是“系统提示条”的语言：中性底色、彩色徽章、紧凑排版。它正确，但确实像设置面板里的工具。 这一版换成产品引导的语言：饱和语义色、18pt 大圆角、指向锚点的尾巴、去掉图标、标题 + 说明的双行节奏。颜色按你要的三档：绿 / 琥珀 / 品牌红，深色外观各提亮一档。 同时补上你要的第二件事：提示可以钉在某个元素上，而不是只能浮在页面正中。

已定：L1 绿 / L2 琥珀 / L3 品牌红 版式：标题 + 说明 + 一个动作 深色各提亮一档 已定稿 · 可开发

行为规则

场景关闭方式说明
引导气泡（锚定）点 X / Esc / 点气泡外只显示一次，按 seenKey 记忆；手动关掉也算看过
状态气泡（权限）条件恢复后自动消失不给 X；它描述的是仍然存在的状态，关掉会误导
字段错误点 X / Esc / 动作修好后自动消失；不自动超时，避免还没读完就没了
全局结果（无锚点）2.4s 自动 / 点气泡外按 position 落在顶部 / 中间 / 底部，默认居中；不拦点击
多个锚定同时命中—只显示优先级最高的一条；其余排队
位置规则共三种落点。有具体元素 → 贴着那个元素；没有锚点时默认页面正中； 业务也可以显式指定顶部或底部——比如保存完成后贴在底部，不打扰正在看的内容。 三个落点都在同一套视觉里，只有 y 不同，锚定优先于落点。
06

锚定怎么实现

业务侧只多传一个锚点标识，不写坐标、不写尾巴方向。方向由中心按可用空间算。

① 注册锚点：在目标元素上加一个修饰符

// 任何 View 都能被锚定
VoiceKeyCard()
    .noticeAnchor(.voiceKey)

// 用枚举而不是字符串，避免拼错
enum NoticeAnchorID: Hashable {
    case voiceKey, inputMonitoring, phraseField
}

② 业务侧：只声明锚在哪

NoticeCenter.shared.show(.init(
    kind: .tip,
    title: "按住它说话",
    text: "按住遥控器语音键，松开后文字会插到光标处。",
    action: .dismiss(title: "知道了"),
    anchor: .voiceKey,          // nil = 居中
    seenKey: "tip.voiceKey.v1"  // 只显示一次
))

// 状态类：不给 X，条件恢复后自己消失
NoticeCenter.shared.show(.init(
    kind: .status,
    title: "这一项还没开",
    text: "勾选后按键映射才会生效。",
    action: .openSystemSettings(.inputMonitoring),
    anchor: .inputMonitoring,
    dismissible: false
))

③ 中心侧：方向由几何决定，不靠调用方猜

func placement(for anchor: CGRect, in bounds: CGRect, size: CGSize) -> Edge {
    let gap: CGFloat = 18   // 8 间距 + 10 尾巴
    if bounds.maxX - anchor.maxX >= size.width + gap { return .trailing }
    if anchor.minX - bounds.minX >= size.width + gap { return .leading }
    if bounds.maxY - anchor.maxY >= size.height + gap { return .bottom }
    return .top
}

// 尾巴位置 = 锚点中心，收进 [22, 宽-22]
let tailX = min(max(anchor.midX - frame.minX, 22), frame.width - 22)
取值方式。用 anchorPreference 把子视图的 frame 提到父层，避免全局坐标系手算； 滚动容器里再叠一层 onScrollGeometryChange，锚点离开可视区就关闭气泡。

和上一版的差别

v3 · 系统提示条

  • 12pt 圆角矩形，中性黑 / 白底
  • 16pt 彩色圆徽章承载语义
  • 13pt 单行，11 × 13 内边距

  • 14.5 标题 + 13.5 说明，16 × 18 内边距

L3 · 必须处理

错误

输入目标已改变，重新打开常用语。

品牌红 #A5342C + 白色感叹标记 + 不自动消失。三处信号叠加，颜色只是一层。

系统强调色留给控件层。 气泡底色按上表固定；NSColor.controlAccentColor 只用在动作按钮的焦点环和键盘选中态。 那里是交互反馈，正好是 accent 的本职；气泡承载的是信息，不能让它随主题色变成读不出来的黄块。
深色模式的三条规则。 一、三档各提亮一档（#1A7A52 / #9E5611 / #C04239），保证与背景 ≥ 3:1； 二、深色下改用纯色，不用渐变，避免末端变暗吃掉提亮； 三、额外加 1px 白色 14% 描边，补足边界。
09

定稿记录

三项待定已确认，设计侧不再有悬而未决的选择。下面是记录，以及按依赖排的实现顺序。

错误标记用感叹号

标题前 !，12pt 细线白色。不用 ×，避免与右上角关闭按钮在同一区域形成两个叉。

「显示一次」按功能 + 版本

键名形如 tip.voiceKey.v1。用户手动关掉算看过；文案大改时升版本号，才有机会重新出现。

深色绿色保持 #1A7A52

深底分离 3.20，白字 5.32。不再提亮——再亮一档白字会掉到 4.4，贴着及格线。

位置：默认居中，可指定三档

NoticePosition.top / .center / .bottom；有锚点时锚点优先。

颜色三档与深色规则

L1 绿 / L2 琥珀 / L3 品牌红；深色各提亮一档、改纯色、加 1px 白 14% 描边。

按依赖排的实现顺序
