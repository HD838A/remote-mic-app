# 统一按键设置 UI 验证记录

范围：`codex/unified-button-configuration` macOS 源码候选。
使用生产 SettingsView 和生产最小尺寸 1020 × 772，隔离 UserDefaults 与人工脱敏动作数据。
本地 ad-hoc Release clone 只用于 UI 观察，不是用户安装包；没有启动真实硬件。

本轮前段原生窗口检查已确认：方案“编辑键位”跳到按键页、继承基础行为、进入动作库后返回原按键、
在按键页明确选择宏，以及高级脚本默认关闭。静态截图曾发现英文默认方案名称，已修正中文展示。
旧截图已移至 macOS Trash，避免被当作最终验收证据。

末轮原生 UI 工具报告 Mac 锁屏且无法自动解锁，已请求用户解锁。
因此最终浅色/深色原始截图、全部侧边栏和引用跳转的末轮核验尚未完成，
本目录不提供未经格式、尺寸、SHA-256 和逐张查看验证的最终图。
解锁后应按[测试手册](../../Testing/UnifiedButtonConfiguration.md)完成全部入口、窗口几何、滚动、
继承/宏绑定、脚本关闭状态的浅色和深色检查并在此记录摘要。

真实遥控器、系统首次授权、第三方 App 响应和语音首尾完整性未验收。
