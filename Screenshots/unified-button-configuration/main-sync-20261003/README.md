- 中文浅色：新建、名称填写、首动作选择、上一步草稿保持、编排、确认保存；按键页主页键单击选择保存的组合动作，常用语页返回后保留编辑对象及绑定；六个导航入口逐一点击。
- 中文深色：按键、动作库、键位方案、回眸、连接与设置六入口逐一点击，窗口几何保持。
- 英文深色：按键副标题、动作库、基本信息、步骤编排、确认保存、保存后返回与键位方案摘要。步骤按钮的长英文按现有规则截断，AX 完整名称仍可识别。

这些结果仅证明页面与草稿/保存/选择路径；未执行真实用户动作、权限授权、遥控器、语音或第三方输入。
本轮没有重跑 Siri Remote/Chromecast 方案实机矩阵，旧截图仅为历史证据。
中文深色与英文深色分别重新启动初始化语言；隐藏入口运行时改语言后，私有入口仍保留初始语言，
因此不能把本轮视为运行时语言切换验收，生产启动路径是否同样受影响未确认。
名称必填标识、首步职责与导入导出布局调整、“发送常用语”宏步骤均未在本轮开发。
