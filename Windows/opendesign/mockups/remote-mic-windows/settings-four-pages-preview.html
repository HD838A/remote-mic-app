Windows 所需能力

Windows 没有与 macOS“输入监控/辅助功能”完全对应的统一授权页，因此按真实使用边界分别说明。

1

蓝牙与设备连接

RC003 必须先在 Windows 蓝牙设置中完成配对；软件据此读取蓝牙语音服务和设备状态。

已检测
2

语音软件的麦克风访问

Typeless 或千问需要被 Windows 允许使用麦克风，并在软件内选择 CABLE Output。Remote Mic 本身不采集电脑麦克风。

由目标软件决定
3

管理员权限

日常桥接不依赖管理员权限；仅安装 VB-CABLE、首次启用特定兼容适配或排障时可能需要。

日常无需
