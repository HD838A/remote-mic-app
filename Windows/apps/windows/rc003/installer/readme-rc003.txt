Remote Mic · RC003（Windows 源码/构建候选）
====================================================

状态：本安装包是一个尚未经过 Windows 真机验收的源码/构建候选，不代表
Xiaomi 蓝牙遥控器 2 Pro / RC003 已在 Windows 上完整实现或验收通过。见文末
"真机验证事项（待核验）"。

系统要求
--------
- Windows 10 1809（内部版本 17763）或以上，64 位；
- 未签名安装包：首次运行时 Windows SmartScreen 可能提示"Windows 已保护你
  的电脑"。这是预期行为，不是错误——本项目目前没有购买代码签名证书。

  在点击"仍要运行"之前，建议先核对安装包（或便携版 ZIP）的 SHA-256 校验
  值是否与同一次构建产出的 SHA256SUMS.txt 一致。以 PowerShell 为例（把
  <文件名> 换成你实际下载的文件名，例如
  RemoteMicRC003Setup-0.1.0-candidate-unsigned.exe）：

      Get-FileHash -Algorithm SHA256 .\<文件名>

  把命令输出的 Hash 值（不区分大小写）与 SHA256SUMS.txt 中同一个文件名
  那一行的哈希值逐字比较：一致才继续安装；只要有一个字符不一致，就不要
  运行这个文件——重新下载，或联系发布者核实来源。哈希核对一致后，再点击
  SmartScreen 提示中的"更多信息"，然后点击"仍要运行"。

安装
----
1. 运行 RemoteMicRC003Setup-<版本号>-unsigned.exe；
2. 安装程序只安装到当前用户目录（%LOCALAPPDATA%\RemoteMic\RC003），
   不请求管理员权限，不设置开机自动启动，不安装任何驱动；
3. 安装完成后可以勾选"打开 Remote Mic · RC003 设置"，但安装程序
   不会自动以无参数方式启动语音桥接——桥接模式需要你在 Start Menu 中显式
   点击"启动"，或者在设置窗口底部"桥接控制"区域点击"保存并启动桥接"。

更新已有版本
------------
直接运行更新版本的安装程序即可，不需要先卸载或手动删除旧版本。安装程序会
先停止正在运行的旧版设置窗口和桥接进程，再替换旧的程序文件，并沿用同一个
安装记录；Windows“已安装的应用”中只保留一个 Remote Mic · RC003 条目。
config.json、key_bindings.json、usage-statistics.json 和 logs 目录不会在更新时
删除，因此设备选择、按键设置、使用统计和诊断日志会继续保留。便携 ZIP 不具备
这套自动更新能力；需要无手工清理的后续升级时，请使用安装程序版本。

配对 RC003
----------
1. 同时长按遥控器的【主页键】+【菜单键】，直到遥控器进入配对广播状态；
2. 打开 Windows"设置 → 蓝牙和其他设备"，等待遥控器出现后完成配对；
3. 本程序按蓝牙名称自动查找已配对设备，不需要手动输入地址；如果找到 0 个
   或超过 1 个匹配设备，程序会拒绝猜测并报错退出，而不是随意连接一个。

（可选）安装 VB-CABLE 作为虚拟麦克风
------------------------------------
本程序不会自动下载、安装、启用或卸载任何虚拟音频驱动，也不会修改 Windows
默认输入/输出设备。如果你想让语音识别/听写软件把 RC003 的语音当作一个
"麦克风"来使用，需要自行从 VB-Audio 官方网站下载并安装官方 VB-CABLE：

  https://vb-audio.com/Cable/

安装完成后按下面的方向手动配置——方向不能弄反：

  - Remote Mic 的"语音输出设备"设置项  →  选择 "CABLE Input"
    （VB-CABLE 的虚拟"扬声器"一侧）；
  - 语音识别/听写软件的麦克风输入设置          →  选择 "CABLE Output"
    （VB-CABLE 的虚拟"麦克风"一侧）。

如果两边选成同一个名字，或者方向选反了，语音功能会静默失败，但普通按键
映射仍然正常工作。

一键随包安装（可选）：打开"设置 → 检查与修复"页，"可选：VB-CABLE 虚拟
音频驱动"卡片会显示这两个端点当前是否已存在；点击"安装/修复 VB-CABLE…"
会先弹出说明对话框（VB-CABLE by VB-Audio，独立 Donationware，非本项目
GPL 代码，可自愿捐赠/购买授权，仅随包提供基础版、不含付费的 A+B/C+D，
安装会改变系统状态并需要重启），确认后才会解压安装包内置的、已按固定
SHA-256 校验过的官方 VBCABLE_Driver_Pack45.zip，并以 Windows 用户账户
控制 (UAC) 提示启动官方原始的 VBCABLE_Setup_x64.exe——本程序自身全程不
以管理员身份运行，UAC 提示可以随时取消，取消不会安装任何内容。安装完成
后需要重启电脑，重启后点击"重新检测"确认端点已出现，再点击"选择检测到
的 CABLE Input 作为输出"即可完成上面第一个方向的设置。这个入口只是把
手动下载安装换成随包、离线、显式确认的流程，效果完全一致；仍然可以选择
直接从 https://vb-audio.com/Cable/ 手动下载安装。

首次使用
--------
1. 打开"设置"（Start Menu 中的"Remote Mic · RC003"或
   "Remote Mic · RC003 设置"，两者都会直接打开设置窗口）。设置窗口
   分"连接""按键""权限""检查与修复"四个页面：本节下面的步骤在"连接"页
   完成；按键映射在"按键"页完成（见下方"默认按键映射"一节），点击遥控器
   实物图上的按键或右侧映射列表中的一行都可以互相定位、高亮同一个按键；
   "权限"页只提供打开 Windows 蓝牙/麦克风/语音识别设置页面的入口，不会
   显示虚假的"已授权"状态；"检查与修复"页会分组显示普通按键、RC003 语音
   链路、Windows 听写、可选驱动这四类前提各自的检测结果（含明确的"待手动
   验证"，而不是伪造一个通过状态），并提供"重新检测"、随包安装/修复
   VB-CABLE（见上方"可选安装 VB-CABLE"一节）等操作；
2. 在"连接"页"语音输出设备"下拉框中选择要写入解码语音的 Windows 音频端点
   （按上一节的方向配置）；
3. 启动桥接有两种等价方式：
     - 在设置窗口底部"桥接控制"区域点击"保存并启动桥接"——会先执行和
       "保存并应用"完全相同的校验并保存设置，只有校验通过才会启动桥接；
     - 或者先点"保存并应用"，关闭设置窗口，再从 Start Menu 选择"启动
       Remote Mic · RC003"。
   "桥接控制"区域会显示以下四种状态之一：未启动、已启动/运行中、已经在
   运行（检测到重复启动、被单实例保护拒绝）、启动异常或快速退出（会附带
   真实的退出码）。这里的"运行中"只表示桥接进程本身还存活，**不代表已经
   与 RC003 建立了连接**——实际的配对、按键和语音状态仍然只能通过下面第
   5 步和日志确认；遇到问题时可以点击同一区域的"打开日志目录"按钮直接
   定位到 %LOCALAPPDATA%\RemoteMic\RC003\logs（如果程序从未运行
   过，日志目录本身也不存在，按钮会如实提示，不会伪造一份日志）；
4. 按一下遥控器上的普通按键（例如方向键或确定键），确认按键映射生效；
5. 在测试遥控器麦克风键之前，先在“按键”页确认豆包输入法的语音快捷键。新
   安装的豆包预设为切换模式 `ralt+space`、按住模式 `ralt`，必须和豆包本身的
   快捷键一致，不要把 Windows `Win+H` 当作豆包快捷键。打开记事本（或任意
   可编辑文本框），把光标点进文本区域，手动按一次已配置的组合键，确认豆包
   语音出现并能输入文字；豆包的麦克风输入设备也必须选择 "CABLE Output"
   （如果按上一节配置了 VB-CABLE）。手动组合键通过后，再按住遥控器麦克风键
   说话，检查是否有文字被输入。

   如果要单独排查 Windows 自己的系统听写，再手动按一次键盘上的 Win+H，确认
   Windows 听写栏出现、说话后有文字被输入。这一步需要同时满足：
     - 光标确实停留在一个可编辑的文本输入框中——听写没有可输入目标时不会
       生效；
     - Windows 已启用"联机语音识别"（Windows 11：设置 → 隐私和安全性 → 语音；
       Windows 10：设置 → 隐私 → 语音），因为 Windows 听写依赖联网的语音
       识别服务，没有网络或未启用该设置时听写不会工作；
     - 系统当前的麦克风输入设备选择的是 "CABLE Output"（如果你按上一节
       安装并配置了 VB-CABLE）。
   Win+H 测试只用于确认 Windows 系统听写链路，不能替代豆包输入法快捷键验收。
   如果豆包手动组合键无法工作，请先解决豆包快捷键或输入设备配置问题，本程序
   不能让本来就不工作的输入法变得可用，只能把语音送到你已经选好的虚拟麦克风。

停止 / 重启
-----------
- 从 Start Menu 选择"停止 Remote Mic · RC003"可以随时停止桥接；
- 重新从 Start Menu 选择"启动 Remote Mic · RC003"即可再次启动。

卸载
----
从 Windows"设置 → 应用"，或 Start Menu 的"卸载 Remote Mic · RC003"
条目卸载。卸载过程会先自动停止正在运行的桥接进程，再删除安装时写入
的程序文件；不会触碰你系统上的蓝牙配对记录，也不会触碰你自行安装的
任何虚拟音频驱动。

卸载不会自动删除设置和日志：config.json、key_bindings.json 和
logs\app.log 会一直保留在 %LOCALAPPDATA%\RemoteMic\RC003 下，因为
安装脚本没有为这些运行期生成的文件配置卸载删除规则。如果这台
电脑上不会再安装任何 RC003 版本（安装器或便携版）、也不需要
保留这些设置和日志，可以在卸载完成后手动删除整个
%LOCALAPPDATA%\RemoteMic\RC003 文件夹；如果还会用到
同一台电脑上的另一个 RC003 安装，请不要删除这个共享目录。

默认按键映射
------------
  麦克风         豆包输入法语音热键（切换 `ralt+space` / 按住 `ralt`），
                 按下/松开的触发方式由设置决定——
                 固定绑定，不出现在可编辑的按键列表中
  电源           Escape
  上 / 下 / 左 / 右   对应方向键
  确定（OK）      Enter
  返回           退格（Delete）
  音量 + / −      系统音量 + / −
  主页           Win+D
  菜单           Shift+F10
  TV             Alt+Esc

除麦克风外，以上每一行都可以在设置窗口"按键"页中重新指定并保存。

物理按键与固定行为
------------------
- RC003 一共有 13 个物理按键：12 个普通按键（电源、上/下/左/右、确定、
  返回、音量+/-、主页、菜单、TV）再加上 1 个固定的麦克风按键；
- 麦克风键没有普通按键映射，它始终直接驱动语音功能，即使设置文件中出现
  旧的自定义值也会被忽略；
- 遥控器没有独立的物理静音键："系统静音"只是可以手动分配给其他按键的一
  个可选动作，不是任何按键的默认映射；
- "返回"键默认映射为退格动作。如果某台 Windows 设备交付了未识别的 Raw Input
  签名，需要使用源码包中的被动按键采集/回放流程学习物理签名；不要直接猜测
  扫描码，也不要把 HID 路径或蓝牙地址写入设置。

不包含内容
----------
- 不包含任何输入法或语音识别功能；
- 不包含 T1、V60/PV60 或其他设备的桥接程序；
- 不包含 VB-CABLE 或任何其他音频驱动（见上方"可选安装"一节）；
- 不会以管理员身份运行，安装时不会请求提权；
- 不会开机自动启动。
