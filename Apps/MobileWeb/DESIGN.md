# Mobile Web 设计规范

Mobile Web 与 iOS 遥控器共享信息架构、按钮语义和基础配色，但针对移动浏览器的界面边界独立适配。

## 视觉

- 页面使用 `#d9dde0` 纯色背景，并将 `theme-color` 保持为同色，使 Safari 顶部状态栏和底部地址栏与页面自然融合。
- 控制器首屏使用稳定的 `svh` 视口单位，避免 Safari 地址栏收放时反复改变布局高度并造成滚动抖动。
- 不使用金属拉丝背景。方向盘与六个圆角矩形按键使用石墨色，顶部按键和“确定”使用浅色，麦克风使用钛灰色。
- 中间六键顺序固定为“返回 / 菜单 / 音量+”和“主页 / TV / 音量-”。图标语义与 iOS 保持一致。
- 页头只展示连接状态和 Mac 名称，不重复展示 App Logo 与产品名；页面下方直接展示内联的小尺寸 App Logo、Mac App 下载入口、单一官网入口、iOS TestFlight 公测及复制链接操作、实体遥控器推荐和三步连接教程，不增加第二个页面。

## 交互

- 页面禁止文字选择、图片拖动和长按系统菜单，所有按钮必须保留清晰的按压视觉反馈。
- 按键震动使用 Web Vibration API 渐进增强。Android Chrome 等支持的平台可震动；iPhone Safari 不支持该 API，因此必须依靠视觉反馈，不能把震动作为操作成功的唯一提示。
- 扫码或恢复历史会话后，页面不得自动建立功能性网络连接；只有用户手动点击“连接 Mac”才可创建 WebSocket。
- 麦克风仅在用户明确按住按钮后启用，松手、取消触摸、切后台或断线时立即停止。
- 麦克风和确定按钮允许原生纵向滑动；浏览器识别为滚动后会取消当前按压并立即停止麦克风。

## 会话与隐私

- Mac 批准后的会话凭证最多在当前浏览器保存两小时，用于短期免重复扫码；这不是永久信任设备。
- Mac 主动结束、会话过期或凭证无效时立即清除本地凭证，并提示重新扫码。
- Relay 不记录按键历史和语音内容；语音只在按住麦克风期间传输。
