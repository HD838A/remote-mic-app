# 版本历史

## 1.9.19（预发布）

- 改进 Onboarding 权限页返回、语音测试输入框和诊断反馈。
- 未安装已知语音工具时保留“其他语音工具”入口，并提供豆包官方安装入口。
- 改进“回眸”录音播放失败提示，帮助区分记录缺失、文件修改、读取失败和播放器启动失败。
- 修复遥控器唤醒后语音键映射未恢复的问题。
- 卸载 SayAll 时将相关 App、历史路径和驱动移入废纸篓，安装替换失败时支持回滚。
- 移除“回眸”仅录音记录上的 Finder 入口，保留播放、导出和移入废纸篓。

## 1.9.18（预发布）

- 修复大量回眸记录浏览时的重复、空白和滚动卡顿。
- 全部应用默认显示最近 7 天记录，选择具体应用可查看完整历史。

## 1.9.17（预发布）

- 改进首次设置中的语音工具配置，支持微信输入法、Typeless 和豆包的安装状态识别与引导。
- 首次设置新增 Fn/地球键、左 Command、右 Command 语音触发模式选择；Typeless 保持 Fn 点按行为。
- 选择语音输入法后自动切换对应输入源，并减少升级用户重复进入完整首次设置。
- 修复预览版 Build 高于候选包时的语义版本更新误判。
- 移除会打开文本下载链接的版本历史按钮，关于页直接显示最新版本的本地化更新内容。

## 1.9.16（预发布）

- 新增左 Command 和右 Command 语音触发模式，默认 Fn/地球键行为保持不变。
- 语音键按下后立即开始、释放后立即结束；输入框聚焦改为普通遥控器按键的独立动作。
- 改进 Electron、Web、搜索框和 Terminal 等前台输入框的聚焦可靠性。
- 修复 RC003 TV 键在不同键盘布局下向前台文本框泄漏字符的问题。
- 改善 Mac 从睡眠唤醒后的蓝牙恢复和音频故障诊断。
- 支持使用遥控器控制 macOS Command-Tab 应用切换器。
- 为不可连发动作增加可选的快速连续按功能，默认保持关闭。
- 修复组合动作编辑页面误消费普通遥控器按键的问题。
- 新增本地保存原始录音，并改进没有可编辑输入框时的回眸记录。
- 新增向上滚动和向下滚动遥控器动作。
- 调整“关于”页语言选择器的布局对齐。

## 1.9.10（预发布）

- 组合动作现在默认开放，无需邀请码即可查看、创建、绑定和使用。

## 1.9.9（预发布）

- 在“关于 → 应用偏好”中新增可选的“登录时自动启动”，需要 macOS 批准时可直接打开“登录项”设置。
- 新增页面内键盘快捷键选择，可选择常用键、方向与导航键、F1–F20、数字键盘以及独立的左右修饰键，同时保留实体键盘录入方式。
- 改进首次设置和权限恢复：窗口会在按内容尺寸调整后居中，Input Monitoring 或 Accessibility 权限变化后已启用的自定义按键映射会自动恢复。
- 语音输入现在只选择已启用的首选输入法，避免重复触发确认提示；除非你在会话中手动改选，否则会话结束后恢复原输入法。
- 改进失效缓存遥控器的蓝牙恢复，采用有界退避并处理蓝牙电源恢复，同时保留已保存的配置和映射。
- 减少语音流期间无效的界面刷新，同时保持音频处理和诊断行为不变。
- 防止同时启动多个无线麦实例；再次打开 App 时会激活已有实例，不会重复初始化蓝牙、音频或 HID。
- 在不同 App 之间切换时保持设置窗口可见，并在窗口真正关闭前保留 Dock 图标。
- 修复 RC003 monitored 模式下将电视键绑定为自定义动作时向前台文本框泄漏“§”字符的问题。

## 1.9.8（预发布）
