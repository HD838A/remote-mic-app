# 术语表

这里解释安装、设备选择、系统设置、日志或技术资料中可能出现的名称。日常使用时通常不需要理解这些技术细节。

## 遥控器与按键

### 小米蓝牙遥控器 2 Pro / RC003

**通俗解释：** 本应用支持的小米蓝牙语音遥控器。RC003 是技术资料和部分设备信息中使用的型号代号。

**何时会遇到：** 蓝牙设备列表、产品包装、日志或故障排查资料中。

### Fn

**通俗解释：** Mac 键盘上的功能修饰键。本应用可让遥控器的麦克风键在需要时提供 Fn 功能。

**何时会遇到：** 按键说明、快捷键录入或键盘相关设置中。

### HID

**通俗解释：** 系统识别键盘、鼠标和遥控器按键的一套标准。对用户而言，可把它理解为“按键设备”或“按键数据”。

**何时会遇到：** Console 日志、技术资料或输入监控权限排障中。

## 麦克风与音频

### 兼容麦克风

**通俗解释：** 为需要特定音频设备类型的输入法或应用准备的虚拟麦克风。

**何时会遇到：** 选择语音输出设备或安装输入法兼容驱动时。

### MiRemoteV 2ch

**通俗解释：** 兼容麦克风在 macOS 音频设备列表中的真实设备名。

**何时会遇到：** “音频 MIDI 设置”、系统声音设置或应用的音频设备选择器中。

### BlackHole

**通俗解释：** 一款开源虚拟音频驱动，可在 Mac 应用之间传递音频。

**何时会遇到：** 安装虚拟音频设备、选择语音输出或排查音频路由时。

### 虚拟麦克风与音频回环

**通俗解释：** 虚拟麦克风把一个应用产生的声音提供给另一个应用作为麦克风输入；音频回环是这种在软件之间传递声音的方式。

**何时会遇到：** 配置输入法语音输入、录音、会议或直播软件时。

### Core Audio

**通俗解释：** macOS 负责录音、播放和音频设备管理的系统音频框架。

**何时会遇到：** Console 日志、音频错误信息或技术排障资料中。

## 蓝牙与设备标识

### ATVV

**通俗解释：** 部分蓝牙语音遥控器用来传输语音的技术协议。普通页面称它为“遥控器语音服务”。

**何时会遇到：** Console 日志、蓝牙协议资料或高级故障排查中。

### UUID / 设备唯一标识

**通俗解释：** 系统用来区分设备或蓝牙服务的一串唯一编号，不是设备名称。

**何时会遇到：** Console 日志、系统报告或蓝牙技术资料中。

## macOS 权限

### 输入监控

**通俗解释：** 允许应用读取遥控器按键。应用不会借此记录你输入的文字。

**何时会遇到：** “系统设置 → 隐私与安全性 → 输入监控”中。

### 辅助功能权限

**通俗解释：** 允许应用把遥控器按键转换成快捷操作并发送给当前应用。

**何时会遇到：** “系统设置 → 隐私与安全性 → 辅助功能”中。

## 安装文件

### DMG

**通俗解释：** Mac 常见的磁盘映像安装包。打开后通常把应用拖到“应用程序”文件夹。

**何时会遇到：** 下载和安装应用时。

### PKG

**通俗解释：** 带有安装向导的 Mac 安装包，常用于安装驱动或需要写入系统位置的组件。

**何时会遇到：** 安装兼容麦克风或其他音频驱动时。
