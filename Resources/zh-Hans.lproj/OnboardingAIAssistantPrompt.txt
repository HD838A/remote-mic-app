自动配置：
1. 不要操作屏幕或点击窗口。只在系统和当前用户的 Applications 目录中定位已安装的无线麦 SayAll，然后运行配置命令。未找到时，向我确认安装位置；不要运行测试副本或下载归档：
   APP_PATH=""
   for APP_CANDIDATE in "/Applications/SayAll.app" "/Applications/无线麦SayAll.app" "$HOME/Applications/SayAll.app" "$HOME/Applications/无线麦SayAll.app"; do
     if test -x "$APP_CANDIDATE/Contents/MacOS/RemoteMic"; then
       APP_PATH="$APP_CANDIDATE"
       break
     fi
   done
   if test -z "$APP_PATH"; then
     printf '%s\n' '{"status":"not_found","reason":"installed_app","remaining":["app_installation"]}'
     exit 1
   fi
   "$APP_PATH/Contents/MacOS/RemoteMic" --agent-configure --auto --json
2. 解析命令输出的 JSON。只使用 --agent-configure、--auto、--json、--verify、--control-source、--voice-tool。不要用 --help、--version、--scope 或其它参数探测；未知参数会被忽略，不能用来判断命令能力。
3. 按 JSON 结果处理：
   - configured：staged 配置已准备。不要声称真实语音已经成功；让我重新打开无线麦 SayAll，并停在真实语音测试步骤完成说话和文字上屏。
   - permission_required：告诉我缺少哪些权限，让我在系统设置中授权后重跑。
   - needs_choice：把 candidates 告诉我，只问一次；我选择后用 --control-source 或 --voice-tool 重跑。
   - not_found 且 reason=connected_remote，或 remaining 包含 remote：停止自动配置。说明系统蓝牙已连接不等于无线麦 SayAll 已连接；让我打开应用，确认遥控器在应用内已连接，再重跑。不要检查蓝牙地址、HCI、系统权限数据库或系统服务，也不要让我断开系统蓝牙。
   - not_found 且 reason=audio_device：告诉我缺少可用的无线麦 SayAll 音频输出设备；按应用提示安装或刷新音频设备后重跑。
   - not_found 且 reason=installed_app：问我安装位置；不要下载或运行测试副本。
   - failed：说明 reason 后停止，不要猜配置成功。
4. 配置成功后，让无线麦 SayAll 停在真实语音测试步骤；不要跳过语音、音频、按键和文字上屏验证，也不要把写入配置当成验证成功。
5. 配置后可用同一应用路径运行 --agent-configure --verify --json 复查 staged 配置；它仍然不能证明真实语音成功。
