# Remote Mic First-Install Guide

[简体中文](首次安装说明.md)

## Requirements

- Apple Silicon Mac
- macOS 14 or later
- Xiaomi Bluetooth Remote 2 Pro

Installation does not require Xcode or the Command Line Tools.

Starting with v1.3.0, the app, both PKGs in the DMG, and the DMG itself are Developer ID signed and notarized by Apple for official releases. Download only from this project's GitHub Releases and verify the `.sha256` file supplied with the same release.

## Install

After opening Remote-Mic-<version>.dmg, double-click Install Remote Mic.pkg. It will:

1. install Remote Mic.app in Applications;
2. install the Doubao-compatible MiRemoteV 2ch microphone;
3. restart the system audio service;
4. launch Remote Mic for the current desktop user.

When upgrading, the installer first confirms that an existing app belongs to Remote Mic by bundle identifier, quits and removes the old app, and then installs the new version. Manual deletion is no longer required. If the target path belongs to another app, installation stops without overwriting it.

If you do not need the Doubao-compatible microphone, drag Remote Mic.app to Applications instead. This path requires an existing loopback device such as BlackHole 2ch.

If macOS still blocks installation, delete the local download, download it again from GitHub Releases, and verify the `.sha256` file; do not use an untrusted copy.

If an older /Applications/无线麦.app exists, the installer migrates it only after confirming that its bundle identifier belongs to Remote Mic. An unrelated app at that path is never removed.

## Pair the remote

1. Turn on Bluetooth in Mac System Settings.
2. For the first connection, hold TV for about 2 seconds until the white light at the bottom of the remote flashes.
3. Hold Home and Menu together to enter Bluetooth pairing mode.
4. On the Mac, pair 小米蓝牙语音遥控器, MI RC, or Xiaomi Bluetooth Remote 2 Pro.

## Permissions

Allow Bluetooth access on first launch.

To customize ordinary buttons, grant Input Monitoring and Accessibility in that order from the **Permissions** page. Quit and reopen Remote Mic after granting either macOS permission.

## Configure voice input

1. Left-click the Remote Mic menu bar icon.
2. In **Connection & Voice**, choose **Refresh Audio Devices**.
3. Select MiRemoteV 2ch or another available loopback device.
4. Choose the same device as the microphone in the target voice-input app.
5. Click the target input field, hold the remote voice button to speak, then release it to finish.

You can first choose the device in QuickTime Player's **New Audio Recording** window and confirm that input level changes while holding the voice button.

## Uninstall

1. Quit Remote Mic.
2. Double-click Uninstall Remote Mic.pkg in the DMG to remove MiRemoteV 2ch.
3. Delete Remote Mic.app from Applications.

The uninstall PKG does not modify or delete BlackHole.
