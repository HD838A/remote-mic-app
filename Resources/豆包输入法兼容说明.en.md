# Doubao Input Method Compatible Virtual Microphone

[简体中文](豆包输入法兼容说明.md)

## Why it is needed

Doubao Input Method may not list ordinary virtual audio devices. MiRemoteV 2ch is Remote Mic's standalone stereo loopback device, allowing Doubao to recognize voice from the remote.

It coexists with BlackHole 2ch and does not modify, delete, or overwrite BlackHole.

## Install

You do not need Xcode, Git, or Terminal.

1. Double-click Install Remote Mic.pkg at the root of the DMG.
2. Enter an administrator password when macOS Installer asks.
3. The installer adds Remote Mic and MiRemoteV 2ch, restarts Core Audio, and launches Remote Mic.
4. Left-click the menu bar icon and choose **Refresh Audio Devices** in **Connection & Voice**.
5. Choose **Select MiRemoteV 2ch**.
6. Quit Doubao completely, reopen it, and test again.

## Verify

In QuickTime Player, choose **File → New Audio Recording**, set the input to MiRemoteV 2ch, and hold the remote voice button while speaking. The input level should move.

If QuickTime shows input but Doubao does not react, click an editable input field in Doubao so the insertion cursor is visible, then hold the voice button again.

## Uninstall

Double-click Uninstall Remote Mic.pkg at the root of the DMG. It removes only:

    /Library/Audio/Plug-Ins/HAL/MiRemoteV2ch.driver

Uninstalling restarts Core Audio. It does not delete Remote Mic or modify BlackHole.
