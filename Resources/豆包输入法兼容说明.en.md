# Doubao Input Method Compatible Virtual Microphone

[简体中文](豆包输入法兼容说明.md)

## Why it is needed

Doubao Input Method may not list ordinary virtual audio devices. The SayAll microphone is a standalone stereo loopback device provided by the app, allowing Doubao to recognize voice from the remote. Existing installations keep MiRemoteV 2ch, its stable identity, and saved selections.

It coexists with BlackHole 2ch and does not modify, delete, or overwrite BlackHole.

## Install

You do not need Xcode, Git, or Terminal.

1. Double-click `Install SayAll.pkg` at the root of the DMG.
2. Enter an administrator password when macOS Installer asks.
3. The installer adds SayAll and the compatible microphone, restarts Core Audio, and launches SayAll.
4. Left-click the menu bar icon and choose **Refresh Devices** in **Connection & Voice**.
5. In **Audio Output**, choose the compatible microphone shown by the system: **SayAll** for a new installation, or **MiRemoteV 2ch** for an existing installation.
6. Quit Doubao completely, reopen it, and test again.

## Verify

In QuickTime Player, choose **File → New Audio Recording**, set the input to SayAll (MiRemoteV 2ch on an existing installation), and hold the remote voice button while speaking. The input level should move.

If QuickTime shows input but Doubao does not react, click an editable input field in Doubao so the insertion cursor is visible, then hold the voice button again.

## Uninstall

Download and double-click `SayAll-<version>-Uninstaller.pkg` from the same Release. It verifies and moves SayAll, recognized legacy app bundles, and the compatible microphone to the macOS Trash, then restarts Core Audio. It does not modify BlackHole or SayAll's local settings.
