小米遥控器桥接 0.2.3 测试版
============================

重要说明
--------

这是供小范围测试的 Universal 应用，支持 Apple Silicon 和 Intel，最低部署目标为 macOS 11 Big Sur。
应用使用 ad-hoc 签名，DMG 内的两个 .pkg 尚未使用 Installer 证书签名；它们都没有 Apple Developer ID 或 Apple 公证，属于测试发行版。
macOS 11 部署目标已经双架构编译校验，但尚未在真实 macOS 11 机器上运行验收。

首次安装
--------

1. 推荐双击“安装小米遥控器桥接.pkg”，按提示输入管理员密码。它会一次安装应用和豆包兼容麦克风，并在完成后自动启动状态栏应用。
2. 如果系统阻止安装，进入“系统设置/系统偏好设置 -> 隐私与安全性”，确认安装包来自你信任的分享者后选择“仍要打开”。
3. 按提示允许蓝牙。启用自定义按键映射时，还需要允许“输入监控”和“辅助功能”，然后完全退出并重新打开应用。
4. 如果不需要豆包兼容麦克风，也可以只把“小米遥控器桥接.app”拖到旁边的 Applications，再从“应用程序”手动打开。

遥控器配对
----------

1. 在 Mac 蓝牙设置中打开蓝牙。
2. 同时长按遥控器“主页”和“菜单”键，使遥控器进入配对广播状态。
3. 在 Mac 上接受“小米蓝牙语音遥控器 / MI RC / Xiaomi Bluetooth Remote 2 Pro”的连接提示。

语音与 Fn
---------

1. 对于支持普通虚拟音频设备的应用，安装 BlackHole 2ch 或等价的双向 CoreAudio 回环设备，然后在本应用“虚拟麦克风 -> 语音输出”中选择该回环设备。
2. 豆包输入法可能不显示 transport 为 virtual 的 BlackHole。推荐使用 DMG 内的“安装小米遥控器桥接.pkg”；它会随应用安装独立的 `MiRemoteV 2ch`，不会修改或覆盖 BlackHole。
3. 安装完成后，从状态栏打开本应用设置，点击“刷新音频设备”，再点击“选择 MiRemoteV 2ch”。
4. 先单击目标输入框，确认竖线光标已经出现。
5. 按住遥控器麦克风键说话：应用会把该遥控器真实上报的 F5 硬件按下/松开映射为 Mac Fn，同时把 RC003 语音送入回环设备；松开时会直接释放 Fn 并结束语音流。该映射只匹配小米 RC003，不修改 MacBook 键盘或其他设备，应用退出时恢复原映射。

先在 QuickTime Player 的“新建音频录制”中选择目标设备，确认按住遥控器语音键时有电平。QuickTime 正常、豆包仍无反应时，优先安装 `MiRemoteV 2ch`，而不是修改遥控器或 ATVV 设置。豆包输入法若只出现绿色提示、没有黑色波纹，通常还表示它没有取得当前可编辑输入框；请松开按键、重新单击输入框，确认光标出现后再试。

隐私与边界
----------

- 应用不上传语音，不保存语音文件；PCM 只在内存与用户选定的音频设备之间流动。
- 应用不会修改系统默认输入或输出设备。
- 应用日志不记录语音内容、蓝牙地址或外设 UUID。
- 实物图由项目用户提供；程序的 GPL-3.0-only 许可不额外授予图片或 Xiaomi 商标的转载权。

卸载
----

退出应用后删除“应用程序/小米遥控器桥接.app”。如需移除权限记录，可在系统“输入监控”和“辅助功能”中删除对应条目。若已安装豆包兼容驱动，双击 DMG 内的“卸载豆包兼容麦克风.pkg”；它只会移除 `MiRemoteV2ch.driver`，不会修改 BlackHole。
