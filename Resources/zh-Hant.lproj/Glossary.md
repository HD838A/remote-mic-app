# 術語表

這裡解釋安裝、裝置選擇、系統設定、日誌或技術資料中可能出現的名稱。日常使用時通常不需要理解這些技術細節。

## 遙控器與按鍵

### 小米藍牙遙控器 2 Pro / RC003

**通俗解釋：** 本應用支援的小米藍牙語音遙控器。RC003 是技術資料和部分裝置資訊中使用的型號代號。

**何時會遇到：** 藍牙裝置列表、產品包裝、日誌或故障排查資料中。

### Fn

**通俗解釋：** Mac 鍵盤上的功能修飾鍵。本應用可讓遙控器的麥克風鍵在需要時提供 Fn 功能。

**何時會遇到：** 按鍵說明、快速鍵錄入或鍵盤相關設定中。

### HID

**通俗解釋：** 系統辨識鍵盤、滑鼠和遙控器按鍵的一套標準。對使用者而言，可把它理解為「按鍵裝置」或「按鍵資料」。

**何時會遇到：** Console 日誌、技術資料或輸入監控權限排障中。

## 麥克風與音訊

### 相容麥克風

**通俗解釋：** 為需要特定音訊裝置型別的輸入法或應用準備的虛擬麥克風。

**何時會遇到：** 選擇語音輸出裝置或安裝輸入法相容驅動時。

### MiRemoteV 2ch

**通俗解釋：** 相容麥克風在 macOS 音訊裝置列表中的真實裝置名。

**何時會遇到：** 「音訊 MIDI 設定」、系統聲音設定或應用的音訊裝置選擇器中。

### BlackHole

**通俗解釋：** 一款開源虛擬音訊驅動，可在 Mac 應用之間傳遞音訊。

**何時會遇到：** 安裝虛擬音訊裝置、選擇語音輸出或排查音訊路由時。

### 虛擬麥克風與音訊迴環

**通俗解釋：** 虛擬麥克風把一個應用產生的聲音提供給另一個應用作為麥克風輸入；音訊迴環是這種在軟體之間傳遞聲音的方式。

**何時會遇到：** 配置輸入法語音輸入、錄音、會議或直播軟體時。

### Core Audio

**通俗解釋：** macOS 負責錄音、播放和音訊裝置管理的系統音訊框架。

**何時會遇到：** Console 日誌、音訊錯誤資訊或技術排障資料中。

## 藍牙與裝置標識

### ATVV

**通俗解釋：** 部分藍牙語音遙控器用來傳輸語音的技術協議。普通頁面稱它為「遙控器語音服務」。

**何時會遇到：** Console 日誌、藍牙協議資料或高階故障排查中。

### UUID / 裝置唯一標識

**通俗解釋：** 系統用來區分裝置或藍牙服務的一串唯一編號，不是裝置名稱。

**何時會遇到：** Console 日誌、系統報告或藍牙技術資料中。

## macOS 權限

### 輸入監控

**通俗解釋：** 允許應用讀取遙控器按鍵。應用不會藉此記錄你輸入的文字。

**何時會遇到：** 「系統設定 → 隱私與安全性 → 輸入監控」中。

### 輔助使用權限

**通俗解釋：** 允許應用把遙控器按鍵轉換成快捷操作併傳送給目前的 App 。

**何時會遇到：** 「系統設定 → 隱私與安全性 → 輔助使用」中。

## 安裝檔案

### DMG

**通俗解釋：** Mac 常見的磁碟映像安裝包。開啟後通常把應用拖到「應用程式」資料夾。

**何時會遇到：** 下載和安裝應用時。

### PKG

**通俗解釋：** 帶有安裝嚮導的 Mac 安裝包，常用於安裝驅動或需要寫入系統位置的元件。

**何時會遇到：** 安裝相容麥克風或其他音訊驅動時。
