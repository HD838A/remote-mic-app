# 版本歷史

## 1.9.21（預釋出）

- 提高版本更新檢查的可用性，減少偶發無法獲取更新資訊的問題。

## 1.9.20（預釋出）

- 新手引導統一使用 Fn 語音鍵，減少首次配置時的模式混淆。
- 對已有語音鍵設定提供遷移提示，幫助完成新版配置。
- 加強首次使用的麥克風、音訊輸出與語音結果診斷，失敗原因更清晰。
- 修復遙控器仍在連接準備時，Fn 點選模式可能被意外關閉的問題。
- 更新專案說明中的展示圖片。

## 1.9.19（預釋出）

- 改進 Onboarding 權限頁返回、語音測試輸入框和診斷反饋。
- 未安裝已知語音工具時保留「其他語音工具」入口，並提供豆包官方安裝入口。
- 改進「回眸」錄音播放失敗提示，幫助區分記錄缺失、檔案修改、讀取失敗和播放器啟動失敗。
- 修復遙控器喚醒後語音鍵對映未恢復的問題。
- 解除安裝 SayAll 時將相關 App 、歷史路徑和驅動移入廢紙簍，安裝替換失敗時支援回滾。
- 移除「回眸」僅錄音記錄上的 Finder 入口，保留播放、匯出和移入廢紙簍。

## 1.9.18（正式版）

- 修復大量回眸記錄瀏覽時的重複、空白和滾動卡頓。
- 全部應用預設顯示最近 7 天記錄，選擇具體應用可檢視完整歷史。

## 1.9.17（預釋出）

- 改進首次設定中的語音工具配置，支援微信輸入法、Typeless 和豆包的安裝狀態辨識與引導。
- 首次設定新增 Fn/地球鍵、左 Command、右 Command 語音觸發模式選擇；Typeless 保持 Fn 點按行為。
- 選擇語音輸入法後自動切換對應輸入源，並減少升級使用者重複進入完整首次設定。
- 修復預覽版 Build 高於候選包時的語義版本更新誤判。
- 移除會開啟文字下載連結的版本歷史按鈕，關於頁直接顯示最新版本的本地化更新內容。

## 1.9.16（預釋出）

- 新增左 Command 和右 Command 語音觸發模式，預設 Fn/地球鍵行為保持不變。
- 語音鍵按下後立即開始、釋放後立即結束；輸入框聚焦改為普通遙控器按鍵的獨立動作。
- 改進 Electron、Web、搜尋框和 Terminal 等前台輸入框的聚焦可靠性。
- 修復 RC003 TV 鍵在不同鍵盤佈局下向前台文字框洩漏字元的問題。
- 改善 Mac 從睡眠喚醒後的藍牙恢復和音訊故障診斷。
- 支援使用遙控器控制 macOS Command-Tab 應用切換器。
- 為不可連發動作增加可選的快速連續按功能，預設保持關閉。
- 修復組合動作編輯頁面誤消費普通遙控器按鍵的問題。
- 新增本地儲存原始錄音，並改進沒有可編輯輸入框時的回眸記錄。
- 新增向上滾動和向下滾動遙控器動作。
- 調整「關於」頁語言選擇器的佈局對齊。

## 1.9.10（預釋出）

- 組合動作現在預設開放，無需邀請碼即可檢視、建立、繫結和使用。

## 1.9.9（預釋出）

- 在「關於 → App 偏好」中新增可選的「登入時自動啟動」，需要 macOS 批准時可直接開啟「登入項」設定。
- 新增頁面內鍵盤快速鍵選擇，可選擇常用鍵、方向與導航鍵、F1–F20、數字鍵盤以及獨立的左右修飾鍵，同時保留實體鍵盤錄入方式。
- 改進首次設定和權限恢復：視窗會在按內容尺寸調整後居中，Input Monitoring 或 Accessibility 權限變化後已啟用的自定義按鍵對映會自動恢復。
- 語音輸入現在只選擇已啟用的首選輸入法，避免重複觸發確認提示；除非你在會話中手動改選，否則會話結束後恢復原輸入法。
- 改進失效快取遙控器的藍牙恢復，採用有界退避並處理藍牙電源恢復，同時保留已儲存的配置和對映。
- 減少語音流期間無效的介面重新整理，同時保持音訊處理和診斷行為不變。
- 防止同時啟動多個無線麥例項；再次開啟 App 時會啟用已有例項，不會重複初始化藍牙、音訊或 HID。
- 在不同 App 之間切換時保持設定視窗可見，並在視窗真正關閉前保留 Dock 圖示。
- 修復 RC003 monitored 模式下將電視鍵繫結為自定義動作時向前台文字框洩漏「§」字元的問題。

## 1.9.8（預釋出）

- 改進從舊版 Remote Mic 安裝升級的可靠性：更新音訊驅動前會先停止舊版 App ，新版無線麥SayAll.app 保持在標準 Applications 路徑，升級後可以更穩定地繼續音訊設定。

## 1.9.7（預釋出）

- 修復首次語音設定過程中 macOS 輸入法確認提示反覆出現的問題；只有在語音工具步驟需要時才會切換選定的輸入法。

## 1.9.6（預釋出）

- 首次設定中的權限卡在已授權後仍可點選，方便重新開啟對應的 macOS 隱私設定檢查或修復權限。
- 已安裝使用者升級後如果缺少必要權限，會直接進入權限修復頁面。
- 改進首次設定中的實體遙控器發現：首次真實按鍵即可選擇正確裝置，不再因等待首個 HID 報告而長時間卡住；當其他輸入工具獨佔裝置時提供更明確的處理提示。

## 1.9.5（預釋出）

- 修復未繫結的實體遙控器在首次設定中已被發現、但首次按鍵可能無響應的問題；首次設定現在可以可靠接受第一次輸入。

## 1.9.4（預釋出）

- 在 Mac 開啟「連接手機」後，iPhone 可掃描短時 QR 碼直接連接目前區域網；直連失敗時會自動回退原有的 Bonjour/P2P 自動發現，舊版 iPhone 與 Apple Watch 的連接方式保持不變。

## 1.9.3（預釋出）

- 首次設定會正確同步 Typeless 的 Fn 點按設定；實體遙控器的普通按鍵已被辨識時，也能繼續後續連接檢查。
- 組合動作不再需要邀請碼；在包含對應私有模組的構建中可以直接使用，其他受邀功能的獨立存取限制保持不變。

## 1.9.1（預釋出）

- 應用統一更名為無線麥SayAll.app，並支援從舊版 Remote Mic.app 和無線麥.app 安裝遷移。
- 組合動作可將開啟 APP、等待、快速鍵和輸入框聚焦組合後繫結到遙控器按鍵。
- 新增僅儲存在本機的「回眸」語音記錄，支援撤銷刪除；SayAll MCP 預設關閉，啟用後僅提供只讀存取。
- 重新整理首次設定流程，明確支援 MiRemoteV 2ch、BlackHole 2ch 等相容裝置，並在完成前驗證真實語音輸入。
- 改進 Apple Watch 直接語音輸入與停止後快速重啟處理；完整真機場景仍在持續驗證。
- 修復首次聚焦輸入框後，第一句語音可能未記入「回眸」的問題。
- 改進虛擬音訊在輸出狀態過期、Mac 休眠或喚醒後的釋放與恢復。
- 在側邊欄、關於頁和統計頁增加分享入口，並將問題回報集中到關於頁。
- 權限缺失時提供更明確的升級檢查與恢復提示。
- 增強 HID 按鍵鏈路的分層診斷資訊，用於繼續定位偶發丟鍵。

- 遙控器卡片完整顯示「小米藍牙遙控器 2」和「小米藍牙遙控器 2 Pro」，使用電量與充電標識區分電池狀態；檔案選單新增「開啟日誌所在資料夾」。

- 修復遙控器藍牙斷開後相容麥克風仍保持活動、可能繼續佔用會議或語音輸入應用的問題；斷開後會結束目前語音並釋放虛擬音訊裝置。
- 移除未實際生效的普通遙控器長錄音續期嘗試，避免額外的強制停止和重連；約一分鐘錄音限制仍在繼續研究。

- 如果目標 APP 被關閉、切換、等待超時或焦點落在敏感欄位，本次語音會安全取消，不會傳送到錯誤視窗。

## 1.8.8（預釋出）
