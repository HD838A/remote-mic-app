# 无线麦首次安装说明

[English](首次安装说明.en.md)

## 使用要求

- Apple Silicon Mac；
- macOS 14 或更高版本；
- 小米蓝牙遥控器 2 Pro。

安装不需要 Xcode 或“命令行开发者工具”。

自 v1.3.0 起，正式发布的应用、DMG 内两个 PKG 和 DMG 均使用 Developer ID 签名并已完成 Apple 公证。请只从本项目 GitHub Releases 下载，并核对同一 Release 提供的 `.sha256` 文件。

## 安装

打开 `Remote-Mic-<版本>.dmg` 后，推荐双击 Install Remote Mic.pkg。安装器会：

1. 把无线麦SayAll.app（文件名 `SayAll.app`）安装到“应用程序”；
2. 安装豆包兼容麦克风 `MiRemoteV 2ch`；
3. 重启系统音频服务；
4. 为当前桌面用户启动无线麦SayAll.app。

从旧版本升级时，安装器会先按 Bundle ID 核对 canonical 和旧应用路径，但不会在安装前删除已有 App；新 `SayAll.app` 安装并验证成功后，才把 Bundle ID 匹配的旧 `Remote Mic.app` 或 `无线麦.app` 移到废纸篓，以便需要时恢复。若废纸篓不可用，旧 App 会保留在原位置；若 canonical 目标路径属于其他应用，安装器会停止；旧路径中的未知内容始终保留。

如果不需要豆包兼容麦克风，也可以把 SayAll.app 拖到 Applications。此方式需要 Mac 上已有 BlackHole 2ch 等可用的回环音频设备。

若系统仍阻止安装，请删除本地下载件，从 GitHub Releases 重新下载，并核对 `.sha256` 文件；不要使用来源不明的副本。

## 配对遥控器

1. 在 Mac 蓝牙设置中打开蓝牙。
2. 首次连接时，长按遥控器“TV”键约 2 秒，直到遥控器底部白灯闪烁。
3. 同时长按遥控器“主页（Home）”和“菜单（Menu）”键，使遥控器进入蓝牙配对状态。
4. 在 Mac 上连接“小米蓝牙语音遥控器”、`MI RC` 或 `Xiaomi Bluetooth Remote 2 Pro`。

## 权限

首次启动后按提示允许蓝牙权限。

如果需要自定义普通按键，还要在“权限”页面依次允许输入监控和辅助功能。授权后请完全退出并重新打开无线麦SayAll.app。

## 配置语音输入

1. 左键单击菜单栏中的无线麦SayAll.app 图标。
2. 在“连接与语音”中点击“刷新音频设备”。
3. 选择 `MiRemoteV 2ch` 或其他可用回环设备。
4. 在目标语音输入应用中选择同一个设备作为麦克风。
5. 单击目标输入框，按住遥控器语音键说话，松开后结束。

可以先在 QuickTime Player 的“新建音频录制”中选择目标设备，确认按住语音键时有输入电平。

## 卸载

1. 退出无线麦SayAll.app。
2. 从同一 GitHub Release 下载并双击 Uninstall Remote Mic.pkg。

卸载 PKG 会在核对 Bundle ID 后，把已识别的 SayAll.app、历史 App 路径和 `MiRemoteV 2ch` 移到 macOS 废纸篓，需要时可恢复。它不会修改 BlackHole 或无线麦的本地设置；同名但不属于无线麦的内容会保留在原位。如果废纸篓不可用或移动失败，卸载器会停止并恢复本轮已移动的项目。

## 隐私与许可

无线麦不上传或保存语音，不修改系统默认音频设备，日志不记录语音内容、蓝牙地址或设备唯一标识。

项目软件代码采用 `GPL-3.0-only` 许可，App Logo 采用独立的专有品牌资产许可。许可材料保留在应用包内；每个正式版本的完整对应源码均可在 GitHub 仓库中获取，并由相应 Git 标签标识。
