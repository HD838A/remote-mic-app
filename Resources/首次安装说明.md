# 无线麦 1.4.6 首次安装说明

[English](首次安装说明.en.md)

## 使用要求

- Apple Silicon Mac；
- macOS 14 或更高版本；
- 小米蓝牙遥控器 2 Pro / RC003。

安装不需要 Xcode 或“命令行开发者工具”。

自 v1.3.0 起，正式发布的应用、DMG 内两个 PKG 和 DMG 均使用 Developer ID 签名并已完成 Apple 公证。请只从本项目 GitHub Releases 下载，并核对同一 Release 提供的 `.sha256` 文件。

## 安装

打开 `Remote-Mic-1.4.6.dmg` 后，推荐双击 Install Remote Mic.pkg。安装器会：

1. 把 Remote Mic.app 安装到“应用程序”；
2. 安装豆包兼容麦克风 `MiRemoteV 2ch`；
3. 重启 CoreAudio；
4. 为当前桌面用户启动 Remote Mic。

从旧版本升级时，安装器会先确认已有应用的 bundle identifier 属于 Remote Mic，再退出并移除旧应用，然后安装新版；不再需要手动删除旧版 App。若目标路径属于其他应用，安装器会停止而不会覆盖它。

如果不需要豆包兼容麦克风，也可以把 Remote Mic.app 拖到 Applications。此方式需要 Mac 上已有 BlackHole 2ch 等可用的回环音频设备。

若系统仍阻止安装，请删除本地下载件，从 GitHub Releases 重新下载，并核对 `.sha256` 文件；不要使用来源不明的副本。

## 配对遥控器

1. 在 Mac 蓝牙设置中打开蓝牙。
2. 同时长按遥控器“主页”和“菜单”键，使遥控器进入配对状态。
3. 在 Mac 上连接“小米蓝牙语音遥控器”、`MI RC` 或 `Xiaomi Bluetooth Remote 2 Pro`。

## 权限

首次启动后按提示允许蓝牙权限。

如果需要自定义普通按键，还要在“权限”页面依次允许输入监控和辅助功能。授权后请完全退出并重新打开 Remote Mic。

## 配置语音输入

1. 左键单击菜单栏中的 Remote Mic 图标。
2. 在“连接与语音”中点击“刷新音频设备”。
3. 选择 `MiRemoteV 2ch` 或其他可用回环设备。
4. 在目标语音输入应用中选择同一个设备作为麦克风。
5. 单击目标输入框，按住遥控器语音键说话，松开后结束。

可以先在 QuickTime Player 的“新建音频录制”中选择目标设备，确认按住语音键时有输入电平。

## 卸载

1. 退出 Remote Mic。
2. 双击 DMG 中的 Uninstall Remote Mic.pkg，移除 `MiRemoteV 2ch`。
3. 删除“应用程序”中的 Remote Mic.app。

卸载 PKG 不会修改或删除已有的 BlackHole。

## 隐私与许可

无线麦不上传或保存语音，不修改系统默认音频设备，日志不记录语音内容、蓝牙地址或外设 UUID。

项目软件代码采用 `GPL-3.0-only` 许可，App Logo 采用独立的专有品牌资产许可。许可材料保留在应用包内；`1.4.0` 的完整对应源码可在 GitHub 仓库中获取，正式发布时由相应 Git 标签标识。
