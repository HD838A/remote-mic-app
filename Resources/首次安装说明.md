# 无线麦 1.0.2 首次安装说明

## 使用要求

- Apple Silicon Mac；
- macOS 26 或更高版本；
- 小米蓝牙遥控器 2 Pro / RC003。

应用使用 ad-hoc 签名，DMG 内的两个 PKG 未使用 Installer 证书签名，当前均未进行 Apple 公证。请只安装来自你信任来源的文件。

## 安装

打开 `Remote-Mic-1.0.2.dmg` 后，推荐双击“安装无线麦.pkg”。安装器会：

1. 把“无线麦.app”安装到“应用程序”；
2. 安装豆包兼容麦克风 `MiRemoteV 2ch`；
3. 重启 CoreAudio；
4. 为当前桌面用户启动无线麦。

如果不需要豆包兼容麦克风，也可以把“无线麦.app”拖到 Applications。此方式需要 Mac 上已有 BlackHole 2ch 等可用的回环音频设备。

若系统阻止安装，请前往“系统设置 → 隐私与安全性”，确认文件来自你信任的来源后选择继续打开。

## 配对遥控器

1. 在 Mac 蓝牙设置中打开蓝牙。
2. 同时长按遥控器“主页”和“菜单”键，使遥控器进入配对状态。
3. 在 Mac 上连接“小米蓝牙语音遥控器”、`MI RC` 或 `Xiaomi Bluetooth Remote 2 Pro`。

## 权限

首次启动后按提示允许蓝牙权限。

如果需要自定义普通按键，还要在“权限”页面依次允许输入监控和辅助功能。授权后请完全退出并重新打开无线麦。

## 配置语音输入

1. 左键单击菜单栏中的无线麦图标。
2. 在“连接与语音”中点击“刷新音频设备”。
3. 选择 `MiRemoteV 2ch` 或其他可用回环设备。
4. 在目标语音输入应用中选择同一个设备作为麦克风。
5. 单击目标输入框，按住遥控器语音键说话，松开后结束。

可以先在 QuickTime Player 的“新建音频录制”中选择目标设备，确认按住语音键时有输入电平。

## 卸载

1. 退出无线麦。
2. 双击 DMG 中的“卸载无线麦.pkg”，移除 `MiRemoteV 2ch`。
3. 删除“应用程序”中的“无线麦.app”。

卸载 PKG 不会修改或删除已有的 BlackHole。

## 隐私与许可

无线麦不上传或保存语音，不修改系统默认音频设备，日志不记录语音内容、蓝牙地址或外设 UUID。

项目采用 `GPL-3.0-only` 许可。许可材料保留在应用包内，`1.0.2` 的完整对应源码由 GitHub 标签 `v1.0.2` 提供。
