# 无线麦前台仍沿用上一套专用方案

## 复现

1. 开启按前台 App 自动切换。
2. 让网易云等目标 App 的专用方案生效。
3. 打开无线麦SayAll.app。
4. 按遥控器上已在专用方案配置的按键。

错误行为：仍执行上一目标 App 的专用方案。

预期行为：无线麦前台时回到默认方案；只有“设置按键”步骤把实体键用于选择，不执行任何方案动作。

## 根因

自动方案解析器把无线麦前台与锁屏/无法识别前台 App 合并处理，并在已经有活动方案时保持原值，因此上一套专用方案不会退出。

## 修复

- 无线麦SayAll.app 成为前台时明确切回默认方案。
- 锁屏、空 Bundle ID 和短暂无法识别当前 App 时仍保持当前，不扩大行为变化。
- “设置按键”步骤继续由宿主单独拦截实体键，只用于选择按键。

## 验证

自动测试覆盖“目标 App 专用方案 → 无线麦默认方案 → 目标 App 专用方案”，并保留编辑步骤路由测试。真实前台切换和实体遥控器仍需本地签名包验收。
