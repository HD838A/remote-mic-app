# 普通安装要求下载 Xcode 命令行工具

- 时间：2026-07-30
- 状态：已修复
- 影响范围：macOS 1.4.6 之前的普通用户安装包
- 功能点：PKG 安装脚本与驱动部署
- 简单描述：安装脚本依赖开发工具命令，使没有 Xcode Command Line Tools 的普通用户被系统要求额外下载开发组件。
- 原始记录：中英文版本历史；修复提交 7f383b6，事故记录 94c47d0

## 详细过程

发布安装脚本使用了普通系统环境不保证存在的开发工具。修复移除该依赖并改用 macOS 标准工具完成安装步骤，同时补充安装包验证和事故记录，确保目标用户无需安装 Xcode 或命令行开发者工具。
