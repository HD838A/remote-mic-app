# Mac 切回前台重复请求会员

旧版在启动、应用激活和系统唤醒时请求完整会员刷新。设置窗口还监听同一个激活事件。已初始化会话因此可能反复请求账号、商品目录和购买选项。并发保护只合并重叠的刷新。

Cloudflare 的接口聚合只能确认这几条接口调用较多。它没有记录 Mac 生命周期触发来源，无法按首次打开、前台切换或其他入口拆分历史用量。

宿主在会员设置内容出现时加载页面。侧栏、深链和各功能跳转复用同一个入口。普通设置页、启动、应用激活和系统唤醒移除完整刷新。首次启动的本机会话恢复、到期维护、支付确认和用户主动操作沿用原有入口。

验证使用 `SAYALL_PRIVATE_PLATFORM_MODE=public swift test --disable-keychain --filter MembershipRefreshRoutingTests` 检查宿主触发点。会员模块另外用模拟 HTTP 验证初次加载、限流、失败恢复，以及退出和停售边界。模拟结果不代表已在分发安装包或 Cloudflare 完整配额日验证。
