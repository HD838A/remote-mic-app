A

结论

当前没有证据证明 PacketLogger 导致 Mac 死机。

代码能确认：启用 Siri Remote 后，只要 App 在运行，系统级 HCI 追踪会持续开启。最值得排查的是 macOS bluetoothd 生成的 .pklg 文件。App 自己的日志不是主要风险。

本文档只记录风险与取证方法。暂不修改代码，不声明根因，不提供修复结论。

C

启用后的运行链路

关键代码：

  • BridgeAppModel.startIfNeeded() 在功能启用时直接启动 Siri Remote，不等第一次语音按键。
  • AppleRemoteAudioClient.start() 启动 helper 后立即准备 HCI 与 PacketLogger。
  • 未在语音会话时，handlePacketInline() 直接丢弃包，不做 Opus 解码。
  • 正常退出时 BridgeAppModel.stop() 释放链路；异常退出依赖 XPC 失效回调和 helper 下次启动恢复。
D

资源边界

资源 是否持续 上限或清理 结论
App 加密日志 .rmlog 是 单文件 10 MB；最多 15 个归档；目录 32 MB；保留 7 天 有硬上限，不是主要风险
原始 HCI 包 仅内存 不写盘、不记录包内容 不形成历史队列
系统 HCI trace .pklg 可能持续 代码不设 MaxFileSize、MaxTraces；不删除文件 主要磁盘风险
PacketLogger 流量 是 8 MiB/s；20,000 packets/s；超限停止 有上限，但上限较高
CPU 事件驱动 仅会话期间解码；无逐包定时器 空闲不应持续高，但非零
bluetoothd 启用/恢复时 killall -30 bluetoothd 触发重载 会短暂影响全部蓝牙设备
HCI helper 按需常驻 LaunchDaemon 无 KeepAlive；空闲等待 XPC 空闲 CPU 低
E

根因假设

假设 置信度 依据 缺口
系统 HCI 文件 trace 持续增长或产生大量磁盘 I/O 中 HCIFileTraces 开启；系统二进制含 .pklg、MaxFileSize、MaxTraces、UnlimitedHCIFileSize；App 不清理 没有现场 trace 文件大小和磁盘采样
全量 HCI 事件持续送到 App 导致 CPU 偏高 中低 PacketLogger 接收所有 HCI 包；空闲时仍经过 XPC 和校验 没有 sample 或 Activity Monitor 对照
bluetoothd 重载与驱动/固件交互触发系统异常 低中 启用和恢复都发送 SIGUSR1；会影响全部蓝牙设备 没有 panic、bluetoothd 崩溃或系统版本证据
App 日志或内存泄漏 低 日志有上限；原始包不写盘；无历史包队列 未做长时间内存采样
与 PacketLogger 无关的蓝牙驱动、硬件或系统问题 未知 本机报告未指向 PacketLogger 缺少用户现场报告

现场需要补充：

  1. 死机时间点、macOS 版本、Mac 型号和是否连接蓝牙音频设备。
  2. /Library/Logs/DiagnosticReports 下的 panic 或 bluetoothd 崩溃报告。
  3. /Library/Preferences/com.apple.MobileBluetooth.debug.plist 是否残留，以及 HCITraces 内容。
  4. 系统 HCI trace 文件的实际路径、数量和总大小。
  5. 复现时分别采样 bluetoothd 与 RemoteMic 的 CPU；对比关闭 Siri Remote 后的表现。
  6. pmset -g log 中死机前后的睡眠、唤醒和电源事件。
G

暂不修复范围

  • 不修改 HCI trace 开关。
  • 不增加 trace 文件清理或容量限制。
  • 不改变常驻预热策略；该项影响首字延迟，需单独产品决策。
  • 不增加组件级卸载；该项已登记在 TODO.md。
  • 不把当前假设写成已确认根因。

当前可用的停止方式只有退出 App。正常退出会释放 lease 并恢复蓝牙 debug 配置；异常退出后由 helper 启动恢复。若恢复失败，日志应出现 release_failed result=configuration_restore_failed，现场应检查 debug plist 是否仍含 HCITraces。

验证边界

本文档基于代码、系统二进制字符串和本机现有报告，不构成真实故障复现。

本机未发现 bluetoothd 或 kernel panic 报告。RemoteMic 报告分为三类：截图 harness 触发 SIGTRAP；测试包缺少 Sparkle framework；一份 CPU 资源报告指向 SwiftUI 辅助功能树。这些报告均不能证明 PacketLogger 导致系统死机。

在取得现场证据前，本问题保持待排查，不进入修复或发布门禁。
