# 首次使用无法选择艾拍宝 T1

本机 Build 452 支持 T1 的日常连接，但新用户在首次引导中找不到 T1。控制设备卡片从公共蓝牙型号枚举生成，当时枚举只有 RC003 和 RC001。连接设备集合、普通按键和语音路由的型号校验也都依赖该枚举，因此单独补一个卡片无法完成引导。

修复把 T1 纳入公共蓝牙路径，沿用已有的型号持久化、连接识别和语音测试门禁。首次引导展示 T1 实际按键及其主页加返回的配对步骤。已在系统中连接且可唯一识别的 T1 走既有的自动建桥流程。普通按键测试只记录实体输入，并抑制配置动作。

`SKIP_SWIFT_PACKAGE_BUILD=1 scripts/test.sh` 中的新回归在修复前失败，修复后 66 项通过。Apple Silicon 应用以仓库打包脚本编译，通过中英文资源校验。在隔离的真实 App 窗口，用两张卡片来回切换，选中 T1 并继续后实际进入权限页。中英文浅色和深色的生产渲染截图覆盖控制设备、配对与普通按键页。该轮交互验收到权限页，完整 T1 新装授权、真实按键以及听写继续按验收手册验证。
