# Siri Remote 按键映射、活动高亮与页面布局

## 复现条件

- 设备：Apple Siri Remote A2854。
- 页面：无线麦SayAll.app → 按键 → A2854 独立映射页。
- 开启“启用自定义按键功能”。

## 错误行为

1. 播放/暂停、静音和电源配置自定义动作后，仍执行原生功能或不执行映射。
2. 音量减会执行自定义动作，同时继续降低系统音量。
3. 实机按下 Siri、确定、播放/暂停、静音、电源时，对应卡片没有活动描边。
4. 页面卡片纵向间距大于 RC003，且“右”键卡片错误地位于左列。

## 日志证据

- 播放/暂停和静音进入 `APPLE REMOTE SYSTEM_ACTION` 固定旁路，没有读取设备档案映射。
- 电源记录 `APPLE REMOTE ACTION ... result=unmapped control=power`。
- 音量减同时记录 `APPLE REMOTE BUTTON ... action=openRemoteMic` 与 App 打开成功，证明映射已经执行；系统音量仍变化说明原生 Consumer HID 事件没有被抑制。
- 确定键由适配器规范化为通用 `ok`，而 A2854 页面使用原始 control ID `select`；播放/暂停、静音和电源此前没有通用按钮映射；Siri 页面状态此前绑定语音流状态而非物理按下状态。

## 根因

- 播放/暂停与静音由独占 HID 后的固定系统动作回调处理，绕过通用按键映射；电源没有通用映射。
- Apple Remote 路径没有像 RC001/RC003 一样为原生键盘/系统媒体事件建立按下和释放抑制窗口。
- 页面收到的是通用按钮 ID 和语音会话状态，不是 A2854 原始控制项的物理生命周期。
- A2854 独立页面的 placement 常量使用了过大的纵向步长，并把 `right` 标成左列。

## 修复

- 将播放/暂停、静音、电源接入通用 `RemoteButton` 映射，删除固定系统动作旁路；Siri 继续保持固定语音键，不进入普通按键映射。
- 为 A2854 各控制项声明可能出现的原生事件，并在每个 `began/ended` 边沿调用现有 `KeyboardEventSuppressor`；日志记录 control、边沿和候选数量，不记录设备身份或用户快捷键内容。
- 按设备维护原始 A2854 control ID 活动集合，页面直接使用该集合显示确定、媒体、电源和 Siri 的物理按下状态。
- 页面两列卡片中心距统一为 RC003 的 `82.65 pt`，保持 72 pt 卡片不重叠；“右”键移动到右列。根据后续布局反馈，顶部“电源”键移动到左列并重新排列左列，使左右卡片数量差为 1。

## 自动化验证

- 私有 Siri Remote Package：`swift test`，43 项通过。
- 主仓库定向测试：`swift test --filter AppleSiriRemoteAdapterTests`，17 项通过。
- 回归断言覆盖通用按键映射、原生事件候选、宿主抑制入口、原始 control ID 高亮、电源键左列、右键列、左右列数量平衡和 `82.65 pt` 卡片间距。

## 真机验证边界

自动化不能证明 macOS 最终产生的 CGEvent 类型与候选集合完全一致。候选 App 构建后仍必须用 A2854 分别验证播放/暂停、静音、电源和音量减：只执行配置动作、不再产生原生媒体、音量或电源副作用，并在按下期间显示对应活动描边。
