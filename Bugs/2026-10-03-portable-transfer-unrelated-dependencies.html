复现与证据

普通按键选择自定义快捷键，再清除快捷键。随后导入无关组合动作或打开导出候选。修复前 PortableConfigurationCompatibilityTests 的 clearedUnrelatedShortcutDoesNotBlockImportOrCandidateSelection 对导入预览和候选读取均失败。数据与 UserDefaults 全部隔离，不使用真实用户库。

原调用链：文件解码 → exportCandidates → 宿主 portableObjects → 遍历普通映射 → portableAction 对 customShortcut + nil 抛缺依赖错误。导入预览的最低版本检查也调用整库导出。旧链路没有产生成功保存日志；自动化异常是复现证据。

修复

替换列表与导出候选只读身份和名称摘要；导入版本检查读取宿主版本。最终导出才读取所选对象、设置分组及依赖。所选方案的宿主快捷键和 App 依赖通过原窄适配传递，不进入任意 payload 文件格式。已有待配置记录保持。

code review 修复：替换影响列表跳过无法解析的无关待配置动作；展开状态由各页面持有；撤销全部设置分组时保留可读的空设置对象。保持并发检查、整包提交、恢复与隐私边界。
