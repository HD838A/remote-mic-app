# macOS 1.7.6 连接遥控器时启动退出

- 时间：2026-08-06
- 状态：已修复
- 影响范围：macOS 1.7.6 预发布版；macOS 26 且连接小米蓝牙语音遥控器的部分设备
- 功能点：HID 映射读取、写入与应用启动
- 简单描述：读取或写入 HID 映射时系统客户端生命周期过短，部分设备启动后立即退出。
- 原始记录：中英文版本历史；修复提交 7eab31f

## 详细过程

### 现象

1. 1.7.6 在部分已连接小米遥控器的 macOS 26 设备上启动即退出。
2. 普通构建和不连接遥控器的环境不能稳定暴露该问题。

### 根因与修复

HID 映射读取和写入期间没有持续保留所属系统客户端。修复后在完整映射操作生命周期内持有客户端，并增加映射读写回归测试；发布门禁补充在连接遥控器的交互式 Mac 上执行两次启动、正常退出和崩溃报告检查。

### 验证

历史发布记录确认 1.7.7 已包含修复。原始调查未单独保存，本文只归并版本历史与修复提交中可核实的信息。
