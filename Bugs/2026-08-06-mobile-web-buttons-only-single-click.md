# 手机网页版按键只能触发单击

- 时间：2026-08-06
- 状态：已修复
- 影响范围：手机网页版与 Mac 1.7.6 之前的远程按键协议
- 功能点：单击、双击、长按自定义动作
- 简单描述：网页版所有可配置按键都只发送单击，无法触发与实体遥控器一致的双击和长按映射。
- 原始记录：中英文版本历史；修复提交 e2afd02

## 详细过程

旧 Web 协议和客户端没有完整表达按键手势，Mac 端也没有为 Web 与附近 iPhone/iPad 分别维护手势状态。修复扩展了协议、Web 交互和 Mac 手势识别，使三种触发方式与实体遥控器一致，并隔离同时连接的不同移动来源；连接旧版 Mac 时仍回退为单击。相关 TypeScript、Relay、Web 与 Swift 测试随提交补齐。
