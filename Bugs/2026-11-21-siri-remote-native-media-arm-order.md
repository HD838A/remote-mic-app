# Siri Remote 原生媒体事件先于拦截登记

- PR #806 的 `72f59b4b` 允许服务级映射未验证时继续接收设备按键。在 2.0.9（412）中三种媒体键仍然会进入系统事件监听。PR #794 的报告线程预登记用于小米路径。
- 现场共 40 条媒体键按下 `miss`。每条都发生在相应 Siri Remote 控制已到达宿主之后、宿主完成 `arm` 之前。另有 2 条松键 `miss`。
- 在档案选中、状态发布和动作执行之前登记该物理边沿。回归检查登记顺序与三种媒体键的按下、松开配对。原生事件是否能先于宿主回调到达仍待两个型号实机验证。
- 对每个实体媒体键配置容易识别的非音量动作。单击、连点和按住松开时分别观察自定义动作、系统音量、静音状态及过滤日志。映射关闭时检查电脑键盘与遥控器的系统媒体操作。
