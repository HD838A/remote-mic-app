---
title: 私有发布预检使用了错误的测试构建模式
---

## 证据与原因

私有平台完整 Release 模式测试在编译时失败。
蓝牙测试调用的 `_testConfigureSession` 等接口仅在 DEBUG 中存在。
产品 Release 构建不需要这些测试接口。
发布预检却对 test 和 build 都强制传入 release。
它与项目 CI 的 Debug 测试、Release 构建不一致。

## 最小修复

预检显式使用 Debug 测试，然后使用 Release 构建。
保留全部测试、断言、签名、版本和 Tag 校验。
不修改产品实现，不把测试接口加入正式包。
失败时仍不创建 Tag。

## 验证

19 项发布预检测试通过。
回归确认测试使用 Debug，产品构建使用 Release。
回归同时确认验证失败不会创建 Tag。
公开宿主完整 909 项测试通过。
私有平台同源 Debug 完整测试通过，Release 构建单独验证。
这只能证明构建入口，不替代最终包与真实设备验收。

本轮完整日志保存在仓库外，不提交构建产物或凭据。
