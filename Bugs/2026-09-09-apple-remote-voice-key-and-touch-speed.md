# Siri Remote 语音键不唤醒输入法与触摸/滚动迟缓

## 复现与边界

- 设备：Apple Siri Remote A2854。
- 操作：连接后按住 Siri 语音键；随后分别测试触摸移动和环形滚动。
- 用户现场现象：App 能收到语音键，但目标输入法没有被唤醒；触摸和滚动体感明显偏慢。
- 本次无法读取用户实际测试 Mac 的日志，因此下述根因来自代码路径和旧包行为，不把当前开发机日志当作现场证据。

## 根因

`BridgeAppModel` 把 Siri 控件放在 `customMappingEnabled` 门控之后；映射关闭时事件直接走
`system_managed`，没有进入语音生命周期。即使进入语音路径，只要 HCI/PacketLogger 或音频 helper
还未就绪，旧代码也会立即释放刚按下的 Fn，使输入法只看到过短的 down/up。

私有 Siri Remote 包的指针增益为 `0.6`，环形滚动为 `30 px/rad`、平滑系数为 `0.3`，与当前
真机反馈相比偏慢。

## 修复

- Siri 控件在自定义键位门控之前处理，始终保持固定的即时语音路径。
- 按键按下后先保持输入法语音会话；音频尚未就绪时按 `100/250/500/1000/2000 ms` 有限重试，
  松键立即取消重试，并继续等待尾音自然排空，不直接 flush。
- 私有音频组件对可恢复的 HCI/PacketLogger 启动失败增加最多五次退避重试。
- 指针增益提升到 `1.0`，环形滚动提升到 `48 px/rad`、平滑系数提升到 `0.45`。

## 验证

- 公开宿主与私有 Siri Remote Package 的自动化测试和 release 构建必须通过。
- Developer ID、公证、staple、Gatekeeper 和远端下载回验必须针对最终 Draft 资产执行。
- 仍需用户在真实 A2854、`MiRemoteV 2ch` 和目标输入法上验收语音唤醒、首字、尾字、触摸与滚动速度；
  自动化、构建与签名不能替代该验收。
