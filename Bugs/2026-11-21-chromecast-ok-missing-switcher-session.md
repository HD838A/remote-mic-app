# Chromecast OK 没有进入切换器会话

- 缺口已存在于 PR #445 的初版宿主按键接入。后续 PR #459 保留了通用按键执行路径。
- 2.0.9（412）中，Chromecast 的切换 App 动作只提交一次带 Command 的 Tab。之后 10 次 OK 作为普通自定义快捷键通过事件监听点，最终用户结果未知。
- Chromecast 启动现有 `AppSwitcherSession`，会话消费导航、确认、取消与配对松键。自动化检查 Tab 循环、确认的 Option/Command 顺序、超时释放及会话结束后 OK 交回普通映射。
- 真机在切换器关闭和打开时各测 OK。关闭时对同一个目标 App 分别用实体键盘和遥控器执行同一快捷键。打开时确认高亮 App，重按启动键、长按松开、返回、断连与权限失效分别检查。
