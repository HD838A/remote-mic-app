# Siri Remote 触摸指示器缺失与移动/滚动边界不清

## 复现与边界

- 用户在另一台 Mac 使用 Build 178 真机验证：语音输入正常，普通蓝牙鼠标不再卡顿。
- 使用 Siri Remote 移动鼠标或圆周滚动时，没有看到视觉指示器。
- 触摸移动与滚动存在误触；稳定语音和普通鼠标路径不在本轮修改范围。

## 日志与代码证据

- 当前机器没有用户该次真机日志，因此不能从本机日志推断现场事件序列。
- 私有硬件组件已经定义移动/滚动反馈，但公开宿主当前没有桥接反馈回调，也没有把指示器控制器编入 App；因此底层操作成功并不能产生可见反馈。
- 现有自动化只覆盖理想的中心移动和外圈圆周，没有覆盖容易混淆的轨迹，测试门禁无法发现问题。

## 根因假设

1. 指示器宿主集成在私有组件迁移/打包后遗漏。
2. 手势分类只依据接触起点区域，没有用累计轨迹方向区分移动与圆周滚动。
3. 缺少单次接触模式锁和进入迟滞，边界附近的抖动会放大误触。

## 修复目标

- 恢复只由 Siri Remote 触摸触发的非抢焦点指示器，固定在系统鼠标右下方，保留安全间距并处理屏幕边缘，不覆盖鼠标。
- 单次接触先进入待判定状态，通过累计直线位移与切向旋转决定指针或滚动；选定后锁定到抬手。
- 保持语音期间触摸互斥，不改变语音音频生命周期，也不接管 Magic Mouse/触控板。

## 根因与修复

- 根因一：私有组件迁移后，公开宿主遗漏 `onTouchFeedback` 绑定及指示器控制器，实际鼠标事件可以成功，但没有任何可见反馈消费者。
- 根因二：旧解释器在触摸开始时仅按半径一次性选择中心移动或外圈滚动。外圈开始后的径向移动只进入角度算法，角度不变时动作被吞掉；测试又只覆盖理想中心移动和理想外圈圆周，因此未发现。
- 宿主已恢复反馈桥接。40 pt 浮层中的 14 pt 基础指示器默认放在鼠标右下，与 18 × 24 pt 鼠标保护矩形保留 4 pt 水平间距；屏幕边缘按左下、右上、左上顺序换侧。移动圆环和滚动符号复用同一速度缩放曲线。窗口不激活、不接收鼠标事件，并只在 CGEvent 实际提交成功后显示。
- 指针空闲时只通过公开 Accessibility API 检查鼠标下元素及最多四层父元素是否支持 `AXPress`，以覆盖网页、Electron 和按钮内部图标命中的子元素；不读取元素标题、文本或输入内容。可点击时保留约 1.2 秒 OK 窗口，一次 OK 只执行一次；执行前再次确认光标仍停在原位置，真实鼠标移走后不会误点旧目标。滚动、触摸点击、超时、断连和 App 停止都会清理目标。
- 私有解释器将外圈起点视为候选状态，累计径向和切向运动；径向意图达到阈值后锁定指针，圆周旋转达到阈值后锁定滚动，直到抬手不再切换。外圈起始半径由 `0.35` 调整为 `0.38`，滚动启动阈值由 `0.2` 调整为 `0.28`。
- 新增 `phase=classified mode=pointer|scroll|click` 和指示器 shown/hidden 脱敏日志，能区分分类、CGEvent 提交和最终可见反馈。

## 验证记录

- 修复前失败回放：外圈 `(0.9, 0.5)` 向中心移动到 `(0.84, 0.5)` 没有 pointer 输出，确认旧分支吞掉径向移动。
- 私有 Siri Remote Package：61 项、9 suites 通过，覆盖径向/圆周分类、单次接触模式锁、阈值抖动、语音抑制及原有音频/HCI 基线。
- 完整 Siri 宿主：514 项、44 suites 通过。
- 无私有 Siri Remote 依赖的社区宿主：473 项、39 suites 通过，确认开源独立构建不因反馈代码报错或暴露功能。
- 项目自检 44 项通过；社区 Release App 与注入 Siri Remote、组合动作、键位方案、会员和 Mac Remote 的 Release App 均构建成功并通过 `verify-app.sh`。
- 自动化验证了默认右下、4 pt 安全间距、不与鼠标保护矩形相交、移动/滚动共用基础大小和缩放曲线、屏幕三类边缘换侧，可点击目标自身或最多四层父元素解析，以及目标只消费一次 OK、执行前光标位置二次校验、滚动或断连后失效；NSPanel 的真实视觉、距离体感、Accessibility 最终点击、CGEvent 最终投递和 Siri Remote 实体轨迹仍需签名包在用户测试 Mac 验收。
