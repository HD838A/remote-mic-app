## A 用户可见结果

导入页改为单页方案预览。
右侧仅保留来源链接。
页面不显示导入选项。
Free 可查看全部按键，但不可保存。
查看会员进入当前设置窗口的会员页。

## B 根因与修复

私有页面缺少明确的会员导航动作。
宿主通过标准 OpenURLAction 接收内部会员链接。
会员页面可见时切换侧栏并刷新状态。
会员页面隐藏时丢弃内部链接。
官网及 GitHub 链接继续由系统打开。

私有权限变化原来未通知导入控制器。
隔离页面和失败回归测试确认此问题。
私有组件补通知后，保存状态立即刷新。
宿主不新增权益来源，也不放宽保存门禁。

## C 验证边界

公开构建、私有构件消费者和静态检查分别记录。
原生生产页面使用隔离设置和实际下载文件。
已检查完整按键、取消和会员导航。
组件已检查保存、重启及导出重导入。
组件模拟权益不属于真实会员验收。

Release 包路径校验仍被固定 Sentry 上游路径阻断。
已有独立 PR #565 处理此问题。
本轮不改该校验，也不提供安装包。
