# Onboarding 选择其他语音工具时隐藏豆包官方安装入口

- 时间：2026-08-29
- 状态：候选修复完成，58 张生产截图复验通过
- 影响范围：无线麦SayAll.app 1.9.18 (171)，首次 Onboarding 语音工具页
- 功能点：语音工具安装状态与豆包输入法官方入口
- 简单描述：豆包输入法未安装但用户选择“其他语音工具”时，页面只显示“尚未安装”，没有显示豆包官方安装链接。

## 复现

1. 使用隔离截图状态把豆包、微信输入法和 Typeless 均设置为未安装。
2. 在语音工具页选择“其他语音工具”。
3. 页面显示豆包“尚未安装”和三种工具均未检测提示，但不显示“安装豆包输入法”链接。

正常边界：只要豆包未安装，官方入口都应持续可见，不应依赖当前选择豆包还是其他工具。

## 日志与证据

该问题是纯视图条件错误，不涉及运行时事件或设备会话，运行日志没有额外定位价值。生产离屏截图可稳定复现缺失入口；官方地址已经存在于 `AppLinks.doubaoInputMethod`：

`https://shurufa.doubao.com/?from=sayall.app`

## 根因

`OnboardingView.voiceToolContent` 同时要求“当前选择豆包”和“豆包未安装”才渲染安装入口。选择“其他语音工具”后，第一个条件为 false，因此已有官方地址被隐藏。

## 修复

安装入口只依赖豆包安装状态：`voiceToolAvailability[.doubao] == .notInstalled`。不修改链接、安装检测、工具选择或继续门禁。

## 验证

- 自动化断言豆包未安装入口不再依赖 `settings.onboardingVoiceTool == .doubao`。
- 重新生成“其他语音工具 + 三种工具均未安装”的三条控制路径浅色/深色生产截图，共 58 张、每张 `2040 × 1608`。
- 已逐张检查实体遥控器、iPhone App、网页版三条路径的浅色与深色截图；语音工具页均能看到豆包官方安装入口，全部页面无裁切。

静态截图只能证明入口与布局，不能替代真实浏览器打开豆包官网、真实安装和返回后重新检测。
