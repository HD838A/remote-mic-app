## A 复现与证据

普通按键页把遥控器下键配置成右Command+L。
用户删除网易云专用方案后，Chrome和网易云仍无响应。
实体键盘右Command+L在两者均正常。
Build 253与包含修饰键回显修复的254均复现。
配置保存的键码37和Command右侧位正确。

254日志确认事件执行customShortcut，每次提交4个事件。
系统事件监听仅记录无线麦标记的合成事件和下方向键。
未读取输入文字、页面内容、第三方文件或设备身份。
监听程序仅保留在仓库外，不作为产品或CI入口。

| 边界 | 实际观察 |
| --- | --- |
| 原生下键 | 先收到下方向键，附带Fn、数字键盘和事件属性 |
| 硬件查询 | Fn同时被报告成按住，不能据此证明实体Fn按下 |
| HID与session层 | 合成Command、L按下和松开均含多余Fn |
| App事件层 | 收到Command+Fn+L；Command释放后仍有Fn |

当前生产源码在空闲硬件状态下通过受控系统热键接收器。
左右Command立即投递各请求3次、收到3次。
间隔投递也为3次，不能据此增加生产延时。
此实验不覆盖遥控器原生方向键污染的硬件快照。

## B 已确认原因与修复边界

ShortcutEventSequence把硬件快照中的Fn当作真实物理修饰键。
原生方向键会让系统快照含有Fn和数字键盘属性。
现有硬件掩码去掉数字键盘属性，却保留其附带Fn。
该Fn随后进入已配置的Command+L或Command+Option+B。

复用现有KeyboardEventSuppressor监听，不新建全局监听器。
只用键码63的非合成flagsChanged事件更新真实Fn状态。
显式配置的Fn与真正按住的Fn继续保留。
未知初始状态下，过滤数字键盘方向事件附带的Fn。
只记录是否过滤及状态分类，不记录快捷键正文。
